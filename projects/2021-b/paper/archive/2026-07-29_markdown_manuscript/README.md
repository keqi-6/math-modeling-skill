# Markdown 准正文说明

本目录只保留一份按最终论文阅读顺序连续编写的内容主稿：

- `正文草稿.md`

该文件按正式正文标准编写，不是内部提纲或给论文手的解释笔记。当前只完成第（1）问，
因此正文写到第（1）问的模型、求解、检验和小结为止。摘要、
关键词、全文结论和第（2）至第（4）问不设置空标题，也不写阶段性占位文字；这些内容
将在相应问题完成后接续写入。

本目录不是项目管理区。阶段状态、证据路径、代码文件名、图表落点清单和内部引用键
分别保留在 `planning/`、`docs/`、`output/` 与 `references/`，不得混入
`正文草稿.md` 的评阅文本。

LaTeX 正文仅在 Markdown 全文完成并通过内容审计后生成；最终 PDF 的分页、字体、
图表浮动、匿名和提交合规检查届时另做，不能由当前 Markdown 审计替代。
