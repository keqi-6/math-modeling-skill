# 模型假设与符号说明

## 1 基本假设

本节只保留填补题面信息缺口所必需的假设。题目已经给出的21种组合、温度记录和收率
定义属于已知条件，不重复写成假设。

1. **未记录的实验条件在现有比较中不作为新的解释变量。** 题目只要求围绕催化剂组合
   与温度研究现有数据，且没有给出其他实验条件的完整记录。因此，本文在已测数据范围
   内比较组合与温度，不进一步区分未记录条件的作用。该假设只保证当前比较具有统一
   口径，不能证明现实中不存在其他影响因素。
2. **附件2各时点的测量口径保持一致。** 只有在测量定义和单位一致时，首末变化及相邻
   时间变化才具有可比意义。若实际实验中还发生了附件未记录的操作调整，则本文对时间
   变化原因的解释不再成立，但数值变化本身仍是附件记录的事实。

## 2 符号说明

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| `i` | 催化剂组合编号 | A1—A14、B1—B7 |
| `T` | 附件中已测试的温度条件 | ℃ |
| `t` | 附件2的实验时间 | min |
| `X(i,T)` | 组合 `i` 在温度 `T` 下的乙醇转化率 | % |
| `S(i,T)` | 组合 `i` 在温度 `T` 下的C4烯烃选择性 | % |
| `Y(i,T)` | 组合 `i` 在温度 `T` 下的C4烯烃收率 | % |
| `ΔX` | 同一组合相邻已测温度条件之间的转化率差 | 百分点 |
| `ΔS` | 同一组合相邻已测温度条件之间的选择性差 | 百分点 |
| `P(k,t)` | 附件2中第 `k` 类产物在时间 `t` 的选择性 | % |

其中，百分比之差使用“百分点”表示。例如选择性由30%变为35%，绝对变化是5个百分点，
不是增加5%。
