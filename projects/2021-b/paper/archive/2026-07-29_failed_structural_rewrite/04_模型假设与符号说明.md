# 模型假设与符号说明

## 1 基本假设

1. **未记录实验条件在本问中不作为新的解释变量。** 题目没有提供其他条件的完整记录，
   因而本文只比较组合、温度和时间。该假设不表示现实中不存在其他影响因素。
2. **附件2各时点的数据口径一致。** 只有测量对象、单位和计算口径一致，首末变化和
   平均时间变化才可比较。若实验中存在附件未记录的操作调整，则数值差异仍成立，但
   对时间关系的解释需要收缩。

题面给出的组合、温度、时间和收率定义是已知条件，不重复写成假设。

## 2 符号说明

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| `i` | 催化剂组合 | A1—A14、B1—B7 |
| `T` | 实际测试温度 | ℃ |
| `t` | 附件2实验时间 | min |
| `X(i,T)` | 组合 `i` 在温度 `T` 下的乙醇转化率 | % |
| `S(i,T)` | 组合 `i` 在温度 `T` 下的C4烯烃选择性 | % |
| `Y(i,T)` | C4烯烃收率 | % |
| `ΔX`、`ΔS` | 相邻已测温度条件的响应差 | 百分点 |
| `b(i)` | 简单直线斜率 | 百分点/℃ |
| `ρ(i)` | Spearman相关系数 | -1至1 |
| `R2(i)` | 简单直线对观测变化的描述比例 | 0至1 |
| `e` | 观测值与直线概括值之差 | 百分点 |
| `P(k,t)` | 第 `k` 类产物在时间 `t` 的选择性 | % |

百分比之差使用百分点表示。例如选择性从30%变为35%，绝对变化是5个百分点。
