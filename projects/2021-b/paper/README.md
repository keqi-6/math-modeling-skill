# 论文目录导航

## 当前可用状态

正式论文入口尚未建立。第一问至第四问目前统一收录在一份 LaTeX 内容草稿中。
该草稿通过文件名、源码声明和 PDF 元数据标记为非正式论文，正文版式不插入内部管理

## 目录说明

- `draft/manuscript_draft.tex`：第一至四问统一草稿的唯一当前编译入口。
- `draft/manuscript_draft.pdf`：当前唯一内部审阅 PDF，按正文格式编排。
- `draft/body_q1_model.tex`、`draft/body_q2_model.tex`、`draft/body_q3_model.tex`、
  `draft/body_q4_model.tex`：统一草稿中第一至四问的模型、求解、检验和结论模块。
- `draft/references_all.tex`：统一参考文献。
- `archive/2026-07-29_split_question_drafts/`：统一前的第一问、第二问独立草稿快照，
  只供追溯，不再维护。
- `archive/2026-07-29_markdown_manuscript/`：已完成迁移的旧 Markdown 正文及阶段说明，
  只供追溯，不再维护。
- `archive/`：两轮失效稿，只供追溯。
- `figures/`：论文候选图件目录。图件是否进入正文，须在对应问题完成验证和冻结后决定。
- 当前工作区没有队友同步镜像。历史记录中的 `<未收录-历史交付镜像>/`、`<未收录-历史交付镜像_v6>/` 只说明过去
  曾执行过同步；重新交付前必须从当前主目录重建并用内容比较验证，不能沿用旧同步结论。

## 草稿与正式论文的隔离规则

- 当前只编辑 `draft/` 中的内容草稿。
- 未来正式论文的唯一入口固定为 `paper/paper.tex`，目前不存在。
- 正式入口不得自动 `\input` 整个草稿；只能在正式组装阶段吸收已确认内容。
- 草稿 PDF 不得改名为正式论文 PDF。
- 本项目页边距经用户确认为四边 2.5 cm；这是项目决定，不冒充官方硬规则。
- 当前草稿按负责人决定暂不写摘要，直接从问题重述开始；摘要在四问完成后的最后阶段
  撰写，终稿仍须恢复摘要首页。
