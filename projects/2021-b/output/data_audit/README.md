# 数据审计冻结产物

本目录保存第2步由脚本生成的机器产物。

- `tables/`：清洁数据、结构审计表、异常标记和诊断表。
- `figures/`：同一图形的PNG预览版和PDF论文候选版。
- `audit_summary.json`：主要审计事实。
- `run_manifest.json`：主脚本运行环境与输入信息。
- `artifact_manifest.csv`：主脚本产物路径与哈希。
- `verification.json`：独立复核结论。
- `archive/2026-07-28_pre_discrete_scope/`：研究边界修正前的旧图和旧产物清单，可追溯但非当前。

原始数据不在这里修改；其权威副本位于 `data/`。
