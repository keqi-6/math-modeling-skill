# 第二问输出

当前包含经独立复算通过的直接比较、题目回答汇总和结构删除检查。正文依次使用：
同一组合升温前后的变化、同温组合比较、组合偏差与温度偏差相加后仍未解释的变化，
以及整组或整温度删除后的结论边界。技术输出中保留“非加和剩余”等标准字段名，含义
均对应上述普通表述。

- `summary.json`：数据域、排名摘要和声明边界；
- `verification.json`：独立复算结果；
- `tables/`：共同温度分布、配对变化、排名和非平衡匹配补充。
- `formal_summary.json`：按温度、完整组合和共同变化三类题目答案组织；
- `formal_verification.json`：修订后的13项独立复算；
- `figures/`：组合平均偏差、温度平均偏差和未解释变化三类双格式图；正文保留组合
  平均偏差和未解释变化图，温度图因与配对表重复而留作后台诊断；
- `artifact_manifest.csv`：正式产物路径、哈希和生产程序；
- `robustness_summary.json`：完整组合删除、完整温度删除、异常标记和高温补充摘要；
- `robustness_verification.json`：S11的9项独立复算；
- `candidates/`：S6候选信息增量诊断，未批准为正式第二问结果。

当前固定计数为84个共同温度单元、126条主体配对变化和80条补充配对变化。
目前A层5项、修订S10的13项和S11的9项独立检查均通过。A层解释见
`../../planning/analysis/2026-07-29_question2_simple_baseline.md`。
