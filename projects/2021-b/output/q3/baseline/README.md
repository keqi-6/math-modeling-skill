# 第三问S5实测基线

本目录保存D0实测单元在一般与严格低温两个情景中的确定枚举结果。

- `top10_observed_rankings.csv`：每个情景前10个实测单元及相对最高值差距；
- `scenario_summary.csv`：两种情景的候选数、最高、次高和领先差距；
- `summary.json`：机器可读结果与声明边界；
- `verification.json`：不导入主程序的7项独立复算。
- `artifact_manifest.csv`：输入、脚本和结果的SHA-256清单。

这些结果只表示附件1实测范围内的基线，不是第三问最终推荐，也不批准D1插值或D2新配方。
