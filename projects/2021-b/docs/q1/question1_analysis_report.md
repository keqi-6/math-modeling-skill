# 第一问各组合温度关系与时间变化报告

> 当前状态：逐组合线性关系、相邻温度局部例外、辅助诊断、逐次删点稳健性和19项独立复算
> 均已完成。正文主证据已收束为“相邻差分—每25摄氏度斜率—逐组决定系数—逐点
> 删除检验”；其余统计量保留在结构化结果中，避免正文重复裁决同一结论。

## 1. 一句话结论

在题目实际测试的温度条件中，绝大多数催化剂组合在较高温度条件下具有较高的转化率和
C4烯烃选择性，但少数组合存在反向差异；附件2随时间延长时，转化率明显下降，C4烯烃选择性只小幅波动，
同时乙醛所占份额相对增加、脂肪醇所占份额相对减少。

附件1没有时间字段，也没有说明这些温度来自同一次连续升温实验。因此，本报告把每个
温度视为一个固定反应温度条件，只比较不同条件下的结果，不声称它们构成升温过程，也
不额外声称各温度已经达到稳定状态。本报告不预测未测温度，也不把可能的化学路线写成
已经被本题证明。

## 2. 附件1：每种组合随温度怎样变化

### 2.1 乙醇转化率

- 21种组合中，19种在每对相邻已测温度条件中，较高温度都对应较高转化率；
- A5在275摄氏度条件下比250摄氏度低2.3632个百分点，其余相邻条件中较高温度对应
  较高值；
- A6在275摄氏度条件下比250摄氏度低0.6084个百分点，其余相邻条件中较高温度对应
  较高值。

所以最准确的说法是：较高温度条件通常对应较高转化率，但A5、A6在250和275摄氏度
条件的比较中例外。

### 2.2 C4烯烃选择性

- 15种在每对相邻已测温度条件中，较高温度都对应较高选择性；
- A2、A4、A10在275摄氏度条件下低于250摄氏度，其余相邻条件中较高温度对应较高值；
- A1和A3在各自最高温度条件下低于前一个已测温度；
- B4在250和275摄氏度条件下相同，300摄氏度低于275摄氏度，其余相邻条件中较高温度
  对应较高值。

其中A3最值得单独说明：450摄氏度条件下的转化率比400摄氏度高2.6963个百分点，而
选择性低3.53个百分点。这说明“反应掉更多乙醇”和“产物更偏向C4烯烃”不是一回事。

### 2.3 每种组合的“关系”怎样定义

每种组合和每个考察指标的答案由三部分共同构成：线性函数给出已测区间的平均关系，
决定系数说明函数对本组观测的概括程度，相邻温度差保留函数未表达的局部下降或持平。
图中连接原始点只帮助观察条件间关系，不表示真实实验顺序。该定义使第一问交付42个
每种组合的关系答案，而不是用一句总体趋势代替“每种组合分别研究”。

### 2.4 简单直线补充了什么

对21种组合的转化率和C4 烯烃选择性分别建立一条简单直线，共42组。斜率换算为“温度每增加
25摄氏度，指标平均变化多少个百分点”。该直线给出已测范围内的平均函数关系，并与
局部例外共同构成逐组合答案；它不用于预测未测温度。

- 21种组合的转化率斜率均为正，每25摄氏度平均增加3.2828至16.5740个百分点；
- 21种组合的C4 烯烃选择性斜率也均为正，每25摄氏度平均增加1.2918至6.5299个百分点；
- 42组决定系数为0.7421至0.9988，用于判断直线对各组观测的概括程度；
- 逐次删去一个观测点后，42组直线的斜率方向均未改变。

这些结果支持“总体方向为正”，但不能覆盖局部例外。8组关系存在局部反向或持平：

- 转化率：A5、A6；
- C4 烯烃选择性：A1、A2、A3、A4、A10、B4。

因此这8组必须同时报告具体例外区间。即使决定系数较高，也不能把实际下降改写成全程
严格增加。完整参数、残差和删点范围见：

- `output/q1/tables/attachment1_linear_summaries.csv`
- `output/q1/tables/attachment1_leave_one_out_robustness.csv`

完整数值见：

- `output/q1/tables/attachment1_adjacent_changes.csv`
- `output/q1/tables/attachment1_shape_summary.csv`

## 3. 附件2：时间延长后发生了什么

### 3.1 三个核心结果

- 转化率从43.5474%降至29.9060%，相对下降31.33%；
- C4烯烃选择性从39.90%变为39.04%，只下降0.86个百分点；
- C4烯烃收率从17.3754%降至11.6753%，相对下降32.81%。

收率下降幅度更接近转化率下降幅度。因此，本次实验中收率降低主要伴随转化率降低，而
不是C4烯烃选择性大幅恶化。

### 3.2 全部六类产物

从20分钟到273分钟：

| 产物 | 变化 |
|---|---:|
| 乙烯 | +0.45个百分点 |
| C4烯烃 | -0.86个百分点 |
| 乙醛 | +3.62个百分点 |
| C4—C12脂肪醇 | -8.84个百分点 |
| 甲基苯甲醛和甲基苯甲醇 | +1.37个百分点 |
| 其他 | +4.26个百分点 |

增加项合计增加9.70个百分点，减少项合计减少9.70个百分点。原因是六类比例每个时点都
合计100%，这里反映的是内部份额重新分配，不是总产物增加或减少。

### 3.3 两个补充比例

“乙醛 ÷ C4烯烃”从0.1296升到0.2252。通俗地说，开始时每1份C4烯烃约对应0.13份乙醛，
结束时约对应0.23份。

“脂肪醇 ÷ C4烯烃”从0.9950降到0.7905。开始时脂肪醇份额与C4烯烃几乎相当，结束时
每1份C4烯烃约对应0.79份脂肪醇。

这进一步说明：相对于目标产物，乙醛份额在增加，脂肪醇份额在减少。但这些比例不能证明
乙醛或脂肪醇直接转化成C4烯烃。

### 3.4 时间直线只作平均速度

对本次实验已观测的20至273分钟，简单直线给出：

- 转化率每10分钟平均下降0.5276个百分点，决定系数为0.9329；
- C4 烯烃收率每10分钟平均下降0.1989个百分点，决定系数为0.8575。

这两条直线用于概括总体下降速度。原始点仍显示前期下降较快、后期趋缓，转化率末段还有
轻微回升，因此不能把直线解释成每10分钟都精确下降同样数值。C4 烯烃选择性没有建立正式
直线，继续表述为36.72%至40.32%之间波动。

## 4. 文献能够帮助解释到哪里

其他催化实验表明，乙醛可能是乙醇继续形成较大分子的中间产物，脂肪醇也可能属于与目标
产物竞争或共享部分步骤的路线。因此，本题观察结果与“不同产物路线的相对强弱发生变化”
这一解释相容。

但现有数据不能区分：

- 乙醛是形成得更多，还是后续消耗得更慢；
- 脂肪醇是生成减少，还是继续反应增加；
- 时间变化是催化剂变化、装置逐渐稳定，还是未提供的操作条件造成；
- 本题Co/SiO2与HAP各自承担什么具体作用。

因此图4只称为“相关文献中的乙醇转化可能路线示意”。图中以丁二烯作为文献研究的
C4烯烃示例，不把该路线扩大解释为全部C4烯烃，也不绘制现有文献未充分支持的
甲基苯甲醛和甲基苯甲醇生成路线。最终正文引用该图时，图注必须同时说明路线来自
相关文献、丁二烯只是示例、箭头不代表本题数据已经证明反应机理。
