# 第一问已经核对的结果

这些结果已经完成程序计算和独立复算。

## 附件1：温度关系

### 乙醇转化率

- 21种组合中，19种在所有相邻已测温度条件下，较高温度均对应较高转化率。
- A5在250至275摄氏度之间下降2.3632个百分点。
- A6在250至275摄氏度之间下降0.6084个百分点。

因此只能说“大多数情况下较高温度对应较高转化率”，不能说21种组合全部严格增加。

### C4烯烃选择性

- 15种组合在所有相邻已测温度条件下均为较高温度对应较高选择性。
- A1、A2、A3、A4、A10和B4存在局部下降或持平。
- A3在400至450摄氏度之间，转化率增加约2.6963个百分点，但C4选择性下降3.53个
  百分点。

A3说明转化率和选择性不一定同步，必须分别研究。

### 简单线性概括

- 21种组合的转化率平均斜率均为正，每增加25摄氏度平均增加3.2828至16.5740个
  百分点；
- 21种组合的C4选择性平均斜率均为正，每增加25摄氏度平均增加1.2918至6.5299个
  百分点；
- 逐次删去一个温度点后，42组斜率方向均未改变；
- 但A5、A6的转化率和A1、A2、A3、A4、A10、B4的选择性存在局部反向或持平。

因此直线可以概括总体方向，不能替代上述8组关系的具体例外。

## 附件2：时间变化

| 指标 | 20分钟 | 273分钟 | 变化 |
|---|---:|---:|---:|
| 乙醇转化率 | 43.5474% | 29.9060% | 下降13.6414个百分点 |
| C4选择性 | 39.90% | 39.04% | 下降0.86个百分点 |
| C4收率 | 17.3754% | 11.6753% | 下降5.7001个百分点 |

转化率相对下降31.33%，收率相对下降32.81%，而C4选择性只小幅波动。因此，本次实验的
收率下降主要伴随转化率下降。

在20至273分钟的已观测时段内：

- 转化率每10分钟平均下降0.5276个百分点；
- C4收率每10分钟平均下降0.1989个百分点；
- C4选择性不拟合直线，保留为36.72%至40.32%之间波动。

六类产物从20分钟到273分钟的份额变化为：

| 产物类别 | 变化 |
|---|---:|
| 乙烯 | 增加0.45个百分点 |
| C4烯烃 | 减少0.86个百分点 |
| 乙醛 | 增加3.62个百分点 |
| C4—C12脂肪醇 | 减少8.84个百分点 |
| 甲基苯甲醛和甲基苯甲醇 | 增加1.37个百分点 |
| 其他产物 | 增加4.26个百分点 |

增加项合计9.70个百分点，减少项合计9.70个百分点，反映的是六类产物内部份额重新分配，
不能据此证明某一种产物直接转化成另一种。
