# 项目术语与表述口径

本文件是当前项目唯一的术语权威表。正文、图表、方法文档和队友镜像出现不同写法时，
应先核对数学对象与题目原文，再以本表为统一表达依据；代码字段名可以为实现需要保留
英文，但不得反向改变论文术语。

## 核心对象与指标

| 统一术语 | 本文含义 | 允许简称 | 避免使用 |
|---|---|---|---|
| 催化剂组合 | 附件 1 中一个组合编号对应的整套实验条件，包括题面列出的催化剂组成、装料方式及石英砂等信息 | 上下文唯一时可写“组合” | 完整组合、完整催化剂组合 |
| 反应温度 | 附件记录的实验温度，单位为 ℃ | 温度 | 温度水平作为温度本身的同义词 |
| 乙醇转化率 | 题面定义的乙醇参与反应比例，单位为 % | 同一表格后续行可写“转化率” | 乙醇总体转化能力，除非是在机理解释中明确作定性描述 |
| C4 烯烃选择性 | 题面定义的 C4 烯烃在全部产物中的比例，单位为 % | 同一段已明确对象时可写“选择性” | C4选择性、C4烯烃选择性 |
| C4 烯烃收率 | 按题面公式“乙醇转化率 × C4 烯烃选择性 ÷ 100”计算的指标，单位为 % | 同一段已明确对象时可写“收率” | C4收率、目标产出 |
| 考察指标 | 第一、二问共同研究的乙醇转化率或 C4 烯烃选择性 | 指标 | 响应，除非专门讨论统计学响应变量 |
| 百分点 | 两个百分数直接相减所得的绝对差 | 无 | 百分比变化，若实际报告的是百分点 |

## 第一问方法术语

| 统一术语 | 本文含义 | 使用边界 |
|---|---|---|
| 相邻温度差 | 同一催化剂组合在相邻两个已测温度下的指标差 | 只描述离散已测温度，不代表连续变化率 |
| 一元最小二乘线性拟合 | 用最小二乘法对每个催化剂组合分别拟合考察指标关于温度的平均经验关系 | 方法或结果叙述优先写“拟合”；说明统计计算、截距、斜率、残差或图中回归线时允许写“线性回归”，但不得把经验直线写成严格规律或外推未测温度 |
| 逐点删除检验 | 每次删除一个观测点后重新计算斜率方向 | 只检查平均方向是否由单点决定 |
| 平均温度关系 | 一元最小二乘回归给出的已测区间平均变化方向和幅度 | 必须同时报告相邻温度的局部例外，不能外推未测温度 |

## 第二问方法术语

| 统一术语 | 本文含义 | 使用边界 |
|---|---|---|
| 组合—温度双因素加和分解 | 将同一主体数据表中的总体差异分为催化剂组合差异、温度差异和二者简单相加未解释变化 | 是描述性分解，不进行普通双因素方差分析的显著性推断 |
| 扣除温度总体差异后的组合偏差 | 某催化剂组合跨共同温度的平均值相对总体均值的偏差，即模型中的 αᵢ | 不简称“组合效应”，避免因果含义 |
| 温度平均偏差 | 同一批催化剂组合在某温度下的平均值相对总体均值的偏差，即模型中的 βⱼ | 不简称“温度效应”，避免因果含义 |
| 简单相加未解释变化 | 观测值减去总体均值、组合偏差和温度平均偏差后的剩余量，即模型中的 rᵢⱼ | 可能混合非加和变化、实验误差和未记录因素 |
| 组合与温度的非加和变化迹象 | 不同催化剂组合的升温幅度无法完全由固定组合偏差和温度平均偏差相加表示的现象 | 不称为已识别的交互效应，不作显著性或因果声明 |
| 结构保持型删除检验 | 每次删除一个催化剂组合的全部观测（整组删除）或一个温度的全部观测（整温度删除）后重新计算 | 不单独删除一个“组合—温度”单元；两个响应共 \(2\times(21+4)=50\) 次结构重算，不是50次实验 |

## 第三问方法术语

| 统一术语 | 本文含义 | 使用边界 |
|---|---|---|
| 实测候选域 | 满足相应温度情景约束、且在附件中具有真实观测的“催化剂组合—温度”单元集合 | 一般情景与严格低温情景分别定义；不包含插值点或任意连续温度 |
| 实测条件推荐 | 在相应实测候选域中按 C4 烯烃收率枚举得到的最高观测条件 | 是附件范围内的推荐，不称为连续温度全局最优，也不保证重复实验仍为第一 |
| 严格低温情景 | 只允许 \(T<350~^\circ\mathrm{C}\) 的实测条件比较情景 | 350 ℃不属于该候选域，不写成“350 ℃及以下” |
| 内部缺测核查 | 对附件已有温度标签中、位于各组合自身实测范围内部的缺测单元作辅助估计 | 只检查缺测候选是否可能改变实测推荐；预测值不作为观测或正式推荐 |
| 保形分段三次插值 | 在同一催化剂组合内部，按温度对缺测标签进行保形分段三次估计 | 不跨组合借用曲线，不外推，不搜索标签之间的任意连续温度 |
| 内部遮点 | 暂时遮去一个已知内部观测，再用其余观测预测该点并计算误差 | 所得误差是已有数据结构内的预测误差，不是实验测量误差或全域误差 |
| 观测差 | 两个附件观测值直接相减所得的差 | 在没有独立重复时不写成统计显著差异 |

## 第四问实验设计术语

| 统一术语 | 本文含义 | 使用边界 |
|---|---|---|
| 证据缺口 | 前三问因温度覆盖稀疏、无独立重复或缺少新增同温比较而不能回答的问题 | 不等同于模型错误；第四问实验用于补充证据，不以证明前三问正确为目标 |
| 区间加密 | 在两个相邻已测温度之间增加内部温度点 | 只提高局部温度分辨率，不自动确定连续最优点或完整响应面 |
| 独立重复 | 在相同催化剂组合、温度、配方和装料条件下重新执行一次实验 | 用于检查当前高值的局部可复现性；单个重复不足以建立显著性检验或全域误差分布 |
| 同温比较 | 在同一新增温度下分别测量两个催化剂组合并直接比较 | 只支持该温度下的局部比较，不推广为所有温度的组合排序 |
| 局部可复现性 | 当前最高观测条件在一次独立重复中能否得到相近表现 | 不简称为“模型稳定性”，也不等同于长期稳定性 |
| 职责充分性 | 五次实验是否分别覆盖区间加密、严格低温加密、关键高值复现和竞争组合同温比较 | 逐项删除只检查职责是否缺失，不证明实验点在数学上唯一最优 |
| 一次性方案 | 按 E1—E5 预先确定并共同执行的五次实验安排 | 是正文主方案，不与序贯备选合并成七次实验 |
| 序贯方案 | 仅在能够依据先行实验结果调整后续实验时采用的条件性安排 | 必须具备结果反馈权限；是备选执行政策，不替代一次性五次方案 |

## 验证与结论强度

| 统一术语 | 本文含义 | 使用边界 |
|---|---|---|
| 独立复算 | 用独立程序或独立计算路径重新读取输入并核对公式、排序和冻结结果 | 只验证计算一致性，不证明模型正确、化学因果或实验可重复 |
| 实验职责逐项删除检查 | 第四问依次移除 E1—E5 并检查哪类证据职责随之缺失 | 只检查职责冗余，不验证未来实验结果 |
| 描述性比较 | 对现有观测的方向、排序、差值或分解结果作直接比较 | 无独立重复时不得升级为显著性、置信区间或独立因果结论 |

## 表述与格式

- 数字与中文量词之间留空格，如“21 种组合”“84 个观测”。
- 采用“C4 烯烃”，在 `C4` 与“烯烃”之间留空格。
- 比较句必须同时给出对象、条件、指标和方向。
- “证明”只用于已经排除全部反例的命题；本项目当前检验通常写“支持”“表明”或
  “复算一致”。
- “最优”必须紧邻候选域和约束；当前第三问统一写“实测条件推荐”或“最高观测条件”，
  不写“连续温度全局最优”。
- “稳定性”必须说明对象和时间尺度；附件2只讨论本次观测时段内的相对稳定，第四问
  独立重复只讨论局部可复现性。
- 文献机理只写“可能解释”或“与数据相容”，不写成本题已经确认的反应路径。
