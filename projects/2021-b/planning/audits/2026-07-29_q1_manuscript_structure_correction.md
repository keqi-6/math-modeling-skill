# 2026-07-29 第一问正文结构纠错审计

## 1　触发原因

负责人指出当前 Markdown 草稿没有执行项目 skill 的论文正文规则，且正文格式与数学
建模论文要求不一致。复核确认该反馈成立。

## 2　失效稿的具体问题

失效稿位于 `paper/archive/2026-07-29_failed_structural_rewrite/`，主要缺陷如下：

1. 把内部写作流程拆成“数据说明、方法、结果、检验、图表落点”等平行文件，违反
   “执行顺序不等于论文目录”；
2. 读者必须在十个文件之间跳转，无法连续读取“问题—模型—公式—结果—检验—回答”；
3. 阶段状态、冻结信息、内部文献键和 LaTeX 转换门进入候选正文，违反评阅文本与项目
   管理信息分离规则；
4. 方法、结果和验证被人为割裂，公式未按“对象—关系—公式—作用”就地展开；
5. 图表只有内部落点清单，没有在正文论证位置实际出现；
6. 摘要只覆盖第一问，却采用最终摘要外观，容易被误认为可提交文本；
7. `README.md` 错误声称第一问 S12 已关闭，而同期交接和状态文件仍记录 S12 未关闭，
   形成项目权威冲突。

## 3　范式核对

本次分别核对两类来源：

- 全国大学生数学建模竞赛组委会的论文格式规范，用于确定摘要页、正文、目录、页数、
  附录、引用和支撑材料等提交底线；
- 教育部中国大学生在线公开展示的 2021 年 B 题论文 B007，用于观察同题获奖论文的
  实际阅读顺序和正文组织。

B007 前四页采用“摘要—问题提出—问题分析—模型假设—符号声明—模型建立”的连续
结构，并在各问模型章节中继续放置方法和结果。公开论文只用于提炼信息次序，不复制
原句、模型或结论。

## 4　修正决定

1. 失效稿整体归档，不删除；
2. `paper/drafts/` 只保留一份连续的 `正文草稿.md` 和一份不属于评阅正文的
   `README.md`；
3. 当前只完成第一问，故不设置第（2）至第（4）问、摘要、全文结论的空标题；
4. 第一问按“离散关系—线性概括—删点检验—附件 1 结果—附件 2 模型与结果—组成
   解释—检验—小结”连续展开；
5. 图件直接嵌入所支撑的段落，正文只写图号、现象、解释和边界；
6. 项目状态、证据路径、代码名和内部引用键不进入 `正文草稿.md`；
7. LaTeX 仍只在 Markdown 全文通过最终内容审计后生成。

## 5　阶段判定

第一问的方法决定、计算结果和用户理解确认仍然有效；本次回退只针对 S12 中的“论文
映射”部分。新连续正文完成结构、数字、图表和声明边界审计前，不得据此进入第二问，
也不得同步给队友。
