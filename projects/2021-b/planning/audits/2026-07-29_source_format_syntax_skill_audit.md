# Markdown与LaTeX源文件语法边界审计

## 触发原因

用户指出，Markdown文档和TeX源文件必须分别遵循各自语法。第二问文献稿曾把LaTeX引用
和数学定界写入Markdown，说明原有规则虽然在规划整理段中有所提及，但入口不够醒目，
建设责任和审计闭环也不完整。

## 通用修正

本次没有加入题号、数据或项目参数，而是建立跨项目规则：

1. 总Skill新增源文件语法边界，按扩展名规定允许结构、禁止混写和关闭前验证；
2. LaTeX建设模块规定TeX源文件只能使用LaTeX，并要求Markdown迁入时显式转换；
3. 内容规范说明Markdown草案只用Markdown，公式采用文字、Unicode或纯文本围栏；
4. 审计协议增加双向扫描，并要求检查Markdown渲染或LaTeX编译结果。

## 当前项目回修

第二问文献与方法定向稿已经：

- 把来源改为Markdown行内链接；
- 把短数学符号改为Unicode或行内代码；
- 把完整公式改为纯文本围栏；
- 删除依赖LaTeX或数学扩展解释器的语法。

## 验证

- Skill结构验证：通过；
- 项目Markdown的LaTeX结构、引用、交叉引用和数学定界扫描：无当前残留；
- TeX中的Markdown正文结构扫描：无当前残留；
- 修改未改变模型、数据、结果或声明边界。
