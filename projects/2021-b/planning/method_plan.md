## 第（1）问：分组离散趋势分析与受限线性概括

### 1. 负责人决定

2026-07-29，负责人确认采用以下最低充分方法：

- 附件1以21种催化剂组合各自的原始观测、相邻温度差分和变化类型为主体；
- 对每种组合的转化率和C4烯烃选择性增加简单线性斜率，概括已测范围内的平均方向和
  变化大小；
- Spearman秩相关系数只辅助概括温度排序与响应排序是否同向，不用概率数字裁决趋势；
- 不比较高阶多项式，不寻找每组“最佳函数”，不进行普通显著性推断；
- 附件2以真实时间点、首末变化、相邻时段变化和六类产物份额重分配为主体；
- 附件2的转化率和C4收率可增加简单线性下降速度；C4选择性保持波动描述，不强行拟合；
- 所有直线只概括已测范围，不预测未测温度、未测时间或其他催化剂。

这一路线属于描述统计、差分与趋势分析、Spearman秩相关和一元线性回归的组合。相关性
分析是辅助环节，不是第一问的全部模型。

### 2. 研究对象与输入

#### 附件1

对每个组合 `g` 和响应 `y` 分别计算。`g` 为A1—A14、B1—B7中的一个完整类别；`y`
分别为乙醇转化率和C4烯烃选择性；`T` 为该组合实际出现的摄氏温度。不同组合不能合并
拟合一条总体直线。

输入只允许来自当前严格模型接口中的组合、温度、转化率和C4选择性。配方描述字段不进入
本问回归，收率只作辅助解释。

#### 附件2

`t` 为20、70、110、163、197、240、273分钟的真实时间；核心响应为转化率、C4选择性
和由题面公式得到的C4收率。六类选择性作为总和为100%的整体份额处理。

### 3. 附件1离散关系主体

每个组合、每个响应按温度从低到高排列，保存：

1. 原始温度和响应；
2. 相邻响应差值，等于较高温度观测减较低温度观测；
3. 相邻平均变化速度，等于相邻响应差值除以温度差；
4. 首末总变化；
5. 所有相邻差值均为正、含局部下降、含持平或其他方向组合；
6. 每一个与总体方向不一致的具体温度区间。

相邻差分使用“百分点”作为转化率和选择性的绝对变化单位。图中连线只帮助读取离散关系，
不表示同一次连续升温过程。

### 4. 附件1受限线性概括

对每个组合和每个响应建立一条最简单的直线：

```text
响应概括值 = 截距 + 斜率 × 温度
```

正式展示把斜率换算为“温度每增加25摄氏度，响应平均改变多少个百分点”。同时计算：

- Spearman秩相关系数：概括温度排序和响应排序是否总体同向；
- 拟合决定系数：说明直线能够概括多少观测变化，只作描述；
- 平均绝对残差和最大绝对残差：说明原始点离直线有多远；
- 各原始点残差和全部局部反向区间。

不计算或不使用普通回归p值、相关性p值和“显著/不显著”标签。附件没有可识别的同条件
重复观测，残差不得称为实验误差。

#### 解释规则

- 斜率只说明已测范围内的平均方向和平均变化大小；
- 若任一相邻差分与斜率方向相反或为零，必须在同一结论中写出该区间，不能只报直线；
- 若斜率、首末变化和Spearman方向不一致，以原始点和相邻差分为准，并把直线标为不足
  以概括该组合；
- 决定系数较高也不能覆盖局部反向，不能证明因果关系；
- 不依据直线计算或推荐题目未测温度的响应。

这里不设置未经证据支持的统一决定系数阈值。是否“足以概括”由方向一致性、残差大小和
局部反向三类诊断共同说明，不把单个数字设为自动裁决器。

### 5. 附件2时间变化规格

对转化率、C4选择性和C4收率保存：

- 原始时间点和观测值；
- 首末绝对变化与相对变化；
- 每个实际时间区间的变化量；
- 每10分钟平均变化，仅用于比较不等长区间；
- 总体方向、中间波动和末段例外。

转化率和C4收率增加简单线性斜率，解释为本次实验已观测时段内每10分钟的平均变化，并
同时报告残差和局部变化。C4选择性不建立正式直线关系，保留范围、首末差异和波动描述。

六类产物选择性保存首末变化、范围、过程形态和份额平衡检查。六类份额不分别进行普通
相关或回归显著性检验。乙醛与C4、脂肪醇与C4的比例仅辅助观察相对份额，不表示转化量、
反应速度或直接反应路径。

### 6. 允许结论与禁止外推

允许回答：

- 每种组合在已测温度条件下两个响应的总体方向、平均变化和局部例外；
- 哪些组合可以被简单直线较好概括，哪些必须保留为离散关系；
- 本次350摄氏度实验中各核心响应和产物份额随时间怎样变化。

禁止回答：

- 未测温度或未测时间的预测值和最优点；
- 温度对响应的因果效应或化学反应机理；
- 把附件2推广为所有组合的一般时间规律；
- 把附件2认定为A3；
- 把拟合残差解释为随机实验误差；
- 把小样本概率数字作为关系存在与否的裁决。

### 7. 实现、验证与稳健性计划

S9必须冻结逐组合线性参数、Spearman系数、残差诊断、离散关系表、附件2时间概括和
图件清单。图上必须保留原始观测点；简单直线与观测连线在视觉上可区分。

S10独立验证至少包括：

- 从严格接口重新复算42条附件1直线和Spearman系数；
- 抽查斜率每25摄氏度的单位换算；
- 逐项核对局部反向区间没有被直线摘要遗漏；
- 复算附件2两条时间斜率、首末变化和六类份额闭合；
- 检查所有输出均未生成未测温度或时间的推荐。

S11至少检查逐次删去一个观测点后斜率方向是否改变，并比较斜率、Spearman方向和离散
分类是否一致。方向对单点敏感的组合必须降低结论强度，不能写成稳定规律。

### 2. 未采用候选

- 不采用组合特异温度直线作为第二问正式模型。它只对转化率显示额外留一收益，对

- 不进行普通完整交互显著性检验。每个“组合—温度”单元只有一个观测，完整交互与

A层回答温度变化方向、同温组合差异、具体排名和共同变化现象；B层回答组合差异、

完整组合影响以及二者非加和变化迹象。

所有“影响”只解释为现有实验域内的条件差异或关联。完整组合不得拆成配方成分的
独立作用，非加和剩余不得称为纯交互或随机误差，结果不得用于未测温度或新组合预测。

## 第二问S8数学规格

### 1. 规格职责

本节是第二问正式实现的唯一数学规格。S9代码只能实现本节，不得从S6候选脚本反向
改变方法。A层沿用已经验证的S5直接证据；B层新增固定组合与固定温度的加和分解。

### 2. 输入、研究单位与数据域

唯一输入为：

`output/data_audit/tables/cleaned_attachment1.csv`

两个响应分别计算，不把它们合成为未经定义的综合指标：

- `ethanol_conversion_pct`：乙醇转化率，单位为百分数；
- `c4_selectivity_pct`：C4烯烃选择性，单位为百分数。

主体域固定为250、275、300和350℃下共同出现的21种完整组合，共84个
“组合—温度”单元。组合编号是完整方案类别，不拆分配方字段。

325℃、400℃和450℃不进入B层分解：

- 325℃只在同时拥有300、325和350℃记录的10种组合中作配对补充；
- 400℃只在同时拥有350和400℃记录的19种组合中作配对补充；
- 450℃只报告A3从400至450℃的个案变化。

### 3. 符号

对任一响应单独计算：

- `i`：组合索引，取21种完整组合；
- `j`：共同温度索引，取4个温度；
- `y_ij`：组合`i`在温度`j`的观测响应；
- `grand_mean`：84个主体观测的总体均值；
- `combination_mean_i`：组合`i`跨4个共同温度的均值；
- `temperature_mean_j`：温度`j`跨21种共同组合的均值；
- `alpha_i`：组合`i`相对总体均值的固定差异；
- `beta_j`：温度`j`相对总体均值的固定差异；
- `fitted_ij`：加和结构给出的概括值；
- `r_ij`：观测值减去加和概括值的非加和剩余。

### 4. A层直接证据

A层继续采用S5已验证定义：

1. 每个共同温度下21种组合的均值、中位数、四分位数、范围和极值组合；
2. 三个相邻共同温区中同一组合的配对变化；
3. 由于300至350℃跨度为50℃，所有区间同时给出每25℃标准化变化；
4. 每个共同温度的降序排名、四温平均排名、名次范围和前后列出现次数；
5. 相邻共同温度排名的Spearman秩相关、平均绝对名次变化和最大名次变化对象；
6. 325℃、400℃匹配补充和A3的450℃个案。

A层不拟合未测温度，不计算普通显著性检验。

### 5. B层加和分解

#### 5.1　效应定义

按平衡主体域的样本均值直接计算：

```text
grand_mean = 84个y_ij的平均值

alpha_i = combination_mean_i - grand_mean

beta_j = temperature_mean_j - grand_mean

fitted_ij = grand_mean + alpha_i + beta_j

r_ij = y_ij - fitted_ij
```

采用和为零约束：

```text
21个alpha_i之和 = 0

4个beta_j之和 = 0
```

该参数化共有24个可辨识参数：1个总体均值、20个独立组合差异和3个独立温度差异。
程序可以保存全部21个`alpha_i`和4个`beta_j`，但必须核对其和为零。

#### 5.2　平方和

```text
SS_total =
所有单元的 (y_ij - grand_mean) 的平方和

SS_combination =
4 × 所有组合的 (combination_mean_i - grand_mean) 的平方和

SS_temperature =
21 × 所有温度的 (temperature_mean_j - grand_mean) 的平方和

SS_nonadditive =
所有单元的 r_ij 平方和
```

平衡设计下必须满足：

```text
SS_total =
SS_combination + SS_temperature + SS_nonadditive
```

三个描述性占比定义为各自平方和除以`SS_total`。占比之和必须为1。

#### 5.3　效应值的解释

- `alpha_i`为正：组合`i`跨四个共同温度的平均水平高于总体均值；
- `alpha_i`为负：低于总体均值；
- `beta_j`为正：温度`j`跨相同21种组合的平均水平高于总体均值；
- `beta_j`为负：低于总体均值；
- `r_ij`绝对值较大：该单元不能由固定组合差异与固定温度差异简单相加充分概括。

效应值的单位为百分点，平方和单位为百分点平方，占比无量纲。

### 6. 非加和剩余的报告规则

正式结果必须同时给出：

- `SS_nonadditive`及其占总差异的比例；
- 每个单元的`r_ij`；
- 每个响应中绝对剩余最大的若干单元；
- S5逐段增量范围和排名变化作为现实表现。

不得仅凭`r_ij`大小把某个单元判为数据错误，也不得把`r_ij`称为：

- 纯组合—温度交互；
- 实验随机误差；
- 测量误差；
- 显著或不显著效应。

允许称为“加和结构未解释部分”“非加和剩余”或“共同变化迹象”。

## 第三问S8数学规格

### 1. 输入与统计单位

唯一输入为`output/data_audit/tables/cleaned_attachment1.csv`。一行表示一个完整催化剂
组合在一个温度条件下的观测，主键为`catalyst_id + temperature_c`，追溯键为
`source_excel_row`。

对组合i在温度t的实测乙醇转化率记为Cᵢ(t)，C4烯烃选择性记为Sᵢ(t)，实测收率为：

```text
Yᵢ(t) = Cᵢ(t) × Sᵢ(t) ÷ 100
```

三个响应均以百分数记录，Y的数值单位为百分点。

### 2. D0实测域

一般情景实测域：

```text
D0_general = 附件1全部114个实测组合—温度单元
```

严格低温实测域：

```text
D0_low = D0_general中满足t < 350摄氏度的73个单元
```

两个情景分别按Y从高到低排序。排序相同时依次按组合编号和温度升序确定机器输出顺序，
但真实并列必须在解释层标明，不得用辅助排序制造性能差异。

D0负责正式推荐、次高实测单元、最高不同组合、领先差距和前列备选。正式推荐口径是
“附件1实测范围内的最高观测收率”，不是连续全局最优。

### 3. D1标签内插值域

题目数据中出现的温度标签集合固定为：

```text
T_label = {250, 275, 300, 325, 350, 400, 450}摄氏度
```

组合i的D1候选温度必须同时满足：

```text
t属于T_label
t没有出现在组合i的实测记录中
组合i的最低实测温度 < t < 组合i的最高实测温度
```

低温情景再要求`t < 350摄氏度`。按当前数据，一般与低温D1均只有11个325摄氏度单元：
A6—A14、B1和B2。

不搜索任意连续温度，不使用349.9摄氏度等人为逼近严格边界的数值，也不把A1、A2缺少
的400摄氏度或其他组合缺少的450摄氏度纳入D1，因为它们不在相应组合自身实测范围内部。

### 4. PCHIP插值

对组合i按温度排序的实测点记为`(tᵢⱼ, Yᵢⱼ)`。在相邻实测温度区间
`[tᵢⱼ, tᵢⱼ₊₁]`内令：

```text
h = tᵢⱼ₊₁ - tᵢⱼ
s = (t - tᵢⱼ) / h
```

分段三次Hermite表达为：

```text
pᵢ(t) = (2s³ - 3s² + 1)Yᵢⱼ
       + (s³ - 2s² + s)h dᵢⱼ
       + (-2s³ + 3s²)Yᵢⱼ₊₁
       + (s³ - s²)h dᵢⱼ₊₁
```

节点导数d按PCHIP的保形规则确定：相邻割线斜率异号或任一为0时，中间节点导数取0；
同号时取带区间长度权重的调和平均；端点使用单边保形导数。正式实现使用
`scipy.interpolate.PchipInterpolator(..., extrapolate=False)`，并以独立程序复算
11个输出。

PCHIP只生成D1辅助预测`Ŷᵢ(325)`。预测值必须带
`candidate_prediction_not_observation`状态，不得覆盖清洁数据或与D0观测混成同一证据
等级。

### 5. 两种情景的推荐规则

两种情景的正式推荐均来自对应D0排序：

```text
推荐 = arg max Yᵢ(t), 其中(i,t)属于对应D0
```

D1只回答“11个325摄氏度缺口按获批窄插值模型是否出现超过D0推荐的候选”。即使出现，
也只能标为待实验验证候选，不能替代D0正式推荐；当前候选审计显示不会改变低温推荐，
正式实现必须重新生成并核对。
