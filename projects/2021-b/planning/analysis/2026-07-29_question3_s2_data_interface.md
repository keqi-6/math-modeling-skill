# 第（3）问 S2 数据接口

- 状态：负责人已于2026-07-29确认，S2关闭
- 性质：当前第三问数据与候选域接口；不是模型决定、最优结果或论文正文
- 唯一输入：`output/data_audit/tables/cleaned_attachment1.csv`
- 追溯键：`source_excel_row`

## 1. 这一阶段固定什么

第三问要选择一个催化剂条件和温度。S2只固定程序以后可以读取哪些字段、每一行代表
什么，以及D0、D1、D2分别包含什么。它不计算哪一项最好，也不批准插值或新配方模型。

主统计单位是“完整催化剂组合—温度条件”。同一组合在多个温度下出现，不表示有多种
催化剂；同一条件没有独立重复实验，不能直接估计该条件的实验误差。

## 2. 唯一字段接口

| 职责 | 字段 | 含义与单位 |
|---|---|---|
| 追溯 | `source_excel_row` | 官方附件1中的Excel行号 |
| 组合身份 | `catalyst_id` | A1—A14、B1—B7中的一种完整组合 |
| 温度 | `temperature_c` | 摄氏度 |
| 收率输入 | `ethanol_conversion_pct` | 乙醇转化率，百分数 |
| 收率输入 | `c4_selectivity_pct` | C4烯烃选择性，百分数 |
| 优化目标 | `c4_yield_pct` | C4烯烃收率，百分点 |
| 配方追溯 | `catalyst_description`及解析配方字段 | 只描述已有组合，不自动取得独立决策变量身份 |

数据共有114行，核心字段没有缺失，“组合—温度”键没有重复。收率重新按
`转化率 × C4选择性 ÷ 100`核对，最大差为3.553×10⁻¹⁵个百分点。

## 3. 最小手算样例

A1在250摄氏度时：

```text
转化率 = 2.067169%
C4选择性 = 34.05%
收率 = 2.067169 × 34.05 ÷ 100 = 0.703871%
```

清洁表中的`c4_yield_pct`为0.703871%，与手算一致。这个例子只核对目标字段的算法，
不参与最优推荐。

## 4. D0：实测单元

D0由清洁表的114行直接组成。一般情景保留全部114行；低温情景只保留
`temperature_c < 350`的行。350摄氏度不得进入低温情景。

温度覆盖为：250、275、300和350摄氏度各21行，325摄氏度10行，400摄氏度19行，
450摄氏度1行。空白单元表示没有实验，不是收率为0。

D0能支持“已测条件中谁最高”的确定比较，但单次观测排名没有重复实验误差条，不能写成
未来实验中必然仍为第一。

## 5. D1：已有组合内的未测温度

D1保持组合身份不变，只讨论该组合最低与最高实测温度之间、但没有实际观测的温度。
为避免把外推伪装成插值，候选温度必须同时满足：

```text
组合属于现有21种完整组合
该组合最低实测温度 < 候选温度 < 该组合最高实测温度
候选温度不是该组合的实测记录
低温情景还要求候选温度 < 350摄氏度
```

S2不规定连续搜索精度或候选网格。温度控制精度属于后续模型和数学规格决定；在此之前，
D1只是一个权限层，不能运行正式优化。

若暂时只查看附件已有温度标签，11种组合在325摄氏度存在内部空格：A6—A14、B1和B2。
A1、A2没有400摄氏度记录，其他20种组合没有450摄氏度记录，但这些点超出各组合自身
最高实测温度，不属于D1插值。

D1取得正式推荐权限的前提是：专门针对组合内遮点的验证稳定超过简单基线，并能可靠
保持高收率候选排序。现有统一曲线审计没有通过这个门，因此当前D1权限仍为关闭。

## 6. D2：未测配方

D2指附件中没有出现的完整配方。清洁表能够描述现有组合的装料方式、Co/SiO2质量、
Co负载量、HAP质量、石英砂质量、是否含HAP和附件所列乙醇条件，但这些字段彼此混杂，
不是完整均衡的配方试验。

因此S2不把观测水平做笛卡尔积，不枚举“第22种配方”，也不把各字段的最小—最大范围
自动解释为连续可行域。D2目前没有经过实验确认的组合身份、响应值和安全可执行边界，
不能成为第三问正式推荐域，只能作为第四问待验证候选的概念接口。

## 7. 三层接口汇总

| 层次 | 候选身份 | 响应来自哪里 | 当前权限 |
|---|---|---|---|
| D0 | 114个实测组合—温度单元 | 附件1观测并按题面公式计算 | 可进入S5基线 |
| D1 | 已有组合自身实测区间内的未测温度 | 尚无观测，必须由获批模型预测 | 当前关闭 |
| D2 | 附件未出现的完整配方 | 尚无观测，且可行域未识别 | 仅作第四问待验证接口 |

## 8. 能够与不能够说明什么

这个接口能够保证实测值、插值预测和新配方设想不会混在同一张“最优”表里，也能保证
低温情景严格排除350摄氏度。

它不能证明D1存在可靠插值模型，不能证明D2中的任何配方可制备、安全或更优，也不能给
工业规模、长期稳定性、经济性或实验重复性结论。

## 9. 负责人确认内容

负责人确认S2，表示同意：

1. 使用上述唯一字段和“完整组合—温度”统计单位；
2. D0按真实记录定义；
3. D1只允许组合自身实测温度区间内插值，具体温度精度留到后续规格决定；
4. D2目前不枚举、不优化，只保留为第四问待验证接口；
5. 低温情景在所有层次都严格要求温度小于350摄氏度。

确认不等于批准D1模型、D2配方、最优结果、代码或论文文字。

S2关闭后进入S3文献导向。后续若证据要求改变统计单位、D1插值范围或D2身份边界，
必须重新打开S2并传播影响。
