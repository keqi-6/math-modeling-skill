# 第一问最小二乘与Theil–Sen候选方法比较

## 1　文档身份

本文是用户要求开展的补充候选评审，不是第一问当前方法权威，也不自动修改论文。现行
方法仍是“一元最小二乘线性概括 + 离散差分 + Spearman秩相关 + 留一稳定性”。只有负责
人明确决定采用新方法后，才重新打开数学规格、实现、验证和正文映射。

队友文档提出的候选方法为：将温度换算成“相对350℃的25℃单位”，取全部两点斜率的
中位数作为Theil–Sen斜率，并取响应减去斜率乘温度变量后的中位数作为截距。该定义与
[Sen原始方法论文](https://doi.org/10.1080/01621459.1968.10480934)及
[SciPy的joint实现](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.theilslopes.html)
一致。

## 2　公平比较口径

两种方法使用完全相同的输入：

- 21种完整催化剂组合，不删除A11；
- 每组实际存在的5至7个温度点，不插值；
- 分别拟合乙醇转化率和C4烯烃选择性，共42组关系；
- 斜率统一表示温度每升高25℃时响应改变的百分点数；
- 不报告普通显著性检验，不外推未测温度。

评价指标为：

1. 斜率方向是否一致；
2. 斜率数值和21种组合间排序是否接近；
3. 平均绝对残差、最大绝对残差和均方根残差；
4. 逐次删除一个温度点后，斜率方向是否改变。

最小二乘以残差平方和最小为目标，因此均方根残差天然有利；Theil–Sen以成对斜率中位数
抗衡少数极端点，不能期待它同时在所有误差指标上更小。比较的重点是两种概括是否改变
题目结论，以及稳健性收益是否足以抵消解释和拟合代价。

## 3　验证结果

候选程序共计算42组完整关系和228次Theil–Sen留一重算。独立脚本重新按定义复算42组
斜率，并用SciPy官方实现再次交叉核对；两项最大绝对差均为 8.882×10⁻¹⁶。验证全部通过。

| 指标 | 乙醇转化率21组 | C4烯烃选择性21组 |
|---|---:|---:|
| 两种方法斜率方向相同 | 21 | 21 |
| Theil–Sen斜率为正 | 21 | 21 |
| 留一后Theil–Sen方向改变 | 0 | 0 |
| 两种斜率排序的Spearman系数 | 0.9506 | 0.9117 |
| 斜率绝对差中位数，百分点/25℃ | 1.4179 | 0.2530 |
| 相对斜率绝对差中位数 | 21.57% | 6.14% |
| Theil–Sen的MAE更小 | 21 | 21 |
| Theil–Sen的最大绝对残差更小 | 0 | 0 |
| Theil–Sen的RMSE更小 | 0 | 0 |

Theil–Sen在转化率21组中有18组斜率低于最小二乘，在选择性21组中有15组较低。最大绝对
斜率差分别出现在B6转化率和A6选择性：

| 组合与响应 | 最小二乘斜率 | Theil–Sen斜率 | 差值 |
|---|---:|---:|---:|
| B6乙醇转化率 | 9.5929 | 6.5069 | -3.0860 |
| A6 C4烯烃选择性 | 5.0683 | 2.8700 | -2.1983 |

所有42组中，Theil–Sen的MAE都较低，但改善幅度中位数仅为：转化率0.1509个百分点、
选择性0.1269个百分点。与此同时，其最大绝对残差全部更大：增量中位数在转化率为
6.2144个百分点，在选择性为1.1686个百分点；RMSE增量中位数分别为1.4002和0.2429个
百分点。以转化率为例，Theil–Sen最大绝对残差与最小二乘之比的中位数为2.1243。

## 4　现象解释

两种方法都给出42组正斜率，而且各自留一后方向均不改变。因此，第一问最重要的方向性
结论不依赖采用哪一种直线概括，队友方法构成了有价值的稳健性佐证。

斜率大小并非完全相同，尤其是转化率。许多组合在高温端增长较快，最小二乘会让这些
合法观测参与整体平方误差折中；Theil–Sen则取成对斜率中位数，更接近“典型两点变化”
而不是“使所有点总体最贴近的平均直线”。本题数据审计没有发现应删除的错误点，所以
不能把高温端较大变化自动视为异常值并降权。

Theil–Sen的joint截距采用残差中位数，因此MAE略低并不等于整条线在所有意义下更贴合。
其42组最大绝对残差和RMSE全部更大，说明改善典型绝对偏差的同时，最偏离点离趋势线更
远。队友稿只报告MAE，若据此断言模型更优，会遗漏这一权衡。

## 5　候选充分性比较

| 维度 | 现行最小二乘 | Theil–Sen候选 |
|---|---|---|
| 题目职能 | 概括全部已测点的平均线性变化 | 概括全部两点斜率的中位变化 |
| 单点敏感性 | 较高，但现有留一检验方向均稳定 | 较低，现有留一检验方向也均稳定 |
| 方向结论 | 42组均为正 | 42组均为正 |
| 数值解释 | 平方误差意义下的总体直线 | 典型成对变化的稳健斜率 |
| MAE | 略高 | 42组均略低 |
| RMSE与最大残差 | 42组均更低 | 42组均更高 |
| 方法成本 | 已批准、已实现、已验证并写入草稿 | 需新增来源、公式、结果和验证解释 |
| 对现有结论的新增信息 | 主体结论 | 证明方向不依赖最小二乘估计方式 |

## 6　推荐

推荐保持最小二乘为正文中的线性概括，把Theil–Sen作为S11稳健性对照，而不是替换主体
模型。理由是：

1. 两种方法的42组方向完全一致，Theil–Sen没有纠正任何方向结论；
2. 现行最小二乘的228次留一检验已经表明方向不由单点主导；
3. 本题没有证据把某些合法高温观测视为粗差；
4. Theil–Sen略微降低MAE，却使42组RMSE和最大绝对残差全部增大；
5. 作为补充对照，它能以较低正文成本增强“结论不依赖斜率估计方法”的证据。

若负责人采用该推荐，后续只需把候选比较压缩为稳健性段落和必要结果，不替换现有公式、
42组主表或图。若决定用Theil–Sen取代最小二乘，则必须重新打开第一问S7—S12，重写
数学规格、全部数值结果、图表和验证，不能只替换模型名称。
