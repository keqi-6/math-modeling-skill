# 第2步数据审计、预处理与可视化方法论

## 负责人先掌握的五条规则

1. 原始附件保持不变；
2. 21种催化剂组合是完整类别，不拆成可以自由组合的成分；
3. 温度只使用题目给出的档位；
4. 不因某个点看起来奇怪就擅自删除或修改；
5. 每一步处理都必须能回到原始表逐项核对。

后文保留程序复核需要的技术名称，负责人不需要先记住这些名称。

## 1. 文档身份

- 状态：当前方法论权威，用户已确认并完成实现重构。
- 适用阶段：技术主线第2步。
- 输入权威：`data/附件1.xlsx`、`data/附件2.xlsx`。
- 实现：`src/data_audit/01_audit_and_visualize.py`。
- 独立复核：`src/data_audit/02_verify_audit.py`。
- 结果说明：`docs/data_audit/data_audit_report.md`。
- 边界：本文件规定怎样读、查、转换和展示数据，不选择四问的正式模型。

## 1.1 初学者阅读指南

“数据审计”不是马上做复杂统计，而是先确认手里的数据有没有被读错、改错或比较错。
本项目按以下顺序工作：

1. **先数清楚**：有多少表、多少行、多少组合、多少温度；
2. **再核对含义**：每一列是什么单位，空白究竟是缺失还是该对象本来就没有这个属性；
3. **只做确定转换**：例如补全Excel合并单元格中的组合编号、按题面公式计算收率；
4. **检查实验是否公平可比**：例如不同温度下测试的组合数量是否相同；
5. **标记可疑点但不擅自删除**：异常只是“值得查看”，不等于“数据错误”；
6. **由另一份脚本重新核算**：防止主脚本自己犯错又自己宣布正确。

贯穿本文件的阅读模板是：

`要检查的问题 → 小例子 → 本题做法 → 结果怎样解释 → 不能据此说明什么`

例如，325摄氏度只测了10种组合，350摄氏度测了21种组合。若直接比较两个温度的总体
平均值，差异既可能来自温度，也可能来自“被测试的组合换了一批”。因此后续优先比较
同一个组合在两个温度下的变化。这叫控制比较对象，不需要先掌握复杂统计学。

本步没有改变任何有效响应数值。所谓“预处理”主要是把原Excel结构变成机器可读表格，
同时保留原行号和原文字，保证每个结果都能追溯回去。

## 2. 总体原则

本步采用“原始数据不变、结构化数据可重建、诊断不等于处理、描述不等于推断”的原则。

证据链为：

`官方工作簿 → 原始字段读取 → 结构和语义审计 → 可逆结构化 → 派生变量 → 诊断表与图
→ 独立复核 → 用户确认`

任何异常规则、相似性距离、相关系数或图形趋势都不能自动触发删点、身份映射、因果结论
或模型选择。

## 3. 审计对象与统计单位

### 3.1 附件1

存在三个统计层次，不能混用：

1. 组合类别层：21种完整催化剂组合，每种组合的描述字段只计算一次；
2. 组合—温度层：114条实验观测，是主要响应数据；
3. 温度层：7个温度水平，但各温度覆盖的组合数量不完全相同。

配方描述变量之间的相关性只能在21种组合上计算，不能把同一组合随温度重复多次后计算，
否则会产生伪重复。这种相关性只诊断描述字段依赖，不把成分升级为独立因素。响应与温度
的趋势可在组合—温度层分析，但必须控制组合身份或逐组合展示。

### 3.2 附件2

附件2是同一次350摄氏度实验中的7个不等间隔时间点。时间点是纵向观测，不是7次独立
重复实验。因此不能把普通独立样本检验直接用于这7条记录，也不能从这一条序列估计所有
催化剂的一般失活分布。

### 3.3 温度域

共享数据接口记录7个已观测温度标签：

`{250, 275, 300, 325, 350, 400, 450}摄氏度`

这些标签用于描述D0观测覆盖、排序、绘图和严格温度约束。第三问后来确认采用分层候选
域：D0为已观测单元；D1只允许已有组合自身实测温度区间内插值，并须另经验证；D2未测
配方只作为第四问待验证候选。共享数据审计本身不批准D1的连续精度或任何预测模型。

## 4. 原始结构审计方案

### 4.1 文件级

- 计算文件字节数和SHA-256；
- 记录工作表名称、最大行列数；
- 检查意外工作表、空尾列、合并单元格和隐藏结构；
- 根目录原件与 `data/` 副本逐字节比较；
- 每次运行记录输入哈希、运行时间和软件版本。

### 4.2 字段级

对每个字段检查原始名称、单位、数据类型、缺失、唯一值、最小值、最大值和合法域。

| 字段 | 合法域或检查 |
|---|---|
| 温度 | 数值、正数，并核对题面实验水平 |
| 时间 | 非负、严格递增，同时保留实际间隔 |
| 转化率 | 0%至100% |
| 各类选择性 | 0%至100% |
| 质量 | 非负；没有HAP与数据缺失必须区分 |
| Co负载量 | 非负，以题面文字为准 |
| 附件所列乙醇条件 | 正数；保留附件的ml/min单位，不自行解释为浓度或流量 |

### 4.3 记录级

- 附件1检查“组合编号—温度”复合键重复；
- 附件2检查时间重复和顺序；
- 检查同一组合的配方说明是否始终一致；
- 检查合并单元格填充后，每条响应是否获得唯一组合标签；
- 用原工作簿行号作为永久追踪键。

### 4.4 代数一致性

- 六类产物选择性应合计为100%，报告实际闭合误差；
- C4收率用转化率和C4选择性独立重算；
- 以首行进行手算；
- 对全部记录比较机器公式结果，而不是只检查摘要数字。

## 5. 结构化预处理方案

### 5.1 合并单元格

只对组合编号和配方说明执行向下填充，因为这是Excel合并单元格的视觉语义。响应、
温度和时间不填充。若填充前没有上一个有效标签，脚本立即失败。

### 5.2 空列

附件1第11列完全为空。排除该列，但记录原工作簿仍有11列。不得用“删除空列”掩盖有效
字段的缺失。

### 5.3 配方文字解析

用明确模式提取Co/SiO2质量、Co负载量、HAP质量、石英砂质量和附件所列乙醇条件。解析失败时
立即报错，不静默返回缺失或猜测数值。

派生量定义：

- 活性催化剂质量 = Co/SiO2质量 + HAP质量；
- 总装填质量 = 活性催化剂质量 + 石英砂质量；
- Co/SiO2与HAP质量比仅在HAP质量大于0时定义；
- HAP质量分数 = HAP质量 / 活性催化剂质量。

A11没有HAP是配方事实，不是缺失；其质量比“未定义”属于结构性空值。后续模型若需要
该比例，不能简单把它插补成普通比例。

### 5.4 装料方式

当前实现依据官方附件的分组语义，把A1—A14编码为方式I，把B1—B7编码为方式II。该字段
不是根据响应反推出来的。完成门要求再次核对工作簿表头或题面说明，防止只凭编号字母
形成循环定义。

### 5.5 响应和派生量

原始响应全部保留，不标准化、不平滑、不舍入。C4收率只作为确定性派生变量增加：

`C4收率(%) = 乙醇转化率(%) × C4选择性(%) / 100`

标准化只允许在特定诊断中临时使用，例如附件2相似性距离；标准化值不能覆盖清洁数据。

### 5.6 缺失和异常

当前阶段不删除、不插补、不缩尾、不平滑，也不因选择性恰好闭合而调整分量。如果后续
发现明确录入错误，必须保存原值、新值、证据、影响范围，并由用户决定是否修正。

## 6. 异常诊断方案

全局1.5倍四分位距规则用于发现整个数据集中的极端响应；同温度稳健标准分数用于发现
相同温度下相对其他组合特别不同的响应。两者只用于筛查。

限制包括：

- 全局规则混合了不同温度和配方，高温高响应容易被标记；
- 同温度规则仍混合不同配方，不代表同质总体；
- 450摄氏度只有一个样本，不能进行同温度异常比较；
- 小样本下中位数绝对偏差可能不稳定或为0；
- 附件1未提供可识别的同条件重复观测，无法仅凭统计距离判定测量错误。

因此输出使用“flag”而不是“outlier removed”。没有现实误差证据时，删点不是默认方案。

## 7. 实验设计审计方案

### 7.1 覆盖与平衡性

建立“组合×温度”观测矩阵，统计每个温度和每种组合的观测数、最小温度、最大温度。
目的不是补齐不存在的数据，而是防止把不平衡覆盖造成的总体均值差异误认为温度效应。

### 7.2 因素水平与混杂

在21个组合类别层记录上计算配方描述水平频数和Spearman秩相关。它只用于检查描述字段
之间的依赖与混杂，不能识别因果方向、分离独立成分效应，或把描述量变成可重组的决策
变量。

本项目后续以21种完整组合类别和温度为研究对象，不设计第22种配方。原始及派生的配方
字段只用于解释、核验和局部受控比较，不与组合类别一起作为一组“独立因素”解释。

### 7.3 装料方式

先找数值配方完全相同、只有装料方式不同的匹配组，再在共同温度下计算配对差。它比直接
比较方式I和II总体均值更公平，但目前只有两组匹配配方，仍不能代表所有配方。

### 7.4 组合内温度趋势

每种组合独立按温度排序，记录Spearman相关、严格递增、非递减、严格递减和方向变化
次数。这只描述已测点，不证明连续单调、不定位真实拐点，也不支持测量范围外外推。

## 8. 附件2身份诊断方案

当前诊断把附件1在350摄氏度的每种组合表示为“乙醇转化率加六类产物选择性”。各维按
21个候选组合的标准差缩放，再计算附件2每个时间点到各候选的欧氏距离，并保留前5名。

这只是主动寻找用户所说的“强烈身份依据”，不是分类模型。确认身份至少还需要直接的
配方或批次证据、多种合理度量下稳定的唯一候选、相对第二候选的稳定间隔、对时间漂移
的解释，以及与测量误差相容的匹配精度。

当前只有单一距离定义。A3虽在7个时间点均排第一，但没有精确匹配，只能报告“数值上
最相似”，身份仍未知。

## 9. 可视化方案

### 9.1 总原则

- 图回答结构、趋势、分布或比较问题，精确值由CSV表承担；
- 颜色具有固定语义，并同时使用线型、点形或标签；
- 不使用三维、彩虹色阶、阴影和装饰性背景；
- 每种图保留PNG快速复核版和PDF论文候选版；
- 原始响应不平滑，连线只帮助读取同一组合的观测顺序；
- 图内“均值”“相关”“相似”等必须保留描述性边界。

### 9.2 图件职责与风险

| 图 | 数据层次 | 回答的问题 | 方法风险和使用边界 |
|---|---|---|---|
| 01温度覆盖热图 | 组合—温度 | 哪些条件测过 | 只表示有无观测，不表示性能 |
| 02配方描述热图 | 21种完整组合 | 描述字段如何随组合变化 | 列内标准化只用于显形；不代表独立因素 |
| 03响应分布 | 114条原始响应 | 范围、偏态和长尾 | 同组合多温度非独立；核密度只作视觉摘要 |
| 04温度响应 | 组合—温度 | 各曲线与方式均值 | 方式均值受不平衡和混杂影响，只作诊断 |
| 05组合小多图 | 每种组合 | 各响应随温度怎样变 | 三响应同为百分比，但现实含义不同 |
| 06收率热图 | 组合—温度 | 已测收率结构和空缺 | 空白是未测，不是0；不能代表连续最优 |
| 07选择性闭合 | 记录级 | 各分量是否合计100% | 浮点误差在容差内显示为0 |
| 08秩相关热图 | 114条记录 | 变量共同变化结构 | 配方重复和温度混杂，只用于发现候选关系 |
| 09附件2时间图 | 7个时间点 | 响应及组成怎样变化 | 不等间隔、单序列，堆叠图可能掩盖小分量 |
| 10高收率条形图 | 已测条件 | 离散观测基线 | 排名不是模型优化结果 |

### 9.3 原始与处理后数据的呈现

图03、04、05、07、08、09使用原始响应或确定性派生量；图01展示原始实验覆盖经过结构化
后的设计矩阵；图02展示从配方文字解析的描述字段并标注原值；图06和10展示题面公式派生的
收率。所有图都可通过 `source_excel_row` 回到原工作簿。

不另画内容完全重复的“清洗前/清洗后曲线”，因为本步没有改变响应值，两套曲线会完全
重合。正确对照应是原表—清洁表逐字段对账，而不是重复图片。

### 9.4 视觉验收

逐图检查中文与单位、图题和图例重叠、空白与0、颜色退化、PNG/PDF一致性，以及坐标范围
是否夸大差异。图进入论文后，还要在最终PDF实际尺寸下复查。

## 10. 独立验证方案

验证脚本不导入主审计脚本，独立读取工作簿和冻结CSV，检查记录数、组合数、复合键、
原表与清洁表行键、全部收率公式、选择性闭合、首行手算、A11特殊配方、两组匹配配方，
以及主产物路径和SHA-256。扩展后当前23项全部通过。

独立复核证明实现与关键规则一致，但不能替代用户对方法本身是否合理的审计。

## 12. 用户决定

用户已批准八项处理口径、M1—M7补强、产物保留/降级/归档方案以及7水平有序离散温度
域。第3步主分析严格使用21种完整组合、7个离散温度标签和三个核心响应；配方描述只作

## 13. 项目负责人需要看懂和审定什么

不要求项目负责人逐行检查Python代码，但需要能够回答以下问题：

1. 为什么21种组合必须作为完整类别，而不能随意拆成多个独立因素；
2. 为什么325、400和450摄氏度的覆盖不足会限制总体平均比较；
3. 为什么异常标记不能自动变成删点决定；
4. 为什么附件2的7个时间点不是7次独立重复实验；
5. 为什么A3“最相似”仍不足以证明附件2的催化剂身份；
6. 为什么收率必须除以100，以及手算样例是否正确；
7. 哪些处理改变了表格结构，哪些处理改变了观测值。

当前第7项的答案是：合并标签、解析文字、删除全空尾列和增加派生收率只改变数据表达；
没有一项处理改变、删除或插补原始有效观测值。
