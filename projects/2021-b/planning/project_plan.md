# 2021 CUMCM B题技术建模步骤清单

## 使用说明

本文件是项目“怎样把题做出来”的当前步骤权威。主线按技术依赖排列，不按论文目录
排列。重要题意解释、指标、假设、模型族、参数依据、验证命题和结论强度，由用户在
理解理由、替代方案与后果后决定；AI负责资料读取、候选比较、推导、实现、运行、复核
和整理。

三个反复出现的项目用词含义如下：

- 基线：不用复杂方法也能直接算出的参照结果；
- 冻结：经过核对并获确认后，暂不随意改动的阶段结果；
- 独立验证：换一种计算过程重新检查关键数字，而不是重复运行同一段程序。

状态标记：

- `[x]`：已有证据证明完成；
- `[ ]`：尚未完成；
- `[待确认]`：AI可准备候选，但必须由用户决定后才能继续。

每个实质步骤采用双完成门：

1. **技术完成门**：数据、计算、脚本、产物和独立复核达到要求；
2. **理解完成门**：AI按“问题—小例子—本题计算—结果—含义—限制”讲解，项目负责人
   能说明关键方法的用途与边界，并完成需要的人工作出决定。

技术完成不自动代表该步骤已经可以进入论文或成为后续权威。团队基础薄弱时，脚本成功、
术语堆叠和验证通过均不能替代通俗解释。

## 逐问工作规则

从这里开始不再让四问按同一阶段横向齐步推进。每次只打开一个问题，并完成：

`本问题意复核 → 本问已有证据 → 简单基线 → 候选方法讲解 → 用户选模 → 数学规格
→ 编程求解 → 独立验证 → 稳健性与边界 → 用户理解并确认 → 冻结`

其中“本问已有证据”不能只来自附件数据。若涉及团队不熟悉的领域背景、辅助变量、现实
机理、方法谱系、参数或评价依据，必须在基线前完成：

`本问题意与数据事实 → 本问文献导向调查 → 文献启发下的证据重审 → 本问基线`

文献必须同步到 `references/` 并标明阅读状态、支撑主张和限制；搜索结果和AI回答不能
替代原始来源。

后一问只继承已经冻结且与本问兼容的结论。尚未轮到的问题不提前要求用户决定模型、
基线、参数或实验设计。

## 每一小问的强制子阶段清单

此前只有一段通用流程，没有给每一问建立可勾选的子阶段、进入条件和关闭证据。这会使
“已经讨论过”被误当成“已经完成”，也无法阻止文献、选模、实现、验证和写作乱序。
从2026-07-29起，每一问都必须按下列编号维护状态；原题含两个情景或两个小部分时，还要
分别检查其输出和验证，不得用整问的一个“完成”标记掩盖遗漏。

| 子阶段 | 必须完成的动作 | 关闭证据 | 未关闭时禁止 |
|---|---|---|---|
| S1 本问题意 | 逐字核对本问对象、动作、量词、输入和输出 | 任务卡与用户确认 | 不得提出正式模型 |
| S2 本问数据接口 | 固定字段、统计单位、候选域、缺测和能力边界 | 唯一输入接口与手算样例 | 不得用未经批准字段求结论 |
| S3 本问文献导向 | 调查领域语义、方法谱系、参数和声明边界 | 来源记录与本问导向稿 | 触发文献门时不得先选模 |
| S4 本问证据重审 | 用文献和数据重新检查已有事实、冲突与不能回答之处 | 证据清单与禁止声明 | 不得把探索图直接升级为模型结论 |
| S5 简单基线 | 建立最透明、可手算的参照答案 | 基线定义、计算和局限 | 不得只展示复杂方法 |
| S6 候选与充分性比较 | 比较“无需新增模型”和可信候选，说明数据是否适用 | 候选表、适用条件、验证计划 | 不得把AI建议当成已选模型 |
| S7 用户方法决定 | 讲明替代方案、代价和结论强度，由负责人选择 | 交互日志中的明确决定 | 不得编写正式求解代码 |
| S8 数学规格 | 固定变量、关系、参数、约束、输出、接受标准和禁止外推 | 已批准规格 | 不得边写代码边改变问题 |
| S9 实现与求解 | 代码只实现规格，冻结机器可读结果和运行信息 | 源码、清单、结构化输出 | 不得从控制台或聊天抄结论 |
| S10 独立验证 | 用不同计算过程复核公式、关键数字和边界 | 独立验证产物 | 不得声称技术完成 |
| S11 稳健性与解释 | 检查结论对点、模型和边界的敏感性，解释现实含义和限制 | 稳健性证据与读者报告 | 不得升级为论文正式结论 |
| S12 人工复审、冻结与论文映射 | 负责人能解释方法和边界；冻结本问并登记正文落点 | 用户确认、冻结清单和声明映射 | 不得打开依赖本问的下一问 |

子阶段只能在真实依赖允许时合并执行，不能删除编号。若回退，必须写明回到哪个S编号、
哪些后续S编号失效。每问状态以本节下方的专用表为准，不能只用总项目阶段名表示。
