# Q5 多事件联合覆盖与最长连续区间 pilot 规格

实现标识：`Q5-MULTI-EVENT-CONTINUOUS-1.0`。本步骤保留正式 Q5 与原 Q4 不变，以 `docs/q5_longest_pilot.json` 中已经严格评价的 `7.7856 s` 多烟团方案为下界，定向搜索一个更长的三导弹同时全遮蔽连续分支。

## 1. 严格量词与目标

对已选事件集 `K` 和导弹 `j`，使用现有生产几何核

```text
Phi_j(t)=max_{P in V_j(t)} min_{k in K(t)}
         [dist(C_k(t),[M_j(t),P])-10].
```

这里先对烟团取 `min`，因而允许多枚烟团分别遮住目标的不同视角区域；不要求任一单云独立完整遮蔽。全局安全集合为

烟团索引 `k` 可以随 `t`、`j` 和目标表面点 `P` 改变。因此该量词明确允许如下连续接力：前一烟团单独完整遮蔽，随后前后两团各遮一部分并形成联合完整遮蔽，最后后一烟团单独完整遮蔽。它不同于更严苛且未采用的

```text
min_{k in K(t)} max_{P in V_j(t)}
         [dist(C_k(t),[M_j(t),P])-10] <= 0,
```

后一个式子才会要求某一枚烟团在每个时刻独立遮住全部目标。

全局安全集合为

```text
Omega_all={t:max_j Phi_j(t)<=0},
L_all=max_{[a,b] in components(Omega_all)}(b-a).
```

代理搜索也以“连续全覆盖节点串的时长”为第一排序键，覆盖节点总数、最弱时刻覆盖率和总覆盖率只是次级键。禁止将分离区间测度或平均覆盖率冒充最长连续区间。

## 2. 固定航迹多弹计划

一条平台计划固定同一个 `(theta_i,v_i)`，并选择零至三枚 `(tau,delta)` 事件。计划内相邻投放时刻必须相差至少 1 s，所有事件经 `q5.validate` 再次校验。不将不同航向或速度下的独立单弹候选拼成一架无人机方案。

本 pilot 先定向改造当前连续下界的 FY3 计划，再扩展至 FY2、FY4、FY5 的单平台换弹与任意两平台联合换弹。对只有一弹的 FY3 保留关键事件后允许追加两弹；对已满三弹的平台，固定其中两弹并重选第三弹。候选航迹包括：

- 当前 FY3 航迹及其确定性局部航向/速度格点；
- 当前连续区间右端附近的 `C3_surface_tube` 可达航迹；
- 解析服务驻留库中 FY3 的实际航向/速度种子。

这是对已知右端瓶颈的定向一平台/两平台拓扑搜索，不声称穷尽三平台联合换迹、五平台全部连续变量或所有事件拓扑。

## 3. 代理位集与严格复核

在基线最长区间左端到右端外扩区间上，默认以 `0.25 s` 节点和 `24 x 5` 圆柱表面网格生成事件位集。一枚烟幕弹的 mask 保留每个 `(t,j,P)` 是否被有限视线段命中；多弹联合为 mask 按位或，正好对应 `min_k`。

每条航迹用束搜索保留一至三弹计划，且最迟每完成一条航迹就输出事件数、当前最长代理串、已用时间和剩余预算。全局候选前若干名使用现有 `PROBE` 连续核求区间及根；代理全覆盖未通过严格核的候选一律不接受。

## 4. 预算、输出与主张边界

- 运行无随机数；航迹格点、时间节点、束宽和候选上限全部入档。
- 默认墙钟预算 60 s；超时前预留结果写入时间，并保留已完成的轨迹和严格候选。
- 输出是 Q5 工作 pilot，不覆盖 `docs/q5_result.json`、`docs/q5_implementation_report.md` 或 `output/q5/result3.xlsx`。
- 找到更长区间时，只声称得到新的严格可行下界；未提升不证明当前下界最优。
- 当前边缘实现会组合多枚烟团的部分角域覆盖，但仍以有限表面代理位集生成候选；严格评价才是接受依据。
