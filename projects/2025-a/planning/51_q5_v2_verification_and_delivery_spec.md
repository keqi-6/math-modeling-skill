# Q5_v2 验证与结果表交付规格

状态：已执行并通过。对象是 `docs/q5_v2_precise.json` 中的 13 枚弹候选；不覆盖原 Q5，不晋升 `.modeling/state.json`，不修改 Q1—Q4 与 `.obsidian`。

## 1. 验证对象与通过口径

E1 核对输入哈希、运动学回代、全部硬约束、非法输入拒绝、区间目标单位和独立有限视线几何 oracle。独立 oracle 只共享题面常数与表面采样点，不调用生产距离函数、可见性函数或烟团距离聚合函数。生产值与独立值的最大差异阈值为 `1e-8 m`。

E2 重新计算区间并集、交集及四项指标；记录 SCREEN 到 PRECISE 的差异，并采用逐导弹 `4e-4 s`、总和 `1e-3 导弹·s` 的工作收敛阈值。对 PRECISE 报告区间的内部和几何根端点使用 `1024×65` 加密表面作定向检查：内部裕量不超过 `5e-6 m`，几何根两侧保持正确符号，线性估计端点漂移不超过 `2.5e-3 s`。该检查不等价于全时域 DENSIFIED 漏岛证明。

结果表按官方模板写出，除字符串外所有有效单元格统一保留 6 位小数。写出后从投放点和起爆点反解投放时刻与引信，重新检查约束、单弹时长和完整方案 PRECISE 指标。反解空间残差阈值为 `2e-5 m`，表中单弹时长舍入残差为 `6e-7 s`，舍入方案与原方案的 `J_sum` 差异阈值为 `2e-4 导弹·s`。

## 2. 结构与现实轴

E3 复用已登记的逐弹、逐平台删除消融，并新增三类不变量：烟幕弹标签循环置换不改变物理裕量，烟幕弹排列不改变物理裕量，空资源退化为零时长。另用一个二点二烟团反例核对联合覆盖量词：每团烟幕都不能单独完整覆盖，但逐点取最小后可以联合完整覆盖。

E4 记为 `justified_not_triggered_working`。题面没有提供导引头探测概率、识别持续时间、烟雾浓度或实装散布数据，因此只验证题面理想物理机制方向与结论边界，不把几何遮蔽秒数宣称为真实部署成功率，也不虚构任意百分比灵敏度。

## 3. 输出与声明边界

输出为 `docs/q5_v2_validation_results.json`、`docs/q5_v2_validation_report.md`、`output/q5_v2/result3.xlsx` 和可中途查看的 `output/q5_v2/verification_checkpoint.json`。最终可支持“经当前 SCREEN 守卫、PRECISE 连续端点重建、定向 DENSIFIED 与独立 oracle 核对的高质量可行候选”。仍不支持连续域全局最优、已认证列定价、独立全时域 PRECISE/DENSIFIED 漏岛证明或现实作战有效性结论。
