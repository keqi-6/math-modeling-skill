# Q5 几何服务域、角域并集与平台可达域推导

状态：工作推导，不改变 `SPEC-Q5-WORKING-5.0`，不执行优化。基础数据、运动学和遮蔽量词均与 `planning/40_q5_geometry_audit_spec.md` 相同。

## 1. 记号与精确遮蔽集合

时刻 `t`，第 `j` 枚导弹位置为 `M_j(t)`。真目标圆柱记为 `T`，底面中心 `B=(0,200,0)`、半径 `R=7 m`、高度 `h=10 m`；圆柱几何中点

```text
Q = B + (0,0,h/2) = (0,200,5),
rho = sqrt(R^2+(h/2)^2) = sqrt(74) = 8.602325267... m.
```

第 `k` 个有效烟团球心为 `C_k(t)`，烟幕半径 `r=10 m`。对可见表面 `V_j(t)`，精确离散前的单导弹余量为

```text
Phi_j(t) = max_{P in V_j(t)} min_{k active at t}
           [dist(C_k(t),[M_j(t),P])-r].
```

完整遮蔽当且仅当 `Phi_j(t)<=0`。单个烟团对导弹 `j` 的精确全遮蔽球心集合为

```text
D_j(t) = intersection_{P in V_j(t)}
         {C : dist(C,[M_j(t),P]) <= r}.
```

它是所有有限视线段半径 `r` 邻域的交集。这个定义精确，但直接构造代价高。

## 2. 可证明的中点视线锥台充分域

固定导弹位置 `M`，令烟团球心写成

```text
C = M + lambda(Q-M) + e,       0 <= lambda <= 1,
```

其中 `e` 是相对中点视线同比例位置的三维偏移。对任意目标点 `P`，在线段 `[M,P]` 上取

```text
X_P(lambda)=M+lambda(P-M).
```

则

```text
dist(C,[M,P])
<= ||C-X_P(lambda)||
=  ||e-lambda(P-Q)||
<= ||e||+lambda rho.
```

因此

```text
||e|| <= r-lambda rho
```

是完整遮蔽整个圆柱（甚至包括不可见背面）的充分条件。得到安全服务域

```text
S_ball(M) = union_{0<=lambda<=1}
            Ball(M+lambda(Q-M), r-lambda rho).
```

由于半径随 `lambda` 线性变化，它也可写成

```text
S_ball(M) = conv(Ball(M,r), Ball(Q,r-rho)).
```

这是从导弹附近半径 `10 m` 截面逐渐收缩到目标中点附近半径

```text
r-rho = 1.397674733 m
```

截面的三维圆锥台/凸包。它不是一条中心线，而是有严格安全余量的体域。只在中心线上取点是该体域的过度退化采样。

## 3. 利用圆柱形状的更大充分截面

球包络条件 `||e||+lambda rho<=r` 忽略了圆柱的轴向结构。仍使用同比例见证点 `X_P(lambda)`，但直接最大化

```text
max_{P in T} ||e-lambda(P-Q)||.
```

将 `e=(e_x,e_y,e_z)`，`e_xy=(e_x,e_y)`。圆柱相对中点可写为

```text
P-Q=(R cos theta, R sin theta, z),  |z|<=h/2.
```

平方距离的最大值在圆周及上下端取得，解析式为

```text
G_lambda(e)
= ||e||^2 + lambda^2 rho^2
  + 2 lambda [R ||e_xy|| + (h/2)|e_z|].
```

所以更大的形状感知安全截面为

```text
E_lambda = {e : G_lambda(e) <= r^2},
S_shape(M) = union_{0<=lambda<=1}
             {M+lambda(Q-M)+e : e in E_lambda}.
```

必有 `S_ball(M) subset S_shape(M) subset D_j(t)`。`S_shape` 仍是严格充分域，不依赖圆柱表面网格；相对球包络，它允许利用“水平半径 7 m、半高 5 m”的方向差异。

失效边界：这个证明使用整个闭圆柱，因而不会产生漏判的假全遮蔽，但可能舍弃依靠有限线段最近点改变、仅覆盖可见面或多烟团拼接才可行的球心。

## 4. 导弹视角下的角域表述

令

```text
c = C-M,              d=||c||,
u_C=c/d,
p=P-M,                L_P=||p||,
u_P=p/L_P.
```

有限线段距离的精确表达为

```text
s*(P,C)=clip(c dot u_P, 0, L_P),
dist(C,[M,P])^2 = ||c-s*u_P||^2.
```

若烟团位于所有目标点之前，即 `0<=c dot u_P<=L_P`，则遮蔽条件化为

```text
angle(u_C,u_P) <= beta(C),
beta(C)=asin(r/d),              d>=r.
```

若 `d<r`，导弹位于烟团球内，所有出射方向均被覆盖。若投影超过目标端点，则必须回到上述有限线段公式，不能只使用球冠。

定义真目标在导弹单位视球面上的角轮廓

```text
K_j(t)={u_P : P in V_j(t)}.
```

一个位于目标之前的烟团对应球冠

```text
A_j(C,t)={u : angle(u,u_C)<=beta(C)}.
```

多个烟团完整遮蔽的精确角域条件为

```text
K_j(t) subset union_{k active} A_j(C_k(t),t),
```

并对不满足“烟团位于目标之前”的边界点使用有限线段端点修正。这个表述直接保留了审计中验证的空间拼接：不存在“必须有一个烟团独立覆盖整个目标”的要求。

### 4.1 等价的二维透视平面与烟团阴影椭圆

球面角域还可精确投影到二维。以导弹 `M` 为投影中心，令

```text
n=(Q-M)/||Q-M||,
L=||Q-M||,
Pi={Y : n dot (Y-M)=L},
```

即过圆柱中点 `Q`、法向指向目标的像平面。目标点 `P` 的中心投影为

```text
Y(P)=M + L(P-M)/(n dot (P-M)).
```

因为圆柱 `T` 是凸集，从外点 `M` 张成的视锥 `cone(T-M)` 也是凸锥，其与平面 `Pi` 的交

```text
K_j^Pi(t)=Pi intersection cone(T-M_j(t))
```

是二维凸目标投影区域。它与“所有能击中圆柱的视线方向”一一对应。

把坐标原点暂移到 `M`。烟团球心向量为 `c=C-M`，`d=||c||>r`，像平面点向量为 `y=Y-M`。一条视线落入烟团球的无限射线影锥当且仅当

```text
c dot y > 0,
(c dot y)^2 >= (d^2-r^2)||y||^2.
```

在仿射平面 `n dot y=L` 上，这是一个二次不等式，其边界是椭圆。记对应闭椭圆区域为 `E_jk^Pi(t)`。若 `d<=r`，导弹位于烟团球内，整个像平面方向均被覆盖。

当烟团沿这些方向位于目标首次交点之前时，多烟团完整遮蔽精确等价于

```text
K_j^Pi(t) subset union_k E_jk^Pi(t).
```

若某个烟团接近或越过目标，椭圆只表示无限射线命中，必须再用有限线段投影参数检查“命中发生在目标之前”；这与第 4 节的端点修正规则相同。

因此 G2 不需要在三维圆柱表面做均匀点集覆盖，而可成为二维连续几何：

1. 解析/自适应构造凸目标投影边界；
2. 为每个有效烟团构造阴影椭圆；
3. 检查目标投影是否被椭圆并集覆盖；
4. 若失败，返回最深未覆盖点及负责的目标视线；
5. 把该视线作为新切割，而不是全局加密整个圆柱网格。

椭圆并集的连续证书可由二维排列结构完成：候选缺口拓扑只会在目标投影边界、椭圆边界、椭圆—目标交点和椭圆—椭圆交点处改变；在每个排列单元取一个内部点即可判断该单元是否未覆盖。数值实现仍须对近切和重合椭圆保留有限线段 oracle 复核。

## 5. 指定时刻的平台烟团可达域

平台 `i` 初始位置为 `O_i=(O_ix,O_iy,z_i)`。在观察时刻 `t`，设烟团年龄

```text
a=t-t_e,       0<=a<=min(20,t),
t_e=t-a.
```

引信时间为 `delta`，投放时刻 `tau=t_e-delta`。物理约束给出

```text
0<=delta<=delta_max(i,t_e),
delta_max(i,t_e)=min(t_e,sqrt(2 z_i/g)).
```

对单次事件，航向可取任意水平角、速度 `v in [70,140]`。烟团球心满足

```text
C_xy = O_i,xy + v t_e h(theta),
C_z  = z_i - 0.5 g delta^2 - w a,
w=3 m/s.
```

所以固定 `(t,a)` 的可达截面是水平环带与竖直区间的直积：

```text
70(t-a) <= ||C_xy-O_i,xy|| <= 140(t-a),
z_i-0.5 g delta_max^2-wa <= C_z <= z_i-wa.
```

全单事件可达域为

```text
R_i(t)=union_{0<=a<=min(20,t)} R_i(t,a).
```

这一定义消除了固定烟龄集合 `(0.5,2,5,9,14,19)`：烟龄 `a`、引信 `delta` 和速度 `v` 都应作为连续几何变量，只在求交后自适应离散。

当前题目模型只要求爆炸点不低于地面；烟团形成后的下沉中心可低于地面。若以后加入地面截断或地形，`R_i(t)` 的下边界必须重建，不能沿用本式。

## 6. 单平台—单导弹全服务求交

平台 `i` 在时刻 `t` 能用一个烟团完整服务导弹 `j` 的安全充分条件是

```text
F_ij^ball(t)=R_i(t) intersection S_ball(M_j(t)) != empty,
```

或使用更大的形状感知域

```text
F_ij^shape(t)=R_i(t) intersection S_shape(M_j(t)) != empty.
```

求交变量仅为

```text
(a,delta,v,theta,lambda,e),
```

并受解析等式/不等式约束。这里不需要先枚举表面点、烟龄、视线比例和横向偏移。一个求交解可直接恢复

```text
t_e=t-a,
tau=t-a-delta,
heading=atan2(C_y-O_iy,C_x-O_ix),
v=||C_xy-O_i,xy||/(t-a).
```

因此它既是几何证书，也是物理决策的构造式。

### 6.1 球包络服务域的闭式成员判定

给定一个实际烟团中心 `C`，判断它是否属于 `S_ball(M)` 不需要枚举 `lambda`。记

```text
y=C-M,
d=Q-M.
```

对某个 `lambda`，球截面成员条件为

```text
||y-lambda d||^2 <= (r-lambda rho)^2.
```

移项得到关于 `lambda` 的二次函数

```text
F(lambda)=A lambda^2+B lambda+C0,
A=||d||^2-rho^2 > 0,
B=2(r rho-y dot d),
C0=||y||^2-r^2.
```

其约束最小点为

```text
lambda* = clip((y dot d-r rho)/(||d||^2-rho^2), 0, 1).
```

于是

```text
C in S_ball(M)  iff  F(lambda*)<=0.
```

这是一条网格无关、常数复杂度的全遮蔽充分证书。对一个已经确定的烟团事件，代入随时间变化的 `M_j(t)` 和 `C_k(t)` 即可定义

```text
f_jk^ball(t)=F_jk,t(lambda*_jk(t)).
```

在烟团活动区间内，`f_jk^ball(t)<=0` 的连通分支就是“该烟团单独完整服务导弹 `j`”的安全连续区间。`M_j(t)` 为线性运动，`C_k(t)` 在爆炸后为竖直线性下沉；所以该函数分段光滑，只在 `lambda*` 投影到 0 或 1 的切换处改变表达式，适合直接求根，不需要固定时间网格。

形状感知域也可作一维成员判定：令 `e(lambda)=C-M-lambda(Q-M)`，计算

```text
H(lambda)=G_lambda(e(lambda))-r^2,
```

并在 `[0,1]` 上求最小值。它没有上述简单二次闭式，但仍只是有解析导数的一维问题，并且每个负值都保持严格充分性。

### 6.2 可达环带与球截面的解析相交条件

固定 `(t,a,lambda)`，令

```text
t_e=t-a,
S=M_j(t)+lambda(Q-M_j(t)),
r_lambda=r-lambda rho.
```

平台可达截面的水平半径区间和竖直区间记为

```text
[q_min,q_max]=[70 t_e,140 t_e],
[z_min,z_max]=[z_i-0.5 g delta_max^2-wa, z_i-wa].
```

令 `d_xy=||S_xy-O_i,xy||`。服务球心 `S` 到水平环带的最短距离为

```text
D_xy = q_min-d_xy,   d_xy<q_min,
       0,             q_min<=d_xy<=q_max,
       d_xy-q_max,    d_xy>q_max.
```

到竖直区间的最短距离同理为

```text
D_z = z_min-S_z,      S_z<z_min,
      0,              z_min<=S_z<=z_max,
      S_z-z_max,      S_z>z_max.
```

因此固定截面相交当且仅当

```text
D_xy^2+D_z^2 <= r_lambda^2.
```

最终平台—导弹安全服务可达性缩减为二维连续判定

```text
g_ij^ball(t)
= min_{0<=a<=min(20,t), 0<=lambda<=1}
  [D_xy(t,a,lambda)^2+D_z(t,a,lambda)^2
   -(r-lambda rho)^2].

F_ij^ball(t) nonempty  iff  g_ij^ball(t)<=0.
```

一旦获得 `(a*,lambda*)`，取环带与竖直区间中离 `S` 最近的点即可构造烟团 `C`；随后用第 6 节公式恢复 `v,theta,delta,tau`。因此这个二维问题不仅判断存在性，还返回可执行事件。与旧生成器相比，它连续覆盖全部合法烟龄、视线比例、速度、航向、引信和三维安全偏移。

### 6.3 固定航迹下的服务判定

若先固定平台航向 `h` 和速度 `v`，爆炸时刻 `t_e=t-a` 的水平坐标不再是环带，而是单点

```text
X_i,xy(t,a;h,v)=O_i,xy+v(t-a)h.
```

只需将上式的 `D_xy` 替换为

```text
D_xy=||X_i,xy-S_xy||,
```

竖直部分仍取到可达引信区间的距离。于是得到

```text
g_ij^ball(t;h,v)
=min_{a,lambda}[D_xy^2+D_z^2-(r-lambda rho)^2].
```

这个函数回答：“沿既定航迹，在时刻 `t` 是否存在一枚合法干扰弹，其烟团能单独完整服务导弹 `j`。”它适合先筛航迹再生成事件，也能解释某条航迹究竟在哪些时间段具有物理服务能力。

必须注意：`g_ij(t;h,v)<=0` 在每个时刻分别允许选择不同炸弹参数；它描述航迹服务包络，不代表一枚固定炸弹能自动覆盖整段时间。连续窗口仍须对同一枚炸弹的固定 `(tau,delta)` 使用 6.1 节的 `f_jk(t)` 正向求服务区间。

## 7. 同一平台多弹的固定航迹耦合

单事件可达不代表三枚弹能由同一平台执行。平台 `i` 的所有爆炸点水平坐标必须满足同一航向、同一速度：

```text
C_k,xy-O_i,xy = v t_e,k h,       k=1,2,3.
```

等价的跨事件约束为

```text
cross2(C_k,xy-O_i,xy, C_l,xy-O_i,xy)=0,
dot(C_k,xy-O_i,xy, C_l,xy-O_i,xy)>=0,
||C_k,xy-O_i,xy||/t_e,k
=||C_l,xy-O_i,xy||/t_e,l=v in [70,140].
```

此外按投放时刻排序后

```text
tau_{k+1}-tau_k >= 1 s.
```

因此正确顺序应为：先在各时刻构造服务域与单事件可达交集，再按上述严格共线—等比例条件把事件连成平台轨迹。不能先独立挑三个覆盖最好的烟团，再事后强行赋给同一平台。

## 8. 三导弹与多烟团的三种几何层级

### 8.0 三导弹共享的目标包络核心

由于任意目标点满足 `||P-Q||<=rho`，任何满足

```text
||C-Q|| <= r-rho = 1.397674733 m
```

的烟团都有

```text
||C-P|| <= ||C-Q||+||Q-P|| <= r.
```

目标点 `P` 本身是每条有限视线段的端点，所以该烟团不依赖导弹位置就能完整遮蔽圆柱。于是

```text
Ball(Q,r-rho) subset intersection_j D_j(t)
```

是三导弹共享的全遮蔽核心。

五个平台初始水平位置到 `Q_xy=(0,200)` 的距离及以 140 m/s 到达所需最短时间约为：

| 平台 | 水平距离/m | 最短时间/s | 60.366 s 内可达 |
|---|---:|---:|---|
| FY1 | 17801.12 | 127.15 | 否 |
| FY2 | 12059.85 | 86.14 | 否 |
| FY3 | 6800.00 | 48.57 | 是 |
| FY4 | 11146.30 | 79.62 | 否 |
| FY5 | 13184.84 | 94.18 | 否 |

因此在共同导弹时间域内，只有 FY3 可能把烟团水平中心送入该核心。即使水平位置恰好通过 `Q`，烟团以 3 m/s 竖直下沉，在直径 `2(r-rho)` 内的最长驻留也只有

```text
2(r-rho)/w = 0.931783155 s.
```

所以目标包络核心是强而短的共同服务机制，不能单独解释几十秒连续遮蔽。长窗口必须主要依赖：远离目标的导弹视线服务域、多个烟团对同一角轮廓的空间拼接，以及不同炸弹的时间接力。

### G0：一枚全服务烟团分配基线

每枚导弹在每个时刻至少分配一个落入 `S_ball` 或 `S_shape` 的烟团。优点是每个服务关系都有解析证书，最容易构造和解释；缺点是排除了多个部分烟团联合覆盖同一导弹的方案。

适用假设：候选库中存在足够多的单云完整服务事件。失效条件：长时段只能依靠空间拼接，或三导弹服务域与平台可达域不允许这种一对一分配。

### G1：形状感知完整服务域

使用 `S_shape` 替代球包络锥台，在保持充分性的同时扩大安全候选域。它仍不表达部分覆盖并集，但不会依赖表面网格。

适用假设：完整服务事件仍是主要构件。失效条件与 G0 相同，但保守损失更小。

### G2：精确角域球冠并集

将所有可达烟团映射为每枚导弹视球面上的球冠，要求覆盖完整角轮廓 `K_j(t)`。对接近或越过目标端点的烟团切回有限线段判据。

优点：保留部分烟团空间拼接，是与题意最一致的候选层；缺点：需要处理球冠并集的连续边界、端点裁剪以及固定轨迹跨时刻耦合。

适用假设：烟团按题目作为完全不透明球体，且视线遮蔽是识别判据。失效条件：引入光学厚度、透过率、风场形变或非球形烟幕时，球冠模型必须更换。

三层均使用相同导弹轨迹、平台运动、烟团参数、目标和最长连续全遮蔽指标。G0 是可解释基线，G1 是安全扩大，G2 是最终应采用的主候选域；不存在用不同数据或不同目标制造优劣的问题。

## 9. 连续时间证书与节点切割

对固定决策，每个活动区间内 `M_j(t)` 和 `C_k(t)` 连续，有限线段距离、对烟团取最小、对表面取最大仍连续。事件爆炸和失效时刻必须作为显式分段边界。

一般距离函数有保守 Lipschitz 界

```text
|d(C(t),[M(t),P])-d(C(s),[M(s),P])|
<= (||C'||+||M'||)|t-s|
<= (3+300)|t-s|.
```

min/max 不增大该界，所以若一个节点的严格余量为 `-eta`，仅凭这个通用界只能证书半径 `eta/303`，通常很小。它适合作为绝对安全兜底，不适合作为主时间步长。

实际实现应对当前最坏表面点、负责烟团和内点投影解析求导，得到局部小得多的界；一旦最坏点、负责烟团或投影分支切换，就加入切割节点。这样连续性检查由几何事件驱动，而不是固定 `2 s` 网格。

## 10. 对下一版候选生成器的直接约束

下一版不得再以固定烟龄、固定视线比例、固定横向/竖直偏移作为主候选域。正确链路为：

```text
全时间域 t
 -> 构造三导弹 S_ball / S_shape 与角轮廓 K_j(t)
 -> 与五平台 R_i(t) 求交
 -> 生成带解析恢复量的服务事件
 -> 用固定航迹耦合连接同平台事件
 -> 先跑 G0/G1 证书基线
 -> 再用 G2 球冠并集补充空间拼接
 -> 只对入围拓扑调用连续严格评价核
 -> 在最坏时间/表面/球冠缺口处自适应切割。
```

如果 `R_i(t) intersection S_shape(M_j(t))` 为空，只能说明“该平台在该时刻没有单云完整服务证书”，不能说明多个部分烟团联合覆盖不可行。只有 G2 连续角域与完整物理约束均闭合后，才能讨论当前有限域内的不可行性。

## 11. 当前可接受主张

可以主张：

- 中点视线不是单线启发式，而有非零截面的解析全遮蔽充分域；
- 形状感知截面给出比球包络更大的网格无关安全域；
- 单事件平台可达烟团域可按烟龄连续参数化；
- 多烟团联合全遮蔽在导弹视角下是球冠/有限线段覆盖并集；
- 固定航向速度通过跨事件共线与距离—爆炸时间等比例约束精确表达。

暂不能主张：

- `S_ball` 或 `S_shape` 是单烟团全遮蔽的必要条件；
- G0/G1 未找到方案意味着物理不可行；
- 有限球冠节点覆盖等于连续角轮廓覆盖；
- 当前推导已给出几十秒方案或全局上界。
