# Q5_v2 题意主模型与分解求解器工作规格

状态：工作分支技术闭环已完成；当前候选已通过工作级 E1—E3，E4 记为有依据的不触发，并已完成 6 位小数结果表舍入回读与队友讲解稿。原 `Q5`、`src/q5/`、`docs/q5_*` 和 `output/q5/` 保持不变；本分支只在 `q5_v2` 命名空间内推进。该状态不等于原 Q5 被覆盖，也不等于需要用户通读复述的正式 S6 人类验收已经完成。求解器复杂度与全文角色的收束决定见 `planning/49_q5_v2_scope_and_manuscript_chain_decision.md`。

## 1. 问题定义与计量口径

题面要求多枚烟幕干扰弹对真目标的有效遮蔽时间尽可能长，并明确不同烟幕弹形成的遮蔽可以不连续。因此，Q5_v2 的题意主目标是逐导弹有效遮蔽时间集合的总测度，而不是三枚导弹同步遮蔽集合的最长连续分量。

对导弹 `m in {1,2,3}`，定义严格完整遮蔽集合

```text
Omega_m = {t : 对导弹 m 在时刻 t 可见的每个真目标圆柱表面点，
                 至少存在一团活跃烟幕与该导弹到该点的有限视线段相交 }。   (1)
```

这里的“至少存在”可以随表面点改变，所以允许多烟团分别遮挡不同表面区域并联合形成完整遮蔽。烟幕弹的导弹标签不参与物理过滤；每一团活跃烟幕都进入每枚导弹的评价。

四项指标统一定义为

```text
J_sum  = sum_m measure(Omega_m),                              单位：导弹·s；
J_fair = min_m measure(Omega_m),                              单位：s；
J_all  = measure(intersection_m Omega_m),                     单位：s；
L_all  = max_{I in components(intersection_m Omega_m)} |I|,   单位：s。   (2)
```

同一导弹下必须先对所有烟幕弹及其联合覆盖形成的时间集合取并集，任何重叠时段只计一次。`J_sum` 的跨导弹相加是题意主评分，不能表述为现实时间轴上保护目标的物理秒数。

## 2. 多目标职责

正式题意结果采用严格词典序

```text
maximize (J_sum, J_fair, J_all, L_all).   (3)
```

其中只有 `J_sum` 是第一目标；后三项只在不降低已解析的前级值时破平。数值容差只用于判断两个计算值是否不可分辨，不授权牺牲前一级目标。

另输出非支配解集，用于展示题意成绩与作战鲁棒性的交换关系。若后续需要在 `J_sum` 允许损失一定比例的条件下选择更鲁棒方案，损失阈值必须由单独的人工决定给出，不能在代码中硬编码。

## 3. 不变的物理与约束

- 五架官方无人机，每机航向和速度在其全部投放中共享，速度范围沿用题面；
- 每机至多三枚烟幕弹，相邻投放时刻至少间隔 `1 s`；
- 弹体运动、起爆点、烟团半径、有效期和下沉速度沿用现有严格物理核；
- 导弹轨迹、真目标有限圆柱、可见表面和有限视线段判据不变；
- 连续时间严格评价量为

```text
g_m(t) = max_{P in V_m(t)} [ min_{k in A(t)} d(C_k(t), [M_m(t),P]) - R_s ],
Omega_m = {t : g_m(t) <= 0}.                                  (4)
```

式中 `V_m(t)` 是导弹 `m` 在时刻 `t` 的可见圆柱表面，`A(t)` 是全部活跃烟团，`C_k(t)` 是烟团球心，`R_s` 是烟团半径。该式明确保留多烟团联合覆盖：不同表面点可以由不同烟团取得内层最小值。

## 4. 方法角色

- `primary_model`：式（1）—（4）的连续时间、多烟团联合完整遮蔽模型。
- `primary_solver`：确定性平台完整计划库、受限 MILP 组合选择、incumbent-preserving 的原变量确定性精修，以及严格连续时间复算。MILP 只承担 Q5 新增的平台计划组合，不取代 Q1—Q4 已建立的物理候选、严格筛选、原变量精修和独立复核主链。
- `auxiliary_validator`：现有 Q5 严格几何评价器，只读复算选定方案的 `Omega_m`、四项指标、约束余量和网格加密差异，不产生另一套正式答案。

随机算法不得承担主问题的唯一组合选择或全局最优性结论。当前实现不把启发式扰动包装成全局定价器，也不把离散表面/时间节点上的 MILP 最优包装成连续原问题最优。

## 5. 平台计划列

一列 `c` 表示某架无人机 `i` 的完整计划：

```text
q_ic = (heading_i, speed_i,
        release_i1, fuse_i1, ..., release_iK, fuse_iK),  0 <= K <= 3.   (5)
```

计划列构造时已经满足同机共享航迹、速度范围、非负投放/引信、起爆高度、容量和 `1 s` 间隔。每列预计算离散系数

```text
a_icmnp = 1  当且仅当列 c 中至少一团烟幕在时间节点 n
                  截断导弹 m 到可见表面点 p 的有限视线段。             (6)
```

系数按表面点保存，不能只保存“单列是否完整遮住整根圆柱”。因此两列各自仅覆盖部分表面时，主问题仍能识别它们的互补联合覆盖。

初始列库来自：历史可行方案、完整可达云心域逆推、表面分区锚点、接力端点和确定性分层网格。中心视线列只能作为高命中种子，不能成为候选域的完备性假设或硬剪枝依据。

## 6. 受限 MILP 主问题

令 `x_ic` 表示是否选择平台 `i` 的列 `c`，`y_mn` 表示导弹 `m` 在时间节点 `n` 是否被完整遮蔽。对每个可见表面点建立

```text
sum_c x_ic <= 1,                                      for every platform i;
y_mn <= sum_{i,c} a_icmnp x_ic,                       for every m,n,p;
x_ic, y_mn in {0,1}.                                                   (7)
```

离散主目标为 `sum_m sum_n w_n y_mn`，其中 `w_n` 是时间积分权重。后续阶段可增加 `eta <= sum_n w_n y_mn` 表达 `J_fair`，以及 `z_n <= y_mn` 对全部导弹成立以表达 `J_all`。`L_all` 优先在连续严格复算后取得；若进入主问题，则使用明确的连续段起止/自动机变量，不能用节点数量冒充连续秒数。

MILP 的整数最优值只证明当前离散节点、表面样本和当前列库内最优。LP 松弛给出的也只是相同受限主问题的上界。只有列定价被全局求解且连续时间/表面离散误差具有有效外界时，才允许把界提升为连续原问题的全局界。

## 7. 候选库扩充与未采用的列生成扩展

当前主链用历史可行计划、几何逆推、确定性邻域变体和瓶颈端点扰动扩充候选库，再由严格评价筛除代理改善但真实目标变差的候选。这一步仍属于统一主链中的“物理可达候选生成”，不另立第二套正式模型。

基于主问题对偶价格的真正列生成只保留为后续改进方向。若未来实现启发式定价器，只能报告“未找到改进列”，不能报告“无改进列存在”；在此之前，当前结果统一标记为 `PRICING_NOT_CERTIFIED`。

## 8. 严格连续复算与未采用的交换扩展

主问题得到组合后，当前实现由式（4）的严格评价核执行两类工作：

1. 用全时域 SCREEN 结果守卫候选区间，再以更密的 PRECISE 表面网格和连续端点求根重建三组 `Omega_m`；
2. 任何代理或离散主问题给出的改善，只有在严格连续复算后仍保持词典序改善才可替换 incumbent。

当前没有实现“发现反例后将新时间/表面约束回填 MILP 并循环重求”的完整交换算法，因此不能声称交换收敛。该机制与连续离散误差的有效外界一起保留为未来扩展；最终时长始终禁止用 MILP 节点计数代替。

## 9. 固定拓扑连续精修

MILP 固定平台列、弹数和主要接力关系后，再以原始航向、速度、投放时刻和引信时长为连续变量作确定性邻域精修。当前实现保留 incumbent：代理层改善但严格复算变差时拒绝替换。若以后允许增弹、删弹、换弹或弹位交换而改变计划拓扑，必须回到组合层重新检查可行性。

连续精修以词典序指标和严格约束余量比较候选。平台效应较强时，可用“给定目标阈值的可行性问题 + 二分”替代直接优化跳跃的区间指标，但它只服务对应的次级鲁棒目标。

## 10. 初始化、停止和失败信号

初始化至少包含旧 `J_sum=47.405023075357` 导弹·s 方案、当前严格交集方案以及由逆几何生成的确定性列。旧值仅为可行下界，不是 Q5_v2 的结果。

一次工作运行记录列库规模、受限 MILP gap、严格复算差异、确定性精修评价数、严格接受增益和墙钟预算。当前结果如实保留：

- `RESTRICTED_MASTER_ONLY`：仅证明列库内最优；
- `PRICING_NOT_CERTIFIED`：当前候选库扩充不构成已认证定价，不能给出全局列完备性结论；
- `CONTINUOUS_ORACLE_VIOLATION`：离散解未通过连续时间/表面检查；当前候选未触发该失败，且已完成工作级 E1/E2，但 PRECISE 仍不构成独立全时域高密漏岛证明；
- `REFINEMENT_UNSTABLE`：网格或连续精修尚未稳定；
- `NO_STRICT_FEASIBLE_SOLUTION`：没有通过严格核的可行方案。

## 11. 输入输出接口

输入包括官方物理参数、五个平台初始状态、三枚导弹轨迹、真目标圆柱、时间/表面初始离散、候选库生成预算及严格核精度层级。正式候选输出必须包含：

- 五个平台共享航迹参数与全部投放/引信决策；
- 每枚导弹的规范化并集区间 `Omega_m`；
- `J_sum`、`J_fair`、`J_all`、`L_all` 及其正确单位；
- 受限主问题界、实际 gap、列库范围和定价证明等级；
- 严格连续复算、加密差异、约束余量和失败信号；
- 可选 Pareto 解集，不用单个加权和掩盖指标交换。

## 12. 分阶段实施范围

1. 已完成独立目标与区间代数层，并对旧候选统一重评分；
