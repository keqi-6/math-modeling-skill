# Q5 独立几何—物理审计规格

规格标识：`SPEC-Q5-GEOMETRY-AUDIT-1.0`。本文件是 `SPEC-Q5-WORKING-5.0` 的验证附件，不改变 Q5 决策域、最长连续全遮蔽目标、正式结果或 Q4。

## 1. 审计目的与核心风险

当前 Q5 候选生成器与严格评价器共享部分几何函数，存在共模错误风险；粗代理网格还可能把网格点覆盖误当成连续圆柱覆盖。本轮暂停优化，只回答：运动学能否闭环、有限视线段距离是否正确、圆柱可见面是否正确、全遮蔽量词是否正确、历史方案的几何余量是否随网格收敛。

核心结构风险为：

1. 把无限直线距离误作有限导弹—目标线段距离；
2. 可见面法向判据与真实射线首次入射面不一致；
3. 逆向烟团候选不能正向重构为相同物理状态；
4. “遮住中心线”被误当成无条件必要且充分条件；
5. 多烟团量词错误地要求单个烟团独立覆盖全目标，或按导弹标签过滤物理烟团；
6. 粗圆柱网格给出虚假的全覆盖或错误最坏点。

## 2. 独立参考路径

审计模块 `src/q5/geometry_audit.py` 不调用生产实现的位集和批量距离公式来形成参考答案。参考路径使用显式三维向量投影逐点计算有限线段距离，并用射线与有限圆柱的解析首次交点判定可见性。生产函数只在最后作为被比较对象出现。

## 3. 可证解析关系

真目标圆柱半径 `R=7 m`、高度 `h=10 m`，以圆柱中点 `Q` 为参考时，任意目标点满足

```text
||P-Q|| <= sqrt(R^2+(h/2)^2) = sqrt(74) = 8.602325... m < 10 m.
```

若烟团中心位于 `C=M+lambda(Q-M)`、`0<=lambda<=1`，则对每个目标点取视线段上的同比例点 `X=M+lambda(P-M)`，有

```text
distance(C,[M,P]) <= ||C-X|| = lambda ||Q-P|| <= sqrt(74) < 10.
```

所以“导弹—圆柱中点”线段上的烟团是单枚导弹完整遮蔽的充分条件，但不是多导弹共同遮蔽的必要条件。相反，导弹—圆柱底面中心线不自动具有该证书，因为到顶缘的最大距离为 `sqrt(7^2+10^2)>10 m`。

## 4. 必做检查

- 随机与边界有限线段距离：独立逐点公式对比生产批量公式；
- 无限直线反例：烟团位于目标之后时无限直线距离为零，但有限线段距离必须为正；
- 可见性：表面法向判据对比射线—圆柱首次交点；切线点单独标记为数值歧义，不混入非歧义错误；
- 运动学闭环：已知航向、速度、投放、引信和烟龄正向生成烟团，再由候选反解器恢复并正向重构；
- 中点中心线充分性与底面中心线反例；
- 多烟团并集：验证评价量词为“逐表面点对烟团取最小，再对表面取最大”；
- 标签不改变物理覆盖；
- 历史方案在多个圆柱网格上的选定时刻三导弹最坏余量、最坏点和网格差。

## 5. 通过边界

解析/闭环检查容差按量纲设置：位置 `1e-7 m`、时间 `1e-9 s`、距离公式 `1e-9 m`；大坐标随机检查允许 `5e-9 m`。可见性只允许发生在切线/棱边歧义集合内的不一致。网格收敛只作诊断，不以有限网格差声称连续表面数学证明。

任何关键结构检查失败时总状态必须为 `fail`，并禁止继续宣称当前 Q5 严格评价核已通过几何审计。报告只写 `docs/q5_geometry_audit.json` 与 `docs/q5_geometry_audit.md`；不覆盖 `docs/q5_result.json`、`docs/q5_implementation_report.md` 或 Excel。

冻结主张：

- `A.Q5.GEOMETRY.AUDIT.001`：Q5 的有限视线段、圆柱可见面、运动学闭环、完整遮蔽量词和网格行为必须经独立参考路径及反例检查后，才允许进入新一轮全域优化。
