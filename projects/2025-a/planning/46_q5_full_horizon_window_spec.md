# Q5 全时域窗口可行性搜索 pilot 规格

实现标识：`Q5-FULL-HORIZON-WINDOW-1.0`。本步骤以全条件动态接力候选为当前下界，新建独立 working pilot，不覆盖正式 Q5、Q4 或 Q4_v2。

## 1. 完整时域与窗口族

三枚导弹同时仍处于来袭过程的公共时域取

```text
H=[0,T],  T=min_j ||M_j(0)||/v_m=60.36647340296691 s.       (1)
```

本轮使用窗口长度 `L=8.0 s`、起点步长 `h=0.5 s`。窗口起点集合为

```text
A={0,h,2h,...,floor((T-L)/h)h} union {T-L}.               (2)
```

最后的 `T-L` 必须显式加入，确保右端精确等于 `T`；不得用 `arange` 静默遗漏 `(60.0,T]`。每个窗口内部同样显式包含左右端点。

`L=8.0 s` 是用于定位可能超过当前约 `8.134 s` 下界的代理窗口：任一更长连续区间至少包含一个相邻0.5秒网格上的8秒子窗。窗口代理可行不等于严格时长达到8秒，必须再经连续时间严格核复核。

## 2. 统一量词与完整变量

每个窗口都使用同一全条件量词

```text
forall t in [a,a+L], forall j in {1,2,3}, forall P in V_j(t),
exists active cloud k:
    dist(C_k(t),segment(M_j(t),P)) <= 10 m.                (3)
```

烟团 `k` 可随 `t,j,P` 改变。搜索不使用主责导弹标签、指定平台、固定接力顺序或单弹完整遮蔽假设。

每个窗口的内层决策仍是五个平台全部航向、速度、三次投放时刻和十五枚弹引信组成的40维合法参数化。满容量只利用覆盖并集的单调性；多余烟团不削弱已有遮蔽。

## 3. 等预算轮转搜索

每个窗口建立同样大小的总体，包含：当前下界按窗口起点整体平移的合法种子、种子全变量扰动、种子与全域变量交叉样本以及全域样本。平移种子只是初始点之一，不固定航迹、平台或烟团职责。

算法按窗口起点轮转：

1. 先初始化并评价全部窗口，任何窗口都不能在首次评价前被排除；
2. 一轮中每个窗口恰执行一代相同规模的差分变异、全域注入和对称坐标探测；
3. 只有完整一轮结束后才能开始下一轮；
4. 墙钟不足以完成下一完整轮时停止，因此各窗口完成代数完全相同；
5. 不把更多预算只分配给当前靠近可行的窗口。

窗口代理目标是式（3）在窗口节点上的最大几何裕量

```text
G_a(x)=max_{t node in [a,a+L]} max_j max_P min_k
       [dist(C_k(t),segment(M_j(t),P))-10].                (4)
```

优先最小化 `G_a`，再最小化最差若干节点的平均裕量。`G_a<=0` 仅表示有限网格代理可行。

本轮不使用候选删除式几何剪枝。以后只能使用硬约束不可能、单事件无法命中任何必需视线，或剩余全部候选并集仍无法覆盖必需位集等有证明的排除规则。

## 4. 连续复核与主张边界

- 初始化后、每个完整轮次后报告全部窗口已完成代数、当前代理可行窗、全时域最小/最大窗口裕量、严格最优值和剩余预算。
- 新出现的代理可行候选与最终各窗口冠军进入连续时间 PROBE；最终最优再与当前下界一同进入 SCREEN。
- 保存每个窗口的起止时刻、评价次数、最佳最大裕量与是否严格复核，以证明完整窗口族均获得相同最低预算。
- 固定并登记随机种子、网格、总体规模、实际完整轮数、输入哈希和软件环境。
- 该搜索完整覆盖式（2）的有限窗口族，但没有穷尽每个窗口内的40维连续域，也没有覆盖所有连续起点；只能提供跨全时域的均衡搜索证据和新的严格可行下界，不能证明连续域全局最优。
