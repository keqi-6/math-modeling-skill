# Q5 固定事件连续服务驻留规格

实现标识：`Q5-FIXED-EVENT-DWELL-1.0`。本步骤把 `planning/42_q5_service_domain_implementation_spec.md` 的“指定时刻存在可行烟团”提升为“同一枚已固定烟幕干扰弹的连续安全服务区间”，不进入多弹调度，不替换正式 Q5 输出。

## 1. 固定事件的正向运动学

一个事件由平台 `i`、航向 `theta`、速度 `v`、投放时刻 `tau` 和引信时长 `delta` 唯一确定。起爆时刻

```text
t_e = tau + delta.
```

烟团在 `t in [t_e,t_e+20]` 的中心为

```text
C_xy(t) = O_i,xy + v t_e (cos theta, sin theta),
C_z(t)  = O_i,z - 0.5 g delta^2 - 3(t-t_e).
```

所以候选事件一旦重构，后续评价不再改航向、速度、投放或引信，也不允许烟团水平追踪导弹。

## 2. 连续安全区间

对给定导弹 `j`，定义固定事件的球包络充分证书函数

```text
f_j(t) = min_{0<=lambda<=1}
         ( ||C(t)-M_j(t)-lambda(Q-M_j(t))||^2
           -(r-lambda rho)^2 ).
```

`f_j(t)<=0` 意味着该枚烟团在时刻 `t` 独立完整遮蔽整个真目标圆柱，是物理上的安全充分条件。对指定安全种子 `t_0`，只返回包含 `t_0` 的连通分支：从 `t_0` 向两侧以固定步长寻找首个异号括号，再对连续函数 `f_j` 使用 Brent 求根。时间网格只用于寻找括号，不用网格端点作为驻留边界。

若同一事件在种子时刻同时对三枚导弹有 `f_j(t_0)<=0`，分别求得三个连通分支后取交集，得到该单烟团的“三导弹同时完整遮蔽”安全驻留。

## 3. lambda 分层候选

指定观测时刻 `t_0` 与几何截面 `lambda`后，仅在连续烟龄

```text
a in [0,min(20,t_0)]
```

上最小化平台可达截面与安全球截面的距离余量，然后重构物理事件。生产扫描固定保留

```text
lambda = 0.0,0.1,...,1.0.
```

每个平台—导弹对的每个 `lambda` 层按连续驻留长度保留前 3 个事件。因此 `lambda=0` 的导弹近旁瞬时深交叠不会在数据结构上淘汰中远端截面。

对已找到的可行烟龄，不把烟团硬编码在服务球截面中心。以固定 `lambda` 下的局部相对速度

```text
u_rel = (0,0,-3) - (1-lambda) dM_j/dt
```

为弦方向，在服务球直径上使用 `-0.999999,-0.5,0,0.5,0.999999` 五个分层落点，分别投影到当前平台可达截面，仅保留仍通过安全证书的物理事件。这一层显式避免“取交集中心”造成的半径驻留偏置；落点仍是确定性有限分层，不声称已经连续优化了整个交集。

## 4. 确定性与监管

- 无随机数；观测种子默认为 1 s 节点并强制加入共同时域终点。
- 每个平台—导弹对完成后立即输出进度、可行事件数、本对最长驻留与累计用时。
- 默认烟龄初筛 41 点；取网格最优点相邻小区间做有界一维精修。
- 连续边界括号步长默认 0.05 s，Brent 求根绝对精度 `1e-9 s`。
- 服务球弦落点固定为 5 层，不使用随机扰动；候选以真实连续驻留而非种子时刻的负余量排序。
- JSON 记录代码、输入、Python/NumPy/SciPy 版本与全部决定性参数。

## 5. 主张边界

允许声称：保存的区间是同一枚固定事件在球包络充分域下的连续安全驻留；事件可正向恢复；`lambda` 各层均被显式探查。

不允许声称：该驻留是单枚烟幕弹的全局最优值；球包络充分域等于完整物理可行域；不同事件可以无条件拼成同一无人机的固定航迹；已经求解多烟团角域并集或 Q5 最长连续全遮蔽调度。
