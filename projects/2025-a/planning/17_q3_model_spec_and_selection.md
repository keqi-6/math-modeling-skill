# Q3 正式模型规格与选择理由

规格标识：`SPEC-Q3-1.0`。  
状态：用户已确认的方法决定；供 Q3 S3→S4 冻结、后续实现与验证共同消费。  
稳定主张：`A.Q3.SELECTION.001`、`A.Q3.MODEL_SPEC.001`。

## 1. 决定、依据与方法角色

用户在听取官方讲评方案、候选差异、求解与验证建议后明确回复“确认接受，继续推进吧”。该确认接受以下方法决定：

1. 正式物理模型固定为官方八变量、多烟幕 `max_P min_k` 联合遮蔽模型；
2. C2 官方双物理域是主求解框架，必须保留少量完整航向守卫；
3. C3 可达起爆状态只负责主要几何种子，所有候选必须回到原八变量完整域精修；
4. C4 点—时覆盖束只作协同挑战者，其是否进入正式种子池由预登记 pilot 决定；
5. B0 错峰复制与 C1 边际贪心是可解释基线，不负责正式最优性主张；
6. 正式投放上界采用按序最后一次投放 `τ_3≤t_M`；官方讲评印刷式 `Στ_k≤t_M` 只作为内部对照约束；
7. 所有最终方案由同一个完整目标、有限线段、连续时间求值器复算。

官方讲评第 7—9 页直接支持时间并集、多烟幕部分覆盖协同、`max_P min_i` 判据、共享航向/速度、逐弹投放/起爆变量及两个物理缩域分别求解。C3、C4、公平 pilot、完整域守卫和证据闭包是为提高命中率、限制遗漏与控制主张强度而增加的工程层，不冒充官方指定算法。

### 1.1 角色冻结

| 角色 | 冻结方法 | 是否产生正式答案 |
|---|---|---|
| `primary_model` | 官方八变量联合遮蔽模型 | 是，决定目标与可行域 |
| `primary_solver` | C2 双物理域 + C3 可达种子 + 全域守卫 + 原变量多启动联合精修 | 是 |
| `conditional_seed_generator` | C4 点—时覆盖束组合 | 仅通过本规格 admission rule 后 |
| `baseline` | B0 错峰复制、C1 边际贪心 | 否，只作比较与初始化 |
| `auxiliary_validator` | 官方字面总和约束、中心点/单弹并集对照、独立稠密表面求值 | 否 |

## 2. 输入、对象、单位与时间基准

全部坐标、题面参数和模板身份来自官方题面、`result1.xlsx` 及已登记参数表。时间原点为无人机接令时刻；位置、速度、时间和角度的内部单位分别为 m、m/s、s、rad，写表方向转换为 `[0,360)` degree。

固定参数包括：烟幕有效半径 `R_s=10 m`、下沉速度 `v_s=3 m/s`、起爆后有效期 `T_s=20 s`、无人机速度范围 `[70,140] m/s`、同机相邻投放间隔 `Δτ=1 s`。项目数值约定 `g=9.8 m/s²`，不得标为题面原值。

对象为 FY1、同质烟幕弹 `B_k (k=1,2,3)`、相应烟幕球 `C_k`、M1 和真目标外表面。三枚弹按投放时刻升序编号。

## 3. 决策变量、派生量与硬约束

正式原变量为

`x=(θ,v,τ_1,τ_2,τ_3,δ_1,δ_2,δ_3)`。

变量域和硬约束：

- `0≤θ<2π`；
- `70≤v≤140`；
- `τ_1≥0`；
- `τ_2≥τ_1+1`、`τ_3≥τ_2+1`；
- `δ_k≥0`；
- `τ_3≤t_M`，其中 `t_M` 为 M1 命中假目标的题面派生时刻；
- `E_{k,z}=z_U-gδ_k²/2≥0`；
- `t_k^e=τ_k+δ_k≤t_M`。起爆晚于命中不产生任务价值，正式可行域直接排除。

无人机、投放点、起爆点和云团轨迹为

`U(t)=U_0+vt(cosθ,sinθ,0)`，

`R_k=U(τ_k)`，

`E_k=(x_U+vt_k^e cosθ,y_U+vt_k^e sinθ,z_U-gδ_k²/2)`，

`C_k(t)=E_k-v_s(t-t_k^e)e_z,  t∈[t_k^e,t_k^e+T_s]`。

任何参数化只能自动满足约束，不能取消最终原变量回代检查。约束接受容差为长度 `1e-8 m`、时间 `1e-10 s`；小于负容差即失败，容差内数值噪声仍须原值报告。

### 3.1 官方字面约束对照

另计算诊断标志

`official_literal_sum_release = [τ_1+τ_2+τ_3≤t_M]`。

它不参与正式可行性和排序，只报告若施加该印刷式会否排除正式候选。不得用它替换 `τ_3≤t_M`，除非合法重开规格。

## 4. 正式联合遮蔽模型

活跃烟幕集合为

`A(t)={k:t_k^e≤t≤min(t_k^e+T_s,t_M)}`。

记 `V(t)` 为从 M1 当前视点可见的真目标外表面。实现不得把圆柱内部点或不可见底面内部点加入正式点集，也不得把目标中心代替外表面。对 `P∈V(t)`，`d_seg(C,M,P)` 是球心到有限线段 `segment[M,P]` 的最短距离，投影参数必须截断到 `[0,1]`。

正式瞬时余量为

`Φ_3(t;x)=max_{P∈V(t)} min_{k∈A(t)}[d_seg(C_k(t),M(t),P)-R_s]`，

`A(t)=∅` 时取 `Φ_3=+∞`。有效遮蔽当且仅当 `Φ_3≤0`。

与单云不同，`min_k` 的烟幕身份可能随目标点切换，因此 Q1 的“只检查上下圆周”不能未经证明直接晋升为 Q3 正式连续 oracle。正式实现至少覆盖可见侧面及可见端面，并对烟幕身份切换处作局部极值复核；上下圆周求值只能作代理或独立下界。

时间集合与目标为

`S_3(x)={t∈[0,t_M]:Φ_3(t;x)≤0}`，

`J_3(x)=μ(S_3(x))`，

`max_x J_3(x)`。

时间求值必须在全部 `t_k^e`、`t_k^e+T_s` 与 `t_M` 处分段；每段先扫描，再对符号变化根和无变号切触候选分别括区间/局部极小化，最后规范化区间并集。重叠不重复计时。

## 5. 单弹、边际与协同输出

关闭其他两枚弹时，第 `k` 枚弹的独立完整遮蔽集合为 `S_k^{ind}`，模板行级时长为

`D_k=μ(S_k^{ind})`。

技术结果必须另存：

- `joint_intervals_s` 与 `joint_duration_s=J_3`；
- `individual_intervals_s[k]` 与 `individual_duration_s[k]=D_k`；
- 删除第 `k` 枚弹后的 `J_{-k}` 与边际贡献 `J_3-J_{-k}`；
- `pure_synergy_intervals=S_3\∪_k S_k^{ind}` 及其时长；
- 单弹区间重叠、空缺、控制量和约束余量。

## 6. 候选生成与主求解合同

### 6.1 B0 与 C1

B0 使用当前 Q2 可行策略的 `(θ,v,τ,δ)`，令后两枚 `τ` 分别增加 1 s、2 s并保持 `δ`；越界时该候选直接标为不可行，不静默修复。

C1 在固定候选航迹上依次最大化 `J_1`、`J_{1,2}-J_1`、`J_{1,2,3}-J_{1,2}`，再进入与主链相同的八变量精修。贪心值只作基线。

### 6.2 C2 官方双域与守卫

方向域沿用官方讲评/Q2 已解释的两类物理走廊：以 FY1 指向真目标中心的方向 `θ_T=atan2(y_T-y_U,x_T-x_U)` 和 FY1 指向 M1 初始位置的方向 `θ_M=atan2(y_M-y_U,x_M-x_U)` 为中心，各取周期半宽 `0.18 rad`。两域的速度均保留完整 `[70,140] m/s`，不把官方未证明完备的速度截断当作正式可行域；另保留完整 `θ∈[0,2π)` 守卫。候选份额固定为 `45%/45%/10%`。

对六个 `[0,1]` 时间坐标采用确定性可行映射：先令 `τ_1=(t_M-2)u_1`，再令 `τ_2=τ_1+1+(t_M-τ_1-2)u_2`、`τ_3=τ_2+1+(t_M-τ_2-1)u_3`；随后令 `δ_k=u_{3+k} min(sqrt(2z_U/g),t_M-τ_k)`。映射后仍回代原约束。守卫在域外发现严格更优候选时必须保存，不得为维护官方分域叙事而删除。

### 6.3 C3 可达起爆状态种子

种子变量为

`y=(θ,v,t_1^e,z_1^e,t_2^e,z_2^e,t_3^e,z_3^e)`，

其中

`δ_k=sqrt(2(z_U-z_k^e)/g)`，`τ_k=t_k^e-δ_k`。

每个固定随机种子使用八维 Latin hypercube 生成起爆状态提案：`θ,v` 按与 C2 相同的 `45%/45%/10%` 域采样，三个 `t_k^e` 各在 `[0,t_M]`、三个 `z_k^e` 各在 `[0,z_U]` 采样；由上式反解 `δ_k,τ_k`，再按 `τ_k` 排序并复核 1 s 间隔。最多读取 `4096` 个提案以收集本阶段要求的可行候选，数量不足则标记 underpowered。所有可行候选用视线走廊余量代理排序，因此高排名种子靠近有效走廊但不被限制在中心共线流形上。每个种子必须唯一回映射并满足全部原约束。C3 不缩小正式可行域，只提供初值。

### 6.4 C4 条件种子

C4 在共同 `(θ,v)` 下为单弹候选建立粗点—时覆盖张量，并选择满足投放间隔的三元组，使逐时刻目标点覆盖缺口最小。pilot 每种子生成 `12` 条共享航迹，每条航迹生成 `32` 个可行单弹候选，并按“新增被覆盖点—时单元数、较早投放、原序号”依次贪心选三弹；每条航迹用八个不同首弹入口形成最多 `8` 个三元组，目标为 `96` 个。正式运行相应使用 `24` 条航迹、每条 `32` 个单弹、八个入口，目标为 `192` 个三元组。候选组合后必须由正式 `Φ_3` 复算并进入原变量精修。

禁止用三个 `S_k^{ind}` 的并集替代点—时覆盖；该替代无法发现纯协同。

### 6.5 原变量精修

所有来源的候选转换到 `[0,1]^8` 可行参数化，采用有界无导数局部搜索。实现首选 Powell；若边界或失败码触发，可回退到 Nelder–Mead 加显式可行修复，但两者必须使用同一代理、停止门和正式复算。单起点上限为 `120` 次迭代、`600` 次代理求值，变量与函数停止阈值分别为 `1e-5`、`1e-7`。

代理只用于候选排序与局部搜索，正式答案按高精度 `J_3` 排序。

## 7. C4 admission pilot

固定随机种子：`250827,250828,250829`。比较来源为 C2、C2+C3、C2+C3+C4；B0/C1 确定性运行一次。

每来源、每种子固定获得：

- `96` 个代理候选；
- 代理前 `6` 个进入同一中精度连续筛选；
- 筛选前 `2` 个进入同一高精度复算。

因此每个随机来源的昂贵调用预算完全相同。候选生成和代理成本另行报告。时长差不超过 `1e-4 s` 视为 pilot 不可区分。

C4 进入正式种子池必须同时满足：

1. 三个种子中至少两个产生严格正值精算候选；
2. `C2+C3+C4` 的 seed-best 中位数相对 `C2+C3` 的下降不超过 `1e-4 s`；
3. 至少满足其一：最佳严格 `J_3` 提高超过 `1e-4 s`，或产生超过 `1e-4 s` 且在高精度加密下保留的纯协同时长；
4. 无硬约束失败、无系统性代理反转、无网格加密角色反转。

否则 C4 保留为内部协同验证器，不进入正式多启动池。pilot 只决定 C4 角色，不重选正式物理模型。

## 8. 正式运行预算与排序

每个固定种子生成：C2 `192` 个可行三弹候选、C3 `192` 个可行种子；若 C4 获准，再生成 `192` 个 C4 三元组。各来源按共同代理排序，前 `12` 个进入中精度筛选，前 `4` 个进入高精度复算。

从所有种子/来源的高精度结果及 B0/C1 中按“`J_3`、最小约束余量、代理分数、来源、原序号”的固定字典序去重并取前 `12` 个进行统一原变量精修。精修后全部中精度复算，前 `3` 个高精度复算；最终选严格 `J_3` 最大者，保存全部失败、零值与近优解。

如果某来源不足预算，只用实际可行数并标记 underpowered；不得从其他来源偷偷补充后仍声称配对公平。全来源均无正值时以 `Q3_FORMAL_ALL_ZERO` 失败，不输出“最优方案”。

## 9. 数值精度层级

### 9.1 代理层

- 时间步长 `0.10 s`；
- 可见表面角向 `64` 节点、侧面高度 `5` 层、可见端面径向 `5` 层；
- 允许 soft-min/soft-max 余量积分；
- 只排序，不形成时长主张。

### 9.2 中精度筛选

- 时间扫描最大步长 `0.02 s`；
- 角向 `128` 节点、侧面高度 `9` 层、可见端面径向 `9` 层；
- 进入/退出根时间容差 `1e-7 s`、余量容差 `1e-7 m`；
- 返回连续区间、端点残差和表面最坏点。

### 9.3 高精度复算

- 时间扫描最大步长 `0.005 s`；
- 角向 `512` 节点、侧面高度 `33` 层、可见端面径向 `33` 层；
- 对角、高度、径向及烟幕身份切换邻域做连续局部精修；
- 根时间容差 `1e-9 s`、余量容差 `1e-8 m`；
- 用至少两倍稠密的独立表面采样器复核最终三名。

高精度仍是数值认证而非解析全局证明；E2 必须报告加密差和最坏残差。

## 11. 失败信号

- `Q3_IDENTITY_MISMATCH`：官方输入、规格或实现 identity 不一致；
- `Q3_CONSTRAINT_FAILURE`：原变量硬约束违反；
- `Q3_SURFACE_EVALUATOR_FAILURE`：可见表面极值非有限或无法求精；
- `Q3_TIME_EVENT_FAILURE`：时间根、切触或区间规范化失败；
- `Q3_PROXY_REVERSAL`：代理候选经严格复算系统性归零/反转；
- `Q3_C3_INVERSE_FAILURE`：起爆状态无法唯一回映射或回映射不可行；
- `Q3_C4_GRID_UNSTABLE`：C4 admission 随网格加密反转；
- `Q3_PILOT_UNDERPOWERED`：来源未完成预登记配对预算；
- `Q3_PILOT_INCONCLUSIVE`：C4 规则无法决定角色；
- `Q3_FORMAL_ALL_ZERO`：正式全部启动均无正值；
- `Q3_EXCEL_ROUNDTRIP_FAILURE`：写后回读导致不可行或指标超容差。

任何失败都必须保存已完成记录和失败码，不得输出无边界的“最优解”。

## 12. 验证 oracle

后续 E1/E2 至少检查：

- B0 手算式共享航迹、1 s 间隔和 Q2 第一弹回归；
- 原变量↔C3 起爆状态往返残差；
- 标签置换后物理集合不变；
- 关闭两弹退化为 Q2 单弹严格求值；
- 构造多烟幕部分覆盖协同反例；
- `J_3≥max_k D_k` 与资源单调性；
- 区间并集无重叠双计；
- 正式/官方字面投放约束差异；
- 表面、时间和局部极值加密收敛；
- 主求值器与独立稠密表面采样器一致；
- Excel 写入—回读—复算一致。

## 13. 假设与允许主张

正式模型只采用题面理想运动学、硬半径烟幕球、匀速下沉和 20 s 有效窗。风、阻力、扩散、浓度、控制误差和真实识别机制不进入正式目标；它们只在 E4 诊断。

通过实现和 E1—E4 后允许声称：在官方题意、`SPEC-Q3-1.0`、固定候选域/预算和数值精度下，得到可复现、约束可行、经多精度与结构验证的高质量近优三弹策略，并量化联合、重叠、边际与纯协同。

禁止声称：严格连续域全局最优、官方双域完备、C3 是完整降维、C4 离散覆盖与连续模型严格等价、真实部署有效。
