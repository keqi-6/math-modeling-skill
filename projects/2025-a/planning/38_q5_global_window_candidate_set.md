# Q5 全时间域最长连续全遮蔽候选集

状态：Q5 因历史窗口锚定于 2026-08-29 重开至 `S2`。本文取代 `planning/35_q5_longest_continuous_candidate_set.md`；旧候选及其 7.06 s、8.27 s 数值仅作为局部下界证据。

## 1. 当前问题与基线

主目标保持为三枚导弹同时受到严格完整可见圆柱遮蔽时的最长连续区间 `L_all`，`J_all` 为第二目标。三弹共同时间域为 `[0,H]`，其中

```text
H = min_j ||M_j(0)|| / 300 = 60.36647340296691 s.
```

基线 C0 是历史决策经当前严格核重评分后的 `L_all=7.060098194887 s`。此前得到的约 8.27 s 解仅是 C0 邻域的工作下界，不承担候选完整性主张。

## 2. 候选比较

### C0：历史窗口局部邻域

围绕 `[15.8876,22.9477] s` 的七个节点生成事件，再做单机计划替换和坐标精修。它计算快、可手检，但不能发现远离该区间的新窗口。实际 pilot 中 FY1 事件池为 0、新增投弹数为 0，故只保留为下界。

### C1：全变量直接进化搜索

在完整时间域直接搜索五组航向速度与最多十五组投放/引信变量。它不依赖历史窗口，但高维混合可行域很薄，严格评价昂贵；短预算没有可解释的不可行诊断。只在离散计划选定后承担跨盆地扰动，不作为唯一主链。

### C2：全域滚动窗口分组计划覆盖

对每个目标时长 `T` 和窗口起点 `s`，建立 `[s,s+T]` 的时间—导弹—可见表面覆盖单元。每架无人机的一条固定航迹及零至三枚合法投弹组成一列计划；主问题从每个平台选择一列，最大化最弱时间片覆盖并优先满足所有单元。该方法直接表达连续作战窗口和固定航迹资源约束，能报告具体失败时刻、导弹、覆盖缺口和弹药利用。

### C3：C2 + 自适应最坏时刻切割

先在端点与粗节点上求 C2，再由严格物理核在整个窗口寻找最大违规时刻 `t*`。若 `Phi_j(t*)>0`，把该时刻及相邻表面弱点加入主问题并重新选择/精修计划。它修复固定节点可能漏掉节点间断裂的问题，但每次切割都会增加计算量。

## 3. 选择

选择 `C0 + C2 + C3` 为正式主链，C1 只用于入围计划的连续变量扰动。选择依据是：

- C0 保证不丢失已知可行下界；
- C2 将搜索范围扩展到完整 `[0,60.36647340296691] s`，不从旧解反推窗口；
- C3 以最坏时刻反馈替换固定七节点的连续性假设；
- 未找到目标时长时可以报告 `not_found_under_budget` 及缺口，不能伪装成不可行证明。

## 4. 全域阶梯和候选生成

第一阶段搜索

```text
T = 10,15,20,25,30,35,40,45,50,55,60 s.
```

每个 `T` 在 `[0,H-T]` 上生成多个起点，强制包含 `0` 与 `H-T`，并以 5 s 步长覆盖内部。候选 pilot 使用 2 s 全域基础节点并加入所有窗口端点；正式求解在最大可行与下一未找到级别之间细化时间与时长。

航迹候选从完整时间域的分层锚点反演产生，按航向、速度、来源时刻和导弹/表面来源去重；历史航迹只作为守卫列。每条固定航迹在全域多个目标时刻生成投弹事件，事件重新计算其对全部全域代理时间片的覆盖位集。每条计划最多三弹，并回代速度、起爆高度、非负时间、容量和同机 1 s 间隔。

## 5. 排序、停止和监管

代理字典序为：

1. 所有窗口时间片是否完整覆盖；
2. 最弱时间片覆盖率；
3. 全窗口覆盖率；
4. 已覆盖单元数；
5. 更少弹数与更大约束余量。

每个时长的最佳代理方案必须进入现有连续严格 `PROBE` 评价，报告真实 `L_all` 和区间。pilot 达到墙钟预算时原子写出部分阶梯，停止原因为 `wall_time_budget`；不会覆盖正式 Q5 JSON、报告或 Excel。

以下信号立即阻断正式化：完整时间域未进入代理网格、某平台候选库意外为空、所有时长重复同一旧方案、60 s 档未被实际枚举、代理全覆盖但严格核系统性断裂且切割未生效。

## 6. 允许主张

pilot 只能比较固定预算下候选生成器的覆盖能力和提供新的严格可行下界。`not_found_under_budget` 不是不可行证明；离散代理全覆盖也不是连续严格可行。正式结果必须经过自适应切割、连续变量精修、PRECISE 与 DENSIFIED 独立复算。

冻结主张 `A.Q5.CANDIDATE_SET.005`：Q5 在完整共同时间域上使用滚动窗口分组计划覆盖生成候选，以自适应最坏时刻切割保证连续性方向，历史窗口只保留为下界而不再限定搜索域。
