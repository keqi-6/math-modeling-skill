# Q1 冻结模型规格与选择理由

> 规格标识：`SPEC-Q1-1.0`。  
> 组件：`Q1`。  
> 生命周期：milestone；identity class：frozen。  
> 身份：本文件完成后由 `.modeling/state.json` 登记的 SHA-256 唯一确定；正文不自嵌哈希，避免自引用。  
> 输入依据：`data/A题.pdf`、`planning/03_inputs_identity_and_provenance.md`、`planning/04_q1_candidate_set.md`、`planning/05_official_parameter_registry.md`。  
> 消费者：Q1 实现、E1/E2 验证、结果解释和论文。  
> 边界：本规格冻结实现前定义，不运行求解器，不声明 Q1 数值答案已经复算。

稳定主张：

- `A.Q1.SELECTION.001`：Q1 选择 K1 解析运动学、G3 完整圆柱连续极值正式求值器、G2 高密度圆周独立验证器和 T2 括区间加根求精计时链；G1 中心点仅作错误对照。
- `A.Q1.MODEL_SPEC.001`：`SPEC-Q1-1.0` 冻结对象、变量、假设、方程、参数、单位、接口、算法、容差、验证预算、输出和失败信号，实施不得静默改变。

## 1. 问题重述

### 1.1 对象与关系

| 对象 | 唯一角色 | 关系 |
|---|---|---|
| `M1` | 运动中的观察点/来袭导弹 | 以 300 m/s 指向假目标原点；其位置决定每时刻视线束顶点 |
| `FY1` | 规定的投放平台 | 以 120 m/s 朝假目标等高度直线飞行，1.5 s 时投放一弹 |
| `B1` | 投放后的烟幕弹 | 继承 FY1 水平速度，受重力运动，延迟 3.6 s 起爆 |
| `C1` | 起爆后的有效烟幕球心 | 半径 `R_s` 的有效球随中心以 `v_s` 下沉，持续 `T_s` |
| `T` | 需要被完全遮蔽的真实目标 | 底面圆心 `(0,200,0)`、半径 7 m、高 10 m 的完整竖直圆柱 |
| `segment[M1(t),P]` | 对目标点 `P∈T` 的有向有限视线 | 只有与有效烟幕球相交时，该目标点视线才被截断 |

系统边界只包含题面理想运动学、球形有效烟幕、完整圆柱视线几何和连续时间计量；不引入风场、空气阻力、浓度连续分布或传感器成像噪声。

### 1.2 已知量、未知量、目标和约束

已知量：FY1、M1 和真目标初始参数；FY1 的 120 m/s 航速与朝假目标航向；投放时刻 1.5 s；起爆延迟 3.6 s；烟幕 `R_s=10 m`、`v_s=3 m/s`、`T_s=20 s`；项目约定 `g=9.8 m/s²`。

Q1 没有需要优化的航向、速度或投爆时序。待求未知量为：

| 符号 | 角色 | 取值域 | 单位 |
|---|---|---|---|
| `t_in,k` | 第 k 个完整遮蔽区间进入时刻 | `[t_e,t_e+T_s]` | s |
| `t_out,k` | 第 k 个完整遮蔽区间退出时刻 | `[t_e,t_e+T_s]` 且 `t_out,k≥t_in,k` | s |
| `I_k` | 第 k 个闭区间 `[t_in,k,t_out,k]` | 有限区间集合 | s |
| `T_eff` | 所有有效遮蔽区间并集的测度 | `≥0` | s |

目标是计算而非优化：

`T_eff = μ({t : 完整圆柱 T 在时刻 t 对 M1 被有效烟幕球完全遮蔽})`。

硬约束：轨迹必须物理可达；起爆高度非负；只在起爆后 20 s 有效窗内计时；烟幕必须与导弹—目标点有限线段相交；完整圆柱所有目标点均被遮住才算有效。

### 1.3 必需输出

| 输出 | 格式 | 单位 | 验收含义 |
|---|---|---|---|
| 投放点 | 长度 3 的 float64 向量 | m | 与解析运动学一致 |
| 起爆时刻/点 | float64；长度 3 向量 | s；m | 与解析运动学及参数约定一致 |
| 烟幕有效窗 | 长度 2 的 float64 向量 | s | `[t_e,t_e+T_s]` |
| 遮蔽区间 | 按起点升序的 `N×2` float64 数组 | s | 无重叠，端点经根求精 |
| 总有效时长 | float64 | s | 区间并集长度，不重复计时 |
| 中心点对照时长 | float64 | s | 仅用于证明中心点简化偏乐观 |
| 数值诊断 | 结构化字段 | s、m、rad | 包含收敛差、端点残差、区间数量和失败信号 |

## 4. 数学核心

### 4.1 解析运动学 K1

FY1 的水平单位方向为 `u=(-1,0,0)`：

`U(t)=U10+v_U t u`。

投放点、起爆时刻和起爆点：

- `R=U(t_r)`；
- `t_e=t_r+δ`；
- `E=U10+v_U t_e u-(0,0,gδ²/2)`。

烟幕球心：

`C(t)=E-(0,0,v_s(t-t_e)),  t∈[t_e,t_e+T_s]`。

M1 轨迹：

`M(t)=M10-v_M t M10/||M10||,  0≤t≤||M10||/v_M`。

解析检查点应得到：`R=(17620,0,1800)`、`t_e=5.1 s`、`E=(17188,0,1736.496)`、烟幕有效窗 `[5.1,25.1] s`。这些是推导实例，不是独立输入。

### 4.2 有向有限视线距离

对目标点 `P`，令 `v=P-M(t)`。球心到无限直线的投影参数为

`λ*=((C(t)-M(t))·v)/(v·v)`。

有限线段参数为 `λ=clip(λ*,0,1)`，最近点 `Q=M(t)+λv`，距离

`d_seg(C(t),M(t),P)=||C(t)-Q||₂`。

使用 `clip` 是规格的一部分：不得用无限直线距离替代，不得把导弹后方或目标后方的烟幕误判为有效遮蔽。

### 4.3 完整圆柱连续极值 G3

上下底面圆周参数化为

`P_z(θ)=(R_T cosθ, 200+R_T sinθ, z)`，

其中 `θ∈[0,2π)`、`z∈{0,H_T}`。

定义圆周视线余量

`φ_z(θ,t)=d_seg(C(t),M(t),P_z(θ))-R_s`，

以及完整圆柱最坏余量

`Φ(t)=max_{z∈{0,H_T}} max_{θ∈[0,2π)} φ_z(θ,t)`。

Q1 在时刻 `t` 完整遮蔽当且仅当：

1. `t∈[t_e,min(t_e+T_s,||M10||/v_M)]`；
2. `Φ(t)≤0`。

`Φ(t)=0` 是进入或退出完整遮蔽的连续边界。中心点判据不得替代 `Φ`。

### 4.4 时间集合与目标量

定义

`S={t∈[t_e,t_stop]: Φ(t)≤0}`，

其中 `t_stop=min(t_e+T_s,||M10||/v_M)`。将 `S` 规范化为互不重叠的闭区间并集 `⋃_k I_k`，最终

`T_eff=Σ_k (t_out,k-t_in,k)`。

区间端点的闭开选择不改变 Lebesgue 测度；实现统一保存为闭区间便于报告。

## 5. 选择理由

| 层 | 选择 | 未选候选及原因 |
|---|---|---|
| 运动学 | K1 解析轨迹 | K2 数值积分会无必要地引入步长误差；仅在未来复杂动力学中考虑 |
| 正式几何 | G3 上下圆周连续最坏余量 | G1 中心点不满足完整目标语义；G2 有限采样不能单独证明连续圆周极值 |
| 独立几何验证 | G2 高密度上下圆周采样 | 与 G3 实现路径不同，可暴露临界角搜索漏检；不替代主求值器 |
| 连续计时 | T2 网格发现、括区间、根求精、区间并集 | T1 固定网格误差直接等于步长；T3 全解析事件复杂且难以复用 |
| 错误对照 | G1 中心点时长 | 仅检查偏差方向和量级，不进入正式 `T_eff` |

选择优先级依次为题意正确、可独立验证、连续时间精度、确定性复现和 Q2–Q5 复用。运行速度只在前述条件满足后比较。

## 6. 冻结算法

### 6.1 完整圆柱主求值器

输入一个时刻 `t`：

1. 用 K1 计算 `M(t)` 与 `C(t)`；若不在烟幕有效窗，返回 `inactive`，不计算遮蔽。
2. 分别对 `z=0,H_T` 建立 `φ_z(θ,t)`。
3. 在 `[0,2π)` 上使用 `Nθ_primary=4096` 个等距周期节点初始化。
4. 所有满足“值不小于左右周期邻点”的节点均建立相邻节点括区间；对 `-φ_z` 使用确定性有界一维最小化，连同全部网格节点取最大值。
5. 一维角度求精在角区间宽度 `≤1e-12 rad` 或达到 `200` 次迭代时停止。
6. 若任一求值非有限、局部求精未收敛，返回失败，不用粗网格值静默替代。
7. 上下圆周最大值中的较大者为 `Φ(t)`，同时返回最坏 `z、θ、λ` 和 `d_seg`。

周期边界必须显式连接第 4095 个节点与第 0 个节点；不能把 `θ=0` 当作非周期端点。

### 6.2 时间区间引擎 T2

1. 搜索域为 `[t_e,t_stop]`，初始均匀步长 `Δt_scan=1e-3 s`，并强制包含两个端点。
2. 计算所有节点的 `Φ(t)`，记录符号变化和 `Φ≤0` 的连续节点块。
3. 对每个符号变化区间用二分法求 `Φ(t)=0`；停止条件必须同时满足时间括区间宽度 `≤1e-9 s` 与根位置余量绝对值 `≤1e-7 m`，最大 `100` 次迭代。
4. 为防止无符号变化的切触，检查每个离散局部最小值三点括区间；在其中有界最小化 `Φ(t)`。若最小值 `≤0`，向左右寻找并求精进入/退出根；恰好相切只产生零测度点，不增加时长但需记录诊断。
5. 将全部区间按起点排序；重叠或间隙 `≤2e-9 s` 的区间合并。
6. 以区间长度之和给出 `T_eff`，不得以命中网格点数量乘步长替代。

### 6.3 中心点错误对照

取圆柱代表中心 `P_c=(0,200,H_T/2)`，用相同时间扫描和根求精过程计算中心点视线时长。该字段单独标记 `diagnostic_only=true`，不能写入正式答案字段。

## 7. 数值容差与验证预算

| 项 | 冻结值 | 通过条件 |
|---|---:|---|
| 浮点类型 | IEEE-754 float64 | 不允许 float32 降精度 |
| 角度主网格 | `4096` | 周期覆盖上下圆周 |
| 角度加密网格 | `8192` | 报告端点及时间验证节点上 `|Φ4096-Φ8192|≤1e-7 m` |
| 独立圆周采样 | `131072` 点/圆周 | 与 G3 最坏余量差绝对值 `≤1e-6 m` |
| 角度停止容差 | `1e-12 rad` | 且迭代数不超过 200 |
| 时间发现步长 | `1e-3 s` | 必须再以 `5e-4 s` 加密复核 |
| 根时间容差 | `1e-9 s` | 端点括区间宽度满足 |
| 根余量容差 | `1e-7 m` | `|Φ(t_root)|` 满足 |
| 区间合并容差 | `2e-9 s` | 仅消除同一根的浮点裂缝 |
| 时间加密一致性 | `5e-4 s` 复扫 | 区间数相同、对应端点差 `≤5e-7 s`、总时长差 `≤1e-6 s` |
| 解析运动学核验 | 关键点 | 坐标绝对误差 `≤1e-9 m`，时刻误差 `≤1e-12 s` |
| 回归参考 | `1.391643 s` | 差值 `≤1e-3 s`；仅为外部一致性告警，不替代 E1/E2 |

如果更严加密导致上述任一条件不满足，状态为失败，禁止只保留看起来合理的时长。

| `uav_speed` | float64 | m/s | Q1 等于 120 且位于 `[70,140]` |

### 8.2 输出契约 `Q1Result`

结构化结果至少包含：

`status, spec_identity, input_identity, release_point_m, explosion_time_s, explosion_point_m, active_window_s, intervals_s, effective_duration_s, center_point_duration_s, worst_geometry, convergence, residuals, warnings, failure_code`。

要求：

- `intervals_s` 为 `N×2` float64，按起点升序且互不重叠；无有效区间时形状为 `(0,2)`，时长为 0，不算执行失败。
- `effective_duration_s` 保存全精度，展示时至少保留 6 位小数。
- `spec_identity` 必须等于本规格登记 SHA-256；`input_identity` 必须绑定官方 PDF 与正式参数映射。
- 结果必须保存为可检查载体；终端输出的孤立数字不构成正式结果。

## 9. 可观察失败信号

| failure code | 触发条件 | 处理 |
|---|---|---|
| `Q1_INVALID_INPUT` | 缺字段、形状/单位/域错误、非有限值 | 拒绝执行 |
| `Q1_INFEASIBLE_EXPLOSION` | 起爆高度低于 0 或时序不合法 | 返回失败，不截断修补 |
| `Q1_GEOMETRY_NONFINITE` | 距离、投影参数或余量非有限 | 返回失败 |
| `Q1_ANGULAR_NONCONVERGENCE` | 角度求精超迭代或加密不一致 | 返回失败 |
| `Q1_TIME_ROOT_UNRESOLVED` | 二分根未同时满足时间与余量容差 | 返回失败 |
| `Q1_INTERVAL_NONCONVERGENCE` | 时间加密改变区间数或超过端点/时长容差 | 返回失败 |
| `Q1_VALIDATOR_MISMATCH` | G2 与 G3 差异超过 `1e-6 m` | 返回失败 |
| `Q1_REGRESSION_WARNING` | 与 1.391643 s 相差超过 `1e-3 s`，但 E1/E2 尚未定位错误 | 产生告警并阻止结果晋级，不单独证明模型错误 |
| `Q1_HIDDEN_CONSTANT` | 改变参数对象后轨迹/判据未按规格响应 | 实现失败 |

`status="ok"` 仅在所有强制验证通过时给出；`T_eff=0` 是合法计算结果，不得误报为算法失败。

## 10. 实施与验证核销清单
