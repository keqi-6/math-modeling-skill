# 文献检索、来源评价与主张绑定

适用于领域语义、方法谱系、参数依据、现实边界、官方规则和外部主张的检索与核验。联网与下载仍需当前工具和权限；本包不因提供检索程序而授予外部写入。

来源保留：V8 `08-literature-search.md`、`12-source-audit-and-provenance.md`、`28-evidence-acceptance.md`，结合 V14 的 input/claim identity 和时效性边界。

## 何时需要检索

当前问出现以下任一情况时进行定向检索：

- 团队不熟悉领域对象、过程、制度或业务背景；
- 题面外变量、代理指标或中间产物需要现实解释；
- 需要识别公认问题类别、主要方法族或验证方式；
- 参数、阈值、误差范围、指标或适用边界需要外部依据；
- 稿件要使用“通常、已有研究、机理表明、官方要求”等外部主张；
- 法规、标准、竞赛规则、软件接口或政策可能已经变化。

完全由题面定义的确定性任务可以不检索，但记录为何不使用外部主张。“已有代码”“时间紧”或“AI 知道”不是充分理由。

## 以主张而非主题为检索单元

把问题写成：

`哪个来源能够支持、反驳或限制主张 C 在范围 R 内成立？`

按对象、机制、数学结构、场景、指标、时间和来源类型组合查询。可以分四轮：

1. 语义轮：实体、指标、制度职能和系统边界；
2. 选模轮：主要方法族、适用条件和替代方案；
3. 规格轮：假设、参数、基线、评价指标和验证设计；
4. 边界轮：现实推广、遗漏机制和时效性。

不得先凭常识固定模型，再只搜索支持既定选择的材料。文献前候选可作为关键词，但必须允许调查后新增、修改或淘汰。

## 来源身份与位阶

| 主张类型 | 优先来源 |
|---|---|
| 当前规则、日期、格式、资格 | 当期官方文件或发布机构 |
| 数据定义、口径和版本 | 数据发布者与原始元数据 |
| 算法定义、方法效果 | 原始论文、权威教材、官方技术文档 |
| 领域脉络 | 高质量综述并回溯关键原始文献 |
| 软件行为和接口 | 对应版本官方文档或源码 |

搜索结果页、摘要片段和 AI 回答只用于发现候选，不能承担正文证据。只有摘要可读时不能标为已阅读全文；往届答案、营销教程和方法清单不能证明事实、机理或最优性。

时效性主张在实际使用时重新联网核验。旧版本记录只能说明历史要求，不能自动成为当期规范。

## 阅读和记录

对实际采用的来源至少记录：稳定 ID、标题/作者/年份、DOI 或原始 URL、访问日期、来源类型、阅读范围、版本/页码、支持或反驳的主张、适用条件、限制和许可处置。

记录载体服从项目现有引用系统，不为满足模板同时创建多个重复台账。关键是能够从主张定位来源，也能从来源定位它被用于何处。

来源的本地副本要有合法取得路径和 identity；引用元数据、全文 identity 与稿件引用一致。引用主题相关但没有实际支撑当前主张属于装饰性引用。

## 外部数值的用途与消费者边界

外部数值不能只登记“有来源”，还要区分它在当前项目中的角色：

- 题面、当期官方规则或正式数据中的输入；
- 有文献依据、经当前模型采用的外部参数或阈值；
- 用于 E4 现实映射或正式方法比较的外部基准；
- 被当前项目仅用于候选启发、异常排查或内部回归告警的公开论文、复现或历史答案结果数值；
- 当前项目自己的正式运行输出。

对前四类至少记录 `source_authority`、`use_role`、`support_scope` 和 `permitted_consumers`。被登记为 `internal_regression` 或 `candidate_hint` 的外部答案数值，不得进入论文、已触发的人类讲解、正式答案主张或验收证据；引用完整也不会改变这个用途。若团队确实要把外部结果作为正式文献比较，先明确改变其用途，核对可比对象、输入、指标、候选域、精度和来源身份，再允许对应消费者使用。

这不是“所有外部数字禁入稿件”。题面常量、经批准的外部参数、现实基准和正式文献比较可以进入相应位置，但必须就近说明来源角色和它能支持什么。一个本项目独立计算值即使与公开结果舍入后相同，只要绑定自己的输入、规格、运行和验证 identity，仍是本项目输出；数值相同不能证明抄录。反过来，一个来源可靠的公开答案只要仍被登记为内部告警，就不能因“看起来正确”自动晋升为正式结果。

## 文献导向稿

复杂或关键子问可形成一份人可审阅的导向稿，包含：

- 需要外部证据回答的具体问题；
- 领域对象和候选机理；
- 方法族、条件、局限及与本题数据的匹配；
- 对数据处理、模型、图表和验证的具体影响；
- 本题证据与文献相容、矛盾或无法区分之处；
- 可进入论文的主张与禁止照搬的结论；
- 每个外部数值的用途角色、允许消费者与不可承担的验收责任；
- 仍未解决的问题。

它是人工讨论材料，不因写入文件成为选模权威。人工确认的是文献带来的关键方向与主张边界，不是逐篇批准引用格式。

## 防止知识污染

- 规则来源和规则强度分开；讲座或优秀论文不能整组升级成硬规范。
- 教材算法核对名称、假设、复杂度和当前软件接口。
- 示例代码实际运行并核对数学含义。
- 当前题目的节点、数值、路径和答案不进入通用 skill。
- 用户反馈先转成跨项目触发条件、动作和可检查结果；一次性偏好留在项目层。
- 历史时间线只能基于日志和产物 identity 推断，不能补造时间戳、动机或交互原话。

## 完成判断

检索完成不以文献数量或数据库数量判定，而看：关键外部主张有身份匹配的来源；阅读状态诚实；来源如何改变或约束当前分析清楚；其他体系和尺度没有无条件移植；人工理解了实质选择和边界。
