# 四问工作图表（working visuals）

本目录保存用于讲解四问方案和结果的工作图，不代表正式论文已经启动。所有数据值均由
`src/figures/build_explanatory_figures.py`从冻结JSON结果读取并生成，禁止在绘图软件中
手工修改数值。可复现命令为：

```bash
python3 -B src/figures/build_explanatory_figures.py --project-root . --output-dir docs/figures
```

## 图表与建议图注

| 文件 | 建议图注 | 主要边界 |
|---|---|---|
| `q1_sequential_state` | 批量`N=10`时两套完整动作空间序贯最优规则的实际可达状态图 | 星形为零风险事实动作（不占统计错误预算），菱形为统计阈值动作，方形为全检后事实判定；抽样前选定情景R或A |
| `q1_average_inspection_ratio` | `N=1000`时，不同批内实际次品率下两套冻结规则的平均检测比例 | 质量状态只用于事后评价，不参与阈值设计；每个点均为有限总体精确期望，连线只作视觉引导 |
| `q2_decision_profit` | 六种题设情形的最优固定决策与完成订单期望利润 | 情形3保留精确并列，不用市场坏品概率破同分 |
| `q3_oat_sensitivity` | 十二个节点次品率逐项正负5个百分点扰动后的最优利润变化 | OAT不是置信区间，也不覆盖多节点同时变化 |
| `q4_sampling_stability` | 五组抽样设计下单率区间与问题二、三策略切换比例 | 各节点区间分别构造，不解释为联合95%置信域 |

每张图同时提供适合论文嵌入的SVG和用于快速预览的240 dpi PNG。精确数据身份、生成命令
及渲染文件SHA-256见`figure_manifest.json`。

## 建议正文报告的特征点

问题一的平均检测比例图建议报告以下特征点：

| 批内实际次品率 | 用于识别超标批次 | 用于确认不超标批次 |
|---:|---:|---:|
| 0% | 90.0% | 2.2% |
| 5% | 94.5% | 61.0% |
| 10% | 95.4% | 90.6% |
| 10.1% | 94.3% | 90.0% |
| 15% | 34.7% | 65.2% |
| 20% | 8.0% | 50.0% |

表中的0%、5%、15%和20%不是第二质量点或灰区，而是冻结规则求出以后代入的评价状态。
图中每1个百分点计算一个精确点，并额外保留10.1%的相邻边界点；独立实现对204个图示点
进行了1228项精确核对。`N=1000`及各质量状态均是计算夹具，不是企业实测批次；冻结的
大批量规则满足风险上限，但不声称已经证明全局最优。

## 数据来源与单位

- 问题一：`output/q1/s5_results.json`、`s5_finite_closure.json`、`s5_large_batch_extension.json`、`s6_large_batch_verification.json`、`s7_quality_state_evaluation.json`、`s7_quality_state_verification.json`；状态坐标为检测件数和累计次品数，仅绘制冻结规则实际可达的状态；平均检测比例由精确评价的平均检测件数除以批量`N`得到。
- 问题二：`output/q2/s5_results.json`；利润单位为元/完成订单。
- 问题三：`output/q3/s5_results.json`；利润变化单位为元/完成订单。
- 问题四：`output/q4/s5_intervals.json`、`s5_q2_summary.json`、`s5_q3_summary.json`；
  次品率无量纲，策略切换按离散率组合计数。

这些数据属于竞赛题给定或代表性分析情形，没有时间口径和空间口径，也不是企业实测样本。

按当前论文取舍，不制作“问题二相关性—最优策略分区图”和“问题三名义情形—`F_HIGH`策略利润间隔图”；前者只适合作为弱模型假设检验，后者会重复OAT图已经表达的局部边界信息。
