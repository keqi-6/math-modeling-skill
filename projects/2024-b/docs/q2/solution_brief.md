# 问题二：固定检测与拆解决策模型的建立与求解

## 1 问题重述

企业用零件1和零件2装配成品。两类零件本身可能是次品；即使两件零件均合格，装配过程
仍可能产生次品。企业需要针对题面参数表给出的六种情景，分别决定是否检测零件1、是否检测
零件2、是否检测成品，以及发现次品后是否拆解。

每个情景只选择一次完整方案。此后无论处于首次生产、市场退货还是拆解后的重新装配，
都继续执行这套固定方案。例如，若方案只检测零件1，那么产品退回后仍只检测零件1，
不能临时追加零件2检测。

本问需要在全部固定方案中，先排除不能保证订单最终完成的方案，再比较其完成一个合格
订单的期望成本和期望利润，给出六个情景下的最优决策。

## 2 问题分析

若只计算第一次装配的成本，会漏掉市场调换、补购、重复检测、重新装配和拆解费用。
替换品仍可能是次品，因此一次订单可能经历多轮生产；售价却只能在这个订单中计算一次。
故本问的核算对象应是“从订单开始到客户最终收到合格品”的完整过程，而不是某一轮产品。

拆解决策还会改变方案是否能够结束。若拆解后保留了一个始终不检测的坏零件，固定方案
会把同一个坏件反复投入装配，使订单以正概率永久循环。有限轮截断或给该方案设置一个
大额罚值都会掩盖这一结构问题，因此利润比较之前必须施加最终成功概率与有限期望约束。

为同时保留零件真实质量、检测动作和拆解回流，本文以两个零件槽位的质量状态描述生产
过程，建立从当前状态到最终合格交付的首步期望递推。随后利用本题16种候选数量有限的
特点，完整生成全部方案，精确判断可行性并比较利润，不使用随机搜索或人为预删。

## 3 模型假设

1. 零件和成品检测完全准确，检测不损伤零件；检出的坏零件立即丢弃。
2. 主模型中，两类同时新购零件的质量相互独立；同类零件重复购买的次品率保持不变。
3. 两件合格零件重复装配时，每轮按题面参数表给定的成品次品率独立失败。
4. 拆解不改变零件原有质量，拆出的原零件只回到当前订单，不进入公共库存。
5. 一个订单只取得一次销售收入；市场次品每出现一次，企业承担一次调换损失并继续生产。
6. 题面没有列出的产能、工期、库存、残值、处置费和资金时间价值不进入主成本。

这些条件限定了模型的适用范围。若存在误检、批次质量变化、装配失败相关、拆解损伤或
跨订单共用零件，就需要增加相应状态和参数，不能无条件沿用本文结果。

## 4 主要符号说明

| 符号 | 含义 | 取值或单位 |
|---|---|---|
| `p1、p2` | 零件1、零件2的次品率 | 0至1 |
| `p0` | 两件合格零件投入后成品仍为次品的条件概率 | 0至1 |
| `g1、g2、g0` | 两类零件及装配过程的合格率 | `gi=1-pi` |
| `x1、x2` | 是否检测零件1、零件2 | 0或1 |
| `xp` | 是否检测成品 | 0或1 |
| `xd` | 次品是否拆解 | 0或1 |
| `S=(z1,z2)` | 一轮准备开始前两个零件槽位的状态 | 每个槽位为`E、G、B`之一 |
| `Vx(S)` | 方案`x`下，从状态`S`到完成订单的期望事件计数向量 | 次/订单 |
| `C(x)` | 完成一个合格订单的期望总成本 | 元/订单 |
| `P(x)` | 完成一个合格订单的期望利润 | 元/订单 |

## 5 模型建立

### 5.1 固定决策方案与执行顺序

用四元组`x=(x1,x2,xp,xd)`表示一套固定方案，四项依次表示检测零件1、检测零件2、
检测成品和拆解次品。每项只能取0或1，因此候选域为

```text
X = {0,1}^4，共有 2^4=16 种固定方案。                              （1）
```

例如，`1101`表示检测两类零件、不检测成品、次品需要拆解；`0100`表示只检测零件2，
不检测成品，次品也不拆解。式（1）只定义方案域，不预先判断哪种方案可行。

每轮严格按照下列顺序执行：

```text
补购或保留零件 → 按固定方案检测零件 → 装配 → 按固定方案检测成品
→ 次品售后 → 按固定方案拆解或丢弃 → 下一轮或订单结束。          （2）
```

式（2）固定了费用和状态变化的发生时点，也排除了退货后临时改变检测对象的动态策略。

### 5.2 零件质量状态与准备规则

在每轮准备零件之前，用`S=(z1,z2)`记录两个槽位。`E`表示缺件，`G`表示槽内实际为
合格件，`B`表示实际为坏件；初始状态为`S0=(E,E)`。`G、B`是模型保存的真实质量，
不表示企业在未检测时已经知道质量。

记两类零件和装配过程的合格率为

```text
g1 = 1-p1，g2 = 1-p2，g0 = 1-p0。                                   （3）
```

式（3）中，`p1、p2、p0`均直接来自当前情景的题面参数。`p0`只在投入的两件零件均为
合格件时使用；只要至少一件零件为坏件，本轮成品必为坏品。

若零件`i`不检测，即`xi=0`，则空槽只购买一次：以概率`gi`得到合格件，以概率`pi`得到
坏件；槽内已有零件时原样保留，不购买也不检测。

若零件`i`需要检测，即`xi=1`，空槽反复执行“购买一次、检测一次”，直到取得合格件。
因此，从空槽准备一件合格零件所需的平均购买次数和平均检测次数均为

```text
E[购买次数] = E[检测次数] = 1/gi。                                  （4）
```

若槽内已有合格件，本轮仍按固定方案复检一次；若槽内已有坏件，则先复检并丢弃，再按
式（4）补购到合格。该规则落实了“拆回原件也要继续执行原固定检测动作”。

把两个槽位的准备结果合并。记`Z=(z1,z2)`为准备结束后的实际质量组合，`Kx(S,Z)`为
方案`x`从状态`S`准备到质量`Z`的概率，`bx(S,Z)`为这一准备过程发生的购件与零件检测
计数。主模型中两个空槽同时补购时，两类质量独立，所以对应概率相乘。

### 5.3 装配、成品检测和回流关系

给定准备完成后的实际质量`Z`，只有`Z=(G,G)`时成品才可能合格。记本轮成品合格概率为

```text
q(Z) = g0，当 Z=(G,G)；否则 q(Z)=0。                                （5）
```

每次准备完成后必装配一次并支付装配费。若`xp=1`，每件成品还要支付一次成品检测费：
合格品完成订单，坏品在厂内拦截，不产生调换损失。若`xp=0`，产品直接进入市场：合格品
完成订单，坏品产生一次调换损失后退回。

坏品随后按`xd`处理。若`xd=0`，整件丢弃，两个槽位重新变为空；若`xd=1`，支付一次
拆解费，无损取回本轮实际质量`Z`。因此坏品分支的下一状态为

```text
Tx(Z) = Z，当 xd=1；Tx(Z)=(E,E)，当 xd=0。                           （6）
```

式（6）是永久坏件能否被保留的关键：拆解不会把`B`自动变成`G`，下一轮是否排除坏件只由
原方案的零件检测位决定。

### 5.4 完成订单的首步期望递推

按固定顺序记录八类事件：购买零件1、购买零件2、检测零件1、检测零件2、装配、检测
成品、拆解和市场次品调换。令`ea、ep、ed、ee`分别表示在装配、成品检测、拆解和调换
分量上增加1次的单位向量。

设`Vx(S)`为从状态`S`开始，直到客户最终收到合格品为止的期望事件计数向量。对准备后的
全部质量组合`Z`分情况，得到

```text
Vx(S) = sum_Z Kx(S,Z) × {
  bx(S,Z) + ea + xp×ep
  + [1-q(Z)] × [(1-xp)×ee + xd×ed + Vx(Tx(Z))]
}。                                                                    （7）
```

式（7）中，准备、装配和成品检测是本轮必然发生的事件；只有成品失败时才增加调换、拆解
和下一轮计数。成功分支在本轮吸收，不再产生后续费用。

把全部可达状态的式（7）联立，可写成

```text
V = a + QV。                                                           （8）
```

式（8）中，`a`汇总本轮事件期望，`Q`记录失败后在各暂态之间的转移概率。只有`Q`的谱半径
小于1，即失败概率质量最终全部流向成功状态时，才允许写成`V=(I-Q)^(-1)a`并得到有限期望。
若系统存在不退出的闭类，不能用伪逆或循环截断制造有限答案。

### 5.5 最终完成条件

对题面六种情景均有`0<p1,p2,p0<1`。若`xd=0`，每次坏品都整件丢弃并回到空槽；只要一轮
成功概率大于0，重复尝试最终成功概率为1，所以前面三位任意，共8种可行方案。

若`xd=1`且`x1=x2=1`，每次装配前两件零件都被筛成合格件。装配失败后拆回的仍是同一对
合格件，后续每轮以`g0>0`的概率成功；成品可检或不检，因此还有2种可行方案。

若`xd=1`且至少一种零件不检测，该零件第一次购买时可能就是坏件。坏件一旦进入回流，
以后既不被检测也不被替换，订单便永远不能成功。令`Ax`表示从两个空槽开始最终完成订单
的概率，则

```text
Ax = 1，                                      当 xd=0；
Ax = g1^(1-x1) × g2^(1-x2)，                  当 xd=1。                （9）
```

在拆解方案中，只要存在未检测零件，式（9）便严格小于1。这6种方案的总成本没有有限期望，
利润记为“因不终止而未定义”，而不是一个很小的有限数。故每个情景的利润比较域共有10种
方案，但仍对全部16种方案记录可行性及其失败原因。

### 5.6 成本、利润和方案选择目标

设从初始状态求得的八类期望次数依次为`n1、n2、m1、m2、na、mp、nd、ne`。其中`n1、n2`
是两类零件购买次数，`m1、m2`是对应检测次数，`na`是装配次数，`mp`是成品检测次数，
`nd`是拆解次数，`ne`是市场坏品及调换次数。

记两类零件购买价为`c1、c2`，检测费为`d1、d2`，装配费为`ca`，成品检测费为`dp`，
拆解费为`cd`，调换损失为`ce`。完成订单的期望总成本为

```text
C(x) = c1n1 + c2n2 + d1m1 + d2m2
     + ca na + dp mp + cd nd + ce ne。                                （10）
```

若一个订单的售价为`r`，则无论中间发生多少次退货和替换，都只计算一次收入，期望利润为

```text
P(x) = r - C(x)。                                                      （11）
```

对每个情景，在满足最终完成条件的方案中精确最大化式（11）。若多个方案的精确利润相同，则全部
保留为并列最优，不再另设市场坏品概率等第二目标破同分。

### 5.7 订单出现市场坏品的概率

期望调换次数描述平均发生多少次售后，不能直接表示订单是否至少发生过一次市场坏品。
令`Hx(S)`表示从状态`S`开始，订单最终完成前至少出现一次市场坏品的概率，则

```text
Hx(S) = sum_Z Kx(S,Z) × [1-q(Z)]
        × [(1-xp) + xp×Hx(Tx(Z))]。                                   （12）
```

当不检测成品时，本轮坏品进入市场，事件已经发生；当检测成品时，坏品在厂内拦截，只有
后续轮次仍需继续计算。式（12）作为售后风险解释指标，不参与式（11）的利润排序。

## 6 模型求解

### 6.1 完整生成和判定16种方案

算法按`0000、0001、...、1111`的四位组合机械生成16种固定方案。对每个方案先使用式（9）
和可达状态检查最终成功概率；只有成功概率为1且暂态方程具有有限解时，才继续计算事件
次数、成本和利润。

这个顺序避免了两类错误：一是凭经验只保留看似合理的方案，遗漏真正最优项；二是先给
永久循环方案计算截断利润，再用罚值把它混入经济比较。

### 6.2 不拆解方案的闭式求解

当`xd=0`时，每次坏品都使系统回到`(E,E)`，各轮具有相同的成功概率。若零件`i`检测，
它进入装配时必为合格件；若不检测，其合格概率为`gi`。定义

```text
ai = 1，当 xi=1；ai=gi，当 xi=0，i=1,2；
s = a1 × a2 × g0。                                                     （13）
```

式（13）中的`s`是一轮从空槽开始最终装出合格品的概率。重复独立尝试直到成功，平均装配
次数和平均失败次数分别为

```text
na = 1/s，失败次数 = (1-s)/s。                                       （14）
```

若零件`i`检测，每轮要平均购买并检测`1/gi`次；若不检测，每轮只购买一次。因此八类事件
次数为

```text
ni = na/gi，当 xi=1；ni=na，当 xi=0；
mi = na/gi，当 xi=1；mi=0，当 xi=0；
mp = xp×na，nd=0，ne=(1-xp)×(1-s)/s。                                （15）
```

订单至少出现一次市场坏品的概率为`(1-xp)(1-s)`。式（13）至式（15）把8种不拆解方案
直接还原为购件、检测、装配和调换次数，再由式（10）和式（11）得到成本与利润。

### 6.3 双零件检测并拆解方案的闭式求解

满足拆解可行条件的方案必有`x1=x2=xd=1`。首次装配前，两类零件分别筛到合格件，平均购件数
为`1/g1`和`1/g2`。装配失败后回收的是同一对合格件，以后只需复检并重新装配。

每轮装配成功率为`g0`，所以平均装配次数与平均失败次数为

```text
na = 1/g0，失败次数 = p0/g0。                                        （16）
```

对`i=1,2`，购件、零件复检及其他事件次数为

```text
ni = 1/gi；
mi = 1/gi + p0/g0；
mp = xp/g0；
nd = p0/g0；
ne = (1-xp)×p0/g0。                                                   （17）
```

式（17）中的`1/gi`来自首次筛选，`p0/g0`来自每次失败拆回后的固定复检。订单出现市场
坏品的概率为`(1-xp)p0`；成品检测只改变坏品是否流入市场，不改变零件的真实质量。

### 6.4 状态方程与闭式关系的双重求解

对10种可行方案均按式（7）建立有限状态方程，并使用精确有理数消元求解；同时按
式（13）至式（17）的闭式关系计算同一组事件次数，两种表示应逐项完全一致。

闭式关系利用了本题可行方案只有“丢弃后整轮重启”和“双检后拆解复用”两类结构；通用
状态方程则保留了每轮的质量身份和费用时点。两种表示相符属于求解校核，不作为模型现实
有效性的证据。

### 6.5 精确排序与停止判据

题面参数表中的有限小数全部转为精确有理数。每个情景的16种方案生成完毕、6种不可终止方案完成
标记、10种可行方案的式（11）全部求出后，算法取最大精确利润；相等者共同保留，至此
停止。

由于固定方案域的16种组合已经穷尽，所得结果是该固定四元方案域内的全局最优集合。
这一结论不能扩展到根据退货状态改变动作的动态方案、表外连续参数或现实全部生产政策。

### 6.6 情景1的完整计算示例

情景1采用方案`1101`。此时`p1=p2=p0=0.1`，故`g1=g2=g0=0.9`。由式（16）和式（17），
两类零件平均购件数均为`10/9`，平均检测数均为`11/9`，平均装配数为`10/9`，平均拆解
和调换数均为`1/9`，成品检测数为0。

情景1的零件购买价、零件检测费、装配费、拆解费和调换损失依次代入式（10），得到

```text
C(1101) = 4×10/9 + 18×10/9 + 2×11/9 + 3×11/9
          + 6×10/9 + 5×1/9 + 6×1/9
        = 346/9 = 38.444444... 元。                                  （18）
```

售价为56元，所以

```text
P(1101) = 56 - 346/9 = 158/9 = 17.555556... 元。                     （19）
```

式（18）和式（19）展示的是完成一个最终合格订单的长期平均成本与利润，不表示单个订单
可以发生分数次操作。

### 7.1 情景1与情景2

两个情景均选择`1101`：检测两类零件，不检测成品，坏品拆解后继续使用原合格件。零件
检测消除了持久坏件，拆解使企业不必在每次装配失败后重新购买两件零件；调换损失只有
6元，因此承担少量市场售后比每轮支付成品检测费更省。

情景2的两类零件次品率和装配次品率均由10%提高到20%，平均筛选、复检、装配、拆解和
调换次数随之增加，期望利润由17.555556元降至10.750000元。这个变化由题面情景参数
造成，不是估计误差或敏感性试验。

### 7.2 情景3的精确并列

方案`1101`不检测成品，平均调换`1/9`次；每次调换损失30元，所以平均调换损失为
`30/9=10/3`元。方案`1111`每次装配都检测成品，平均检测`10/9`次；每次检测3元，平均
检测费用同样为`3×10/9=10/3`元。

两方案的其他事件次数完全相同，所以成本均为`370/9`元，利润均为`134/9`元。`1111`
把市场坏品概率从0.1降至0，但本文没有把售后风险设为利润之后的第二目标，故不能据此
擅自删除`1101`，两者必须共同报告。

### 7.3 情景4

情景4的成品检测费为2元，市场调换损失为30元。方案`1111`在厂内拦截坏品，增加的成品
检测费用低于避免的市场调换损失，因此检测两类零件、检测成品并拆解。其期望利润为
14.25元，市场坏品概率为0；后一个结论依赖检测完全准确的假设。

### 7.4 情景5

情景5中，零件1检测费为8元，零件2检测费为1元且次品率更高。方案`0100`只检测零件2，
坏品整件丢弃并重新开始。检测零件1带来的合格率改善不足以补偿8元检测费；选择拆解又会
使未检测零件1可能形成永久坏件闭类。故`0100`在主模型固定方案域内利润最高。

### 7.5 情景6

情景6的三类次品率均为5%，而拆解费高达40元。方案`0000`不检测也不拆解，虽然平均需要
1.166351次装配并产生0.166351次调换，但检测和拆解的新增费用无法由减少失败的收益收回，
所以简单方案本身就是固定候选域内最优方案。

### 7.6 企业执行方式

企业先根据当前参数情景查得一套四位方案，并在整个订单生命周期内固定执行。若方案选择
零件检测，每次新购或拆回后都按同一规则复检；若不检测某类零件，退货后也不能临时追加
该项检测。坏品是否进入市场、是否拆解以及下一轮保留哪些原件，都由同一四位方案决定。

表1结果只对应题面六种情景。若成本、次品率或固定策略语义改变，应重新生成16种方案并
施加相同的最终完成约束并重新精确排序，不能只凭表中最优编码直接类推。

## 8 模型检验与敏感性分析

### 8.1 完成订单的流量守恒检验

一个已经完成的订单恰好包含一次成功装配，因此失败装配数应等于总装配数减1。结合固定
成品检测与拆解决策，所有可行方案还应满足

```text
失败装配数 = 装配数 - 1；
成品检测数 = xp × 装配数；
调换数 = (1-xp) × 失败装配数；
拆解数 = xd × 失败装配数；
利润 = 一次售价 - 全部事件成本。                                  （20）
```

六个情景中的全部可行方案均满足式（20）。该关系直接来自“一份订单最终只交付一件合格
成品”，可以检查检测、拆解、调换和收入发生时点是否自洽；它属于结构一致性检验，不是
对现实工厂的统计拟合。

### 8.2 极端参数与永久循环检验

六个情景中的36个不可行方案最终吸收概率均严格小于1，因而不能定义完成一份合格订单的
有限期望利润。这一结果排除了用有限返工次数截断永久坏件循环的处理。

最终完成条件还存在明确参数边界。若令`p1=p2=0`且`0<p0<1`，坏零件闭类不再可达，16种固定方案
都能最终完成；若令`p0=1`，每次装配必然失败，16种方案均不能完成。因此“10种可行、
6种不可行”只适用于题面六种正零件次品率且`g0>0`的情景，不能写成所有参数下的恒等结论。

### 8.3 两类零件相关性的敏感性分析

题面参数表只给出两类零件各自的合格率，没有提供两个空槽同时购买时的联合质量频数。记`h`为
此时两件零件同时合格的概率。在不改变边际合格率`g1、g2`的条件下，`h`必须满足

```text
max(0, g1+g2-1) <= h <= min(g1,g2)。                                 （21）
```

主模型的质量独立假设对应`h=g1g2`。令`h`遍历式（21）的完整允许区间，并在每个值
重新比较全部16种方案，而不是只把原推荐方案代入新参数。

表2　联合合格概率变化时的最优方案边界

| 情景 | `h`允许区间 | 主模型独立点 | 相关性区间内的结论 |
|---:|---:|---|---|
| 1 | `[0.80,0.90]` | `1101` | `h<0.85`选`1101`；`h>0.85`选`0000`；等号并列 |
| 2 | `[0.60,0.80]` | `1101` | 全区间均为`1101` |
| 3 | `[0.80,0.90]` | `1101/1111` | `h<31/37`保持原并列；`h>31/37`选`0010`；等号三者并列 |
| 4 | `[0.60,0.80]` | `1111` | 全区间均为`1111` |
| 5 | `[0.70,0.80]` | `0100` | `h<540/713`选`0100`；`h>540/713`选`0010`；等号并列 |
| 6 | `[0.90,0.95]` | `0000` | 全区间均为`0000` |

表2表明，情景2、4、6在这一联合质量边界内保持原推荐；情景1、3、5存在方案切换，因而
主模型推荐依赖零件质量独立假设。这里的`h`只描述两个空槽同时补购时的联合质量，单槽
补购仍按自身边际率，不能把该结果扩展为所有供应批次、时间依赖或装配依赖形式。

### 8.4 适用边界

题面参数表是给定情景，不是带样本量的观测数据；因此式（21）只能分析联合质量相关性对
方案的影响，不能替代真实产线数据。题目未提供工厂历史、检测设备误差、联合质量频数或
现实成本对照，尚不能进行经验有效性检验。本文只能说明模型在题设条件下满足流量守恒、
极端参数行为合理，并揭示部分相关性变化会导致方案切换。

## 9 模型评价

本文模型的主要优点是把固定方案作用于订单全生命周期，而不是只计算首轮产品。两槽位
质量状态保留了拆解回流的原零件身份，最终完成条件能够在利润比较前识别永久坏件循环；
完整枚举与精确有理数计算又使并列、排序和固定候选域最优性不受随机搜索或显示舍入影响。

模型的局限来自题面封闭条件。主结果依赖新购零件质量独立、同类质量率稳定、重复装配
独立、检测准确和无损拆解；产能、工期、库存共用、残值及其他现实费用均未进入模型。
相关性边界已经说明部分独立性变化会使方案切换，但没有现实联合质量数据时，不能判断
哪个`h`更符合企业实际。

若企业取得检测误差、供应批次、联合质量或重复装配数据，应回到状态和转移层重新建模；
若允许退货后根据已知质量改变检测动作，则候选域应扩展为状态相关策略，当前16种固定
方案最优结论不再直接适用。

## 10 问题二结论

问题二的正确比较单位是“从订单开始到最终合格交付”的完整循环。每个情景完整生成16种
固定四元方案，其中8种不拆解方案和2种双零件检测拆解方案能够以概率1完成并具有有限
期望成本；其余6种拆解且保留未检测零件的方案可能永久循环，利润没有定义。

在题面六种固定参数、零件质量独立、检测准确、重复购买和装配概率稳定、无损局部回流及题面
封闭成本口径下，六个情景的最优方案依次为：

```text
情景1：1101；情景2：1101；情景3：1101与1111并列；
情景4：1111；情景5：0100；情景6：0000。                         （22）
```

对应期望利润依次为17.555556元、10.750000元、14.888889元、14.250000元、
11.987654元和21.678670元。情景3的并列是精确成本恒等，不是舍入误差；`1111`虽能消除
市场坏品，但本文没有用该指标打破利润并列。

式（21）的相关性边界进一步表明，情景2、4、6在所考察联合质量区间内保持原方案，情景
1、3、5可能发生切换。故式（22）是固定方案域和本文模型条件下的精确最优集合，不是
动态策略域或现实工厂全部政策中的无条件全局最优。
