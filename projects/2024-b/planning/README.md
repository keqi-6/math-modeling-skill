# planning 目录说明

本目录保存题意、方案、交互决定、阶段分析、审计和历史材料。唯一机器状态位于根目录
`.modeling/state.json`，本目录中的 Markdown 与归档 JSON 只承担人工导航和证据职责。

- `index.md`：当前规划权威地图。
- `understanding.md`：共享题面事实和问题四 S1、S2 权威。
- `task_matrix.md`：四问状态与依赖导航。
- `analysis/`：当前或历史分析、规格和决定包。
- `audits/`：阶段关闭、验证和表达审计。
- `archive/`：被替代的状态与材料，只供追溯和回滚。

当前运行版本为 V9。问题一至三为 `S7`；问题四 S3轻闭环方法已批准，机器暂保留`S3`，
下一动作是建立待审S4数学规格。
正式论文尚未建立，planning 材料不得冒充论文正文或最终交付物。
