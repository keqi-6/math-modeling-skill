> 本文为问题二当前数学合同并授权S5实现。本文不批准S5结果的独立验证或论文晋升。

## 1. 预定用途与直接答案

对表1每个情景，在16种固定四元方案中：

1. 判断订单循环能否以概率1完成，且操作轮数、调换次数和总成本期望有限；
2. 只在通过硬门的方案中，计算完成一个最终合格订单的期望总成本和期望利润；
3. 选出期望利润最大的方案，并报告解释其形成机制的期望次数和售后风险。

结果只是在表1给定参数及本规格条件下的固定方案域内最优，不表示现实工厂全局最优。

## 2. 输入、决策与单位

对情景`s`，直接读取S2冻结的12个数值字段。记：

- `p1, p2`：两类零件次品率，定义域为0至1；合格率`g1=1-p1`、`g2=1-p2`；
- `p0`：两件正品投入后仍装配失败的条件概率，装配成功率`g0=1-p0`；
- `c1, c2`：零件购买价，元/件；`d1, d2`：零件检测费，元/次；
- `ca`：装配费，元/次；`dp`：成品检测费，元/次；
- `r`：一个最终完成订单的唯一销售收入，元/订单；
- `ce`：每件市场坏品的调换损失，元/次；`cd`：坏成品拆解费，元/次。

固定方案记为`x=(x1,x2,xp,xd)`，每项取0或1，依次表示检测零件1、检测零件2、检测
成品和拆解坏成品。候选域是四个二元量的全部组合，共16种；禁止按经验预删。

## 3. 已批准假设及失效后果

| 条件 | 数学作用 | 若失效 |
|---|---|---|
| 检测准确且无损 | 检出坏件必丢弃，检后保留件质量已知 | 需加入误检、漏检和检测损伤状态 |
| 新购两类零件在主模型中独立 | 同时新购时联合质量概率可相乘 | 未检测组合的利润不唯一 |
| 同类购买独立同分布且率稳定 | 补购可压缩为几何筛选，重启轮次同分布 | 需引入批次或时间状态 |
| 正品件重复装配各轮独立 | 每次装配以`g0`成功 | 回流循环的退出概率和期望改变 |
| 拆解保持原质量 | 回流状态保留实际质量 | 持久坏件门和复用收益改变 |
| 局部原件回流 | 拆件只进入本订单下一轮 | 不能解释公共库存政策 |
| 未列成本为封闭核算外项 | 总成本只由表1七类费用组成 | 现实利润可能遗漏成本或残值 |

## 4. 状态、质量身份与处理时点

在每次“准备零件”动作开始前，用状态`S=(z1,z2)`记录两个槽位：每个`zi`属于
`E、G、B`，分别表示缺件、实际合格件和实际坏件。`G、B`是模型内部的真实质量身份；
企业只有在检测后才知道质量。这个区分防止把“未检测”误写成“合格”。

初始状态是`S0=(E,E)`。每轮严格按以下顺序执行：

`补购或保留 → 按固定方案检测零件 → 装配 → 按固定方案检测成品 → 坏品售后 →
按固定方案拆解或丢弃 → 下一轮或订单结束`。

固定方案在所有轮次保持不变。状态不包含“第几次退货”，因为次数不能改变动作。

## 5. 零件准备算子

对零件`i`分别处理，再组合为准备完成后的实际质量`Z=(z1,z2)`。

### 5.1 不检测零件

若`xi=0`：

- 槽位为`E`时购买一次，支付`ci`并增加一次购买计数；以`gi`成为`G`，以`pi`成为`B`；
- 槽位已有`G`或`B`时原样保留，不购买、不检测，企业仍不因保留而获得质量信息。

### 5.2 检测零件

若`xi=1`，本轮进入准备动作的现有零件也必须再次检测并付费：

- 槽位为`E`时反复“购买一次并检测一次”，直到获得合格件；期望购买和检测次数均为
  `1/gi`，准备结束质量必为`G`；
- 槽位为`G`时复检一次，支付`di`，保持`G`；
- 槽位为`B`时先复检一次并丢弃，再反复购买检测至合格；期望新增购买次数为`1/gi`，
  检测次数为`1+1/gi`，准备结束质量为`G`。

主模型六情景均有`0<gi<1`，所以几何筛选期望有限。实现可以展开逐次购买，也可以使用
以上精确期望宏动作；两种表示必须给出相同的期望计数和费用。

把两个零件准备动作组合为概率核`Kx(S,Z)`。当两个空槽均不检测时，主模型按独立条件
取两类质量概率的乘积；其他情形按上述单槽规则组合。准备阶段的奖励向量记为
`b_x(S,Z)`，只记录实际发生的购件和零件检测次数，不提前加入装配费用。

## 6. 装配、成品检测、售后与回流

准备完成后必装配一次，支付`ca`。给定实际质量`Z`，本次成品合格概率为：

`q(Z) = g0`，当且仅当两件都是`G`；否则`q(Z)=0`。

若`xp=1`，每件装配品支付一次`dp`：

- 检测合格，进入市场并完成订单；
- 检测不合格，不进入市场、不产生收入或调换损失，直接执行拆解/丢弃决定。

若`xp=0`，装配品直接进入市场：合格则完成订单；坏品产生一次`ce`并退回。市场坏品
不重复产生销售收入，一个订单从始至终只在最终目标中计一次`r`。

任何坏品随后执行`xd`：

- `xd=0`：不付拆解费，整件丢弃，下一状态为`(E,E)`；
- `xd=1`：支付一次`cd`，无损拆出原件，下一状态为本轮实际质量`Z`。

成品检测只改变坏品在哪里被发现以及是否产生调换损失，不改变零件真实质量。

## 7. 首步期望递推

定义事件计数向量，顺序固定为：

`(购买1, 购买2, 检测1, 检测2, 装配, 成品检测, 拆解, 市场坏品/调换)`。

令`Vx(S)`为从状态`S`开始到订单最终合格交付的期望计数向量。令`ea、ep、ed、ee`
分别是在装配、成品检测、拆解和调换分量上取1的单位向量。下一状态记为：

`T_x(Z)=Z`，若`xd=1`；`T_x(Z)=(E,E)`，若`xd=0`。

则对可行方案使用同一条递推：

```text
Vx(S) = sum over Z of Kx(S,Z) times {
  b_x(S,Z) + ea + xp*ep
  + [1-q(Z)] * [(1-xp)*ee + xd*ed + Vx(T_x(Z))]
}
```

合格分支吸收，不再增加下一轮成本。坏品内部拦截时没有`ee`；市场坏品时`ee`同时代表
一次市场坏品和一次调换。若拆解，坏品分支才增加`ed`。

有限状态下可把递推写为`V = a + QV`。仅当可达暂态矩阵`Q`的谱半径小于1时，允许用
`V=(I-Q)^{-1}a`求期望；不得在奇异系统上使用伪逆制造有限答案。

## 8. 硬可行性门与10种可行方案

对每个方案，从初始状态`(E,E)`检查：

1. 最终合格吸收概率等于1；
2. 可达暂态矩阵谱半径小于1；
3. 因而期望装配轮数、调换次数和各项非负成本有限。

在表1六情景的`0<pi<1`和`0<p0<1`条件下，可以在规格层直接证明：

- `xd=0`时，坏品整件丢弃并回到`(E,E)`；每轮有正成功概率，前面三项任意，共8种可行；
- `xd=1`且`x1=x2=1`时，装配输入必为两件正品，每轮以`g0>0`成功；`xp`任意，共2种可行；
- `xd=1`且至少一个零件不检测时，该零件以正概率为坏件；坏件被无损保留且永不检测，
  形成成功概率为0的可达闭类。因此这6种方案不满足概率1退出，也没有有限期望成本。

实现仍必须生成全部16种并逐项给出门判定；不能只编码10种白名单。不可行方案的利润
身份记为`not_defined_due_to_nontermination`，而不是任意大负数或有限截断估计。

## 9. 费用、利润与方案选择

令初始状态期望计数为`Vx(S0)`。总成本为：

```text
C(x) = c1*购买1 + c2*购买2 + d1*检测1 + d2*检测2
     + ca*装配 + dp*成品检测 + cd*拆解 + ce*调换
```

完成订单期望利润为`P(x)=r-C(x)`。销售收入`r`只出现一次，不进入循环奖励向量。

对每个情景，在通过硬门的方案中取最大`P(x)`。表1数据按有限小数精确读取，理论比较
采用精确值；显示舍入不得改变排序。若多个方案利润精确相同，全部列为并列最优，不用
解释指标或未经批准的偏好破同分。

## 10. 必交输出

### 10.1 全16种方案审计表

每个情景、每个方案至少登记：四项决定、是否通过硬门、失败原因、吸收概率身份、利润
身份；可行方案另登记期望总成本、期望利润和完整事件计数向量。

### 10.2 六情景直接答案

每个情景报告：最优四元方案、是否并列、期望利润和总成本、两类平均购件数、两类平均
检测数、平均装配数、成品检测数、拆解数、市场坏品/调换数。

另报告“订单至少经历一次市场坏品”的概率`H_x(S0)`。其递推为：

```text
H_x(S) = sum over Z of Kx(S,Z) times
  [1-q(Z)] * [(1-xp) + xp*H_x(T_x(Z))]
```

当不检测成品时，第一次坏品即使事件发生；检测成品时内部坏品不算市场坏品并继续递推。
“完成时间”因题面没有时长数据，只能用期望装配轮数和事件计数表示，不能报告日历时间。

## 11. 已知解回归与验收测试

S4确认后，S5实现至少通过以下测试：

1. 候选完整性：每个情景恰有16个不同四元方案，门判定为10个可行、6个不可行。
2. 简单基线：`(0,0,0,0)`六行情景的单轮成功率、装配数、调换数、成本和利润逐项复现
   S2表格。
3. 回流基线：情景1的`(1,1,0,1)`复现成本38.4444元、利润17.5556元；未舍入值用于判断。
4. 永久循环：`(1,0,0,1)`和对称方案必须标为不可行；改变循环截断上限不得产生可比较
   利润。
5. 质量守恒：拆解前后`Z`不变；装配失败不得把`G`改成`B`。
6. 费用时点：收入每订单一次；产品检测仅在`xp=1`每次装配后发生；调换仅在市场坏品
   发生；拆解仅在坏品且`xd=1`发生；回流复检重复付费。
7. 概率守恒：每个状态全部准备和成品分支概率和为1，非负且不超过1。
8. 双表示同值：对可行方案，直接递推与有限线性方程给出相同事件期望。
9. 精确排序：显示舍入前后最优集合不变；真正精确并列共同保留。
10. 独立复算：验证程序不导入主递推函数，至少重建两个基线、全部门判定和六个最终选择
    的关键成本恒等式。

## 12. 不确定性与模型结构计划

| 来源 | 当前身份 | 后续方法与判据 | 声明边界 |
|---|---|---|---|
| 表1有限小数输入 | 固定情景，不是测量误差 | 精确读取；显示舍入单独记录 | 不产生现实置信区间 |
| 两类零件相关性未知 | 主模型条件假设；结构边界待检 | 当两个槽同时为空时，以同时合格概率在边际允许区间内传播；分别检查固定方案指标和重新比较后的最优集合 | 只说明透明补购耦合下的相关性边界，不代表全部时间依赖 |
| 重复购买和装配依赖 | 现实证据不足 | 用持久坏件反例和替代依赖情景说明失效机制；无依据时不设概率分布 | 现实稳定性保持未确认 |
| 检测误差 | 未给数据 | 不虚构灵敏度/特异度；登记失效后需扩展状态 | 只适用于理想检测 |
| 数值近似 | 计划不触发主要误差 | 有限小数转精确有理数；线性方程与递推交叉检查 | 显示舍入不承担排序 |
| 求解不确定性 | 不触发 | 穷尽16种，不使用随机搜索或提前停止 | 最优只相对固定候选域 |
| 模型结构 | S6必须检验 | 攻击永久循环、质量身份、单次收入、费用时点和边界退化 | 结构通过不等于现实确认 |
| 现实模型确认 | 预计`not_triggered` | 无工厂历史或实验对照；若未来获得则重新打开V4 | 现实域未确认 |

相关性检查采用明确的补购耦合：两个槽同时为空时允许一对新购件具有任意符合边际率的
联合质量；只有一个槽为空时，新件按自身边际率并与保留件独立。这个检查是结构情景，
不是由表1识别出的真实依赖过程。若该边界使最优集合变化，必须报告决策依赖独立假设；
若不变化，也只能在该耦合范围内称排序保持。

## 13. 禁止声明与S4人工门

库存策略、产能或工期结论、因果解释、问题四参数估计结果。

用户已经按上述语义确认本规格：批准以上数学合同与验收测试，允许进入S5实现；不等于
