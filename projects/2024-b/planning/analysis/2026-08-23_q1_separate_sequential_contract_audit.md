# 问题一：两个独立单向序贯方案的数学合同审计

- 审计阶段：S3 方法决定传播。
- 审计对象：旧有限总体双层方案中拟复用的数学结构。
- 当前方法权威：`planning/analysis/2026-08-23_q1_s3_approved_separate_sequential.md`。
- 当前已批准 S4 规格：`planning/analysis/2026-08-23_q1_s4_separate_sequential_specification.md`。
- 当前 S5 实现：`planning/analysis/2026-08-23_q1_s5_implementation.md`。
- 审计原则：题意优先；两个情景分别量化；旧结论必须逐项重证，不能整包恢复。

## 1. 首要防混检查

当前有两个不同的策略：

`pi_R: (t,x) -> {R,C}`，`pi_A: (t,x) -> {A,C}`。

相应地有两个不同的停止时刻 `T_R,T_A`、两个风险函数 `alpha_R,beta_A` 和两个效率目标
`W_R*,W_A*`。任何公式若同时出现 `P(拒收)<=0.05` 与 `P(接收)<=0.10` 并据此约束同一
策略，均不属于当前合同。

## 2. 逐项继承审计

| 旧合同项目 | 当前处理 | 数学依据或必要限制 |
|---|---|---|
| 运行时批量 `N` | 保留 | 批次客观存在；用户已确认不同 `N` 会影响检测过程 |
| 固定未知次品数 `D` | 保留 | 有限批次真实次品率为 `D/N`；不是先验随机变量 |
| `D0=floor(0.1N)`、`D1=D0+1` | 保留 | 仅把 10% 映射到有限整数网格，不是第二质量点 |
| 均匀无放回抽样 | 保留 | 与“一批零配件”一致；非随机抽样时风险外推失效 |
| 检测标签准确 | 保留为必要模型条件 | 题面没有检测误差校准；不能虚构误判参数 |
| 状态 `(t,x)` | 保留 | 在交换对称且准确标签条件下是计数型信息状态 |
| 三动作 `A/C/R` | 拆分 | 情景 1 只有 `R/C`，情景 2 只有 `A/C`；不得交叉解释 |
| 程序级错误控制 | 分别保留 | 防止固定时点尾概率被逐次重复使用而膨胀错误 |
| 单调耦合和似然比 | 待 S4 分别重证 | 只能用于相应方向事件，不能自动推出 ASN 单调性 |
| 最大路径次数 | 改写为各自 `N` | 由“不允许证据不足中途终止、最迟全检”得到，不是联合优化结果 |
| 最坏 ASN | 分别保留 | 情景 1 只在 `D>=D1` 优化；情景 2 只在 `D<=D0` 优化 |
| Bellman 递推 | 分别保留 | 两个动作集、风险乘子和目标域必须分别构造 |
| 线性规划/对偶证书 | 保留为严格证明接口 | 随机化凸类可用强对偶；确定性非凸类需上下界实际闭合 |
| 完全截尾 | 只保留思想 | 当前没有共同终端规则可复制；必须按单情景终局重新定义 |
| 终端化与 NP 前沿 | 限定保留 | 可作固定时点下界或宽类审计，不能恢复联合二元最优性 |
| `0.85N` 下界 | 撤销 | 它依赖同一策略同时承担两类错误并把二者相加 |
| OC 与 ASN 曲线 | 分别保留 | 情景 1、2 必须各自报告触发概率与平均检测数 |

## 3. 风险边界能够证明到哪里

若情景 1 的拒收停止集合关于观测次品标签是增事件，则无放回单调耦合支持：

`sup_{D<=D0} P_D(R)=P_D0(R)`。

若情景 2 的接收停止集合是减事件，则支持：

`sup_{D>=D1} P_D(A)=P_D1(A)`。

这两条结论分别成立，不构成联合错误合同。S4 必须把增事件/减事件条件落实到可执行边界，
并处理不可达状态；在此之前它们是证明计划，不是已经冻结的规格结论。

## 4. 已批准 S4 规格如何闭合 ASN 边界责任

风险概率的单调性本身确实不能自动推出停止时间期望的单调性。已批准 S4 规格没有作
这种跳步，而是把主方案明确为单向计数阈值，并对含 `D` 与 `D+1` 件次品的批次使用
嵌套次品集合和同一随机排列作路径级耦合。由每个时点均有 `X_t(D)<=X_t(D+1)` 得到：

- 情景 R 的上阈值命中时间满足 `T_R(D+1)<=T_R(D)`；
- 情景 A 的下阈值命中时间满足 `T_A(D)<=T_A(D+1)`。

因此已批准规格中的两条化简具有直接路径证明：

`sup(D>=D1) E_D[T_R]=E_D1[T_R]`，

`sup(D<=D0) E_D[T_A]=E_D0[T_A]`。

该结论只在两个情景各自只有目标方向提前停止、且状态动作对 `x` 方向单调时成立；若加入
相反方向早停或非单调动作，必须重开 S3。S5 已按全 `D` 递推完成同源反例检查；S6仍须
独立复算，且程序复算始终不能代替这里的证明。

## 5. 最大路径次数为何是 N

当前合同禁止把“证据不足”作为中途终止动作；到全检时依据真实 `D` 作出确定的企业动作，
但不借用另一情景的统计信度。情景 1 在达标批次下错误拒收概率至多 0.05，
因此必有正概率路径不提前拒收并到达全检；情景 2 在超标批次下错误接收概率至多 0.10，
同样必有正概率路径不提前接收并到达全检。故各自的路径最大值均为 `N`。

这个结论依赖当前终止语义。若未来允许在 `t<N` 时以“证据不足”结束，最大值会改变，且
次数优化可能退化为立即结束；必须返回 S3 重新决定，不能在 S4 偷换。

## 6. 不依赖 D 的准确含义

企业执行策略时不知道 `D`，只读取 `N,t,x`。`D` 只用于：

- 定义真实批次质量集合；
- 校准和验证复合风险；
- 评价不同真实质量下的 ASN；
- 构造无先验的最坏情形目标。

因此方案不以真实 `D` 为输入。若实现阶段必须检查多个 `D`，那是有限状态验证，不是给
企业增加已知参数，也不是遍历全部策略。

## 7. 方案类与全局最优声明

企业主方案是确定性 `(t,x)` 规则。旧审计已经证明：把它终端化后，不能自动等同为只看
终点总计数的固定阈值规则；完整抽样历史还能充当离散随机源。因此：

- Bellman 或其他状态递推得到的确定性候选只在明确方案类内比较；
- 随机化凸化问题可以提供对全部随机策略的下界；
- 只有可行确定性上界与有效下界相等时，才能声称相应范围内全局最优；
- 固定阈值、完全截尾或似然比规则只能作基线，不能自动冒充 ASN 最优。

## 8. 不确定性与适用域

| 来源 | 当前状态 | 对声明的影响 | S4/S6责任 |
|---|---|---|---|
| 抽样随机性 | `quantified` | 已批准S4定义精确递推，S5夹具产物保存精确风险与ASN | S6仍须独立复算；夹具N不外推为实际N |
| 批量 `N` 未给数值 | `not_triggered` | `N`是运行时输入而非待估随机参数，只能交付关于 `N` 的生成规则 | 用边界与代表性 `N` 作结构测试，不冒充题面输入 |
| 检测误差 | `unresolved` | 不能外推到未知误判设备 | 不虚构误差分布；在适用边界中明确 |
| 非随机或选择性抽样 | `unresolved` | 超几何风险保证可能失效 | 限制现实声明，必要时回到数据接口 |
| 优化与对偶间隙 | `unresolved` | 未闭合时不能声称全局最优 | 保存可行上界、有效下界和间隙 |
| ASN 最坏点位置 | `bounded` | 已批准S4用路径级耦合证明边界位置，S5同源全域检查通过 | S6仍须独立全域核验以攻击实现和方向错误 |

## 9. 审计结论

旧合同的有限总体表示、状态递推、程序级风险、Bellman—对偶证明接口和方案类审计能够
分别迁移到两个情景。共同策略、共同目标、联合错误预算和 `0.85N` 不能迁移。当前方法
决定在题意层保持两个情景独立，同时保留了序贯抽样和严格平均次数优化的数学主线。
