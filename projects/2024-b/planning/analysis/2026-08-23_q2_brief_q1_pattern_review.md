## 2 最终接受稿采用的职责链

最终稿共 657 行，标题顺序为：

`问题重述 → 问题分析 → 模型假设 → 主要符号说明 → 模型建立 → 模型求解 → 模型结果
→ 模型检验与结果分析 → 模型评价 → 问题结论 → 复现入口`

各部分篇幅并不平均。模型建立前的四部分只有 47 行；主体集中在模型建立、模型求解、
结果和检验，共约 556 行。这落实了用户提出的“前面压缩、技术主体完整展开”。

各章节的职责如下：

| 章节 | 实际职责 |
|---|---|
| 问题重述 | 只固定题目要求、输出形式和不得误解的边界 |
| 问题分析 | 解释为什么不能直接算、为什么要分情景、为何选择当前概率结构 |
| 模型假设 | 只列计算成立所需条件，并说明失效后果 |
| 符号说明 | 只提供跨章节索引，不承担公式首次解释 |
| 模型建立 | 从现实对象依次建立边界、状态、动作、风险、目标和输出 |
| 模型求解 | 说明状态怎样传播、候选怎样产生和比较、何时停止、能证明到什么程度 |
| 模型结果 | 给出具体方案、数值身份、形成机制、差距和现场执行方式 |
| 模型检验 | 区分同源检查、独立复算、结构检验和现实未确认 |
| 模型评价 | 说明模型解决了什么、计算代价和现实失效条件 |
| 结论 | 用普通语言直接回答题目，不重新讲算法 |
| 复现入口 | 单列代码、冻结输出和命令，并明确不属于论文正文 |

## 3 每组公式怎样写成可独立理解的句组

最终稿共有 43 组编号公式。公式通过的标准不是“符号表中出现过”，而是只读公式前后的
相邻段落，也能回答以下问题：

1. 公式中的现实对象是什么；
2. 每个符号表示什么、取什么范围；
3. 公式执行什么计算或限制；
4. 为什么需要这条关系；
5. 它服务题目中的哪一项判断；
6. 它不能证明什么。

实际写法是“对象与来意—局部符号定义—公式—作用解释”。例如，先说明企业要控制哪类
错误，再定义批量、真实次品数、停止时刻和概率，随后给出风险式，最后解释该式限制的是
整个程序的累计错误，而不是每个时刻各使用一次风险上限。

因此，符号表只是导航。局部状态量、中间量和新符号仍在首次参与推理的位置重新解释。

## 4 模型建立和模型求解为什么严格分开

问题一最终稿没有把“建立了什么数学问题”和“程序怎样把它算出来”混在一起。

模型建立先完成现实合同：批量和整数边界、无放回状态、停止动作、两种错误风险、平均
检测次数目标、最坏点缩减以及最终输出。读完这一部分，即使还不知道算法，也已经知道
什么方案算合法、什么量要最小化。

模型求解随后说明：怎样递推未停止概率，怎样计算风险和平均次数，怎样先得到可行上界，
怎样用放宽和分支定界得到严格下界，以及上下界何时允许声明全局最优。软件名称和函数名
没有替代候选生成、比较、剪枝和停止判据。

## 5 结果不是输出表的文字复制

问题一结果部分按“条件与基准—数值—形成原因—代价或差距—决策含义”组织。

例如，`N=10` 不只报告平均检测件数，还用次品位置给出手算机制，并用完整枚举限定
“确定性计数阈值类全局最优”。`N=23、50` 同时报告可行上界、严格下界和正差距，明确
不能因为差距小于一件就忽略，因为这里比较的是长期平均检测次数。

数值身份也被严格区分：题面条件、教学例、实现夹具、精确结果、舍入展示、检查计数和
现实数据不会混写。

## 6 验证按证明能力分层

最终稿没有用“程序跑通”统称验证，而是分开写：

- 同源内部检查：说明同一实现未暴露矛盾；
- 独立复算：说明关键风险、成本和下界不是共享函数造成的同源错误；
- 完整枚举或严格界：在对应候选域内支持最优性声明；
- 结构检验：攻击模型所依赖的单调边界关系；
- 现实确认：因无实测数据而不触发，现实适用域保持未确认。

每一项都紧邻说明“它能证明什么、不能证明什么”。这也是最终稿能够合理自洽而不夸大
结论的关键。

## 7 问题二应迁移的写法

问题二重写应迁移问题一的职责链和局部闭合方式，而不是复制问题一的公式数量或求解器。
建议骨架为：

1. 问题重述；
2. 问题分析；
3. 模型假设；
4. 主要符号说明；
5. 模型建立；
   - 一套固定决策方案的定义；
   - 状态和零件质量表示；
   - 采购、检测、装配、成品检测、销售、退回和拆解的转移；
   - 永久循环的可行性硬门；
   - 完成一个合格订单的期望成本和利润；
6. 模型求解；
   - 16 种固定方案的生成；
   - 两类可行方案的递推计算；
   - 不可行方案的结构判定；
   - 六个情景的精确枚举、排序和平局处理；
7. 模型结果；
   - 六个情景的推荐方案、利润和形成机制；
   - 情景三的并列最优；
   - 企业怎样执行固定方案；
8. 模型检验与结果分析；
   - 独立复算；
   - 概率流与永久循环结构检验；
   - 零件相关性边界；
   - 现实确认边界；
9. 模型评价；
10. 问题二结论；
11. 复现入口。

## 8 不应机械迁移的内容

问题一的两种单向序贯情景、超几何递推、相邻整数边界、似然下界和分支定界都属于问题一
专属数学内容。问题二不应为了“看起来像问题一”而复制这些模型、公式数量、章节长度或
最优性证书形式。

问题二真正需要继承的是：前置内容简短；模型建立和求解成为主体；每个公式组就近解释；
结果说明形成机制；验证按证明能力分层；结论强度与候选域、假设和现实证据严格匹配。
