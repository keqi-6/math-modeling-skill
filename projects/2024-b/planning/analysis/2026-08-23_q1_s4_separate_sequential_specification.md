## 1. 这份规格实际要解决什么

企业在执行时先知道批量 `N`，再从该批零配件中均匀随机、无放回地逐件检测。真实次品
总数 `D` 固定但未知，观测路径不同，停止时间也不同。因此本题的“检测次数尽可能少”
不是预先写死一个常数，而是分别求两个随 `N` 生成的序贯边界，并使目标质量集合上的
最坏平均检测次数最小。

两个题定情景从头到尾分开：

1. 情景 R 只寻找足够的超标证据并提前拒收；证据不足就继续，不能提前接收；
2. 情景 A 只寻找足够的不超标证据并提前接收；证据不足就继续，不能提前拒收；
3. 两者最迟都检测到 `N`，此时已知道整批真实 `D`，再按事实作接收或拒收；
4. `0.05` 只约束情景 R 的错误提前拒收，`0.10` 只约束情景 A 的错误提前接收。

## 3. 共同有限总体工具层

### 3.1 输入、符号与定义域

| 符号 | 含义 | 定义域或单位 | 来源 |
|---|---|---|---|
| `N` | 当前待检批次总件数 | 正整数；件 | 企业执行时读取 |
| `D` | 该批固定但未知的真实次品总数 | `0,...,N`；件 | 客观未知状态，不是策略输入 |
| `p0` | 标称次品率 | `0.10` | 官方题面 |
| `D0` | 不超过标称值的最大整数次品数 | `floor(0.10N)` | `p0` 在有限批整数网格上的映射 |
| `D1` | 超过标称值的最小整数次品数 | `D0+1` | 与 `D0` 相邻，不是第二质量点 |
| `Y_i` | 第 `i` 件检测标签，次品为 1 | `{0,1}` | 未来观测 |
| `X_t` | 前 `t` 件中的累计次品数 | `sum(i=1..t) Y_i` | 状态计数 |
| `(t,x)` | 已检测 `t` 件、其中 `x` 件次品 | `0<=t<=N, 0<=x<=t` | 通用状态 |

策略执行时只读取 `N,t,x`，不读取未知 `D`。`D` 只用于风险校准、性能评价和证明。

### 3.2 假设及失效后果

| 编号 | 成立条件 | 数学作用 | 失效后果 |
|---|---|---|---|
| A1 | 从整批中均匀随机、无放回抽取下一件 | 给出有限总体交换对称性和超几何转移 | 人为挑样或位置相关抽样会使风险保证失效 |
| A2 | 单件检测标签准确 | `Y_i` 等于真实质量标签 | 未知误检会同时改变风险和边界，不能靠任意扰动补救 |
| A3 | 批内真实质量在抽样期间不变 | `D` 为固定整数 | 动态生产流或批次混合不属于当前模型 |
| A4 | 情景在抽样前选定，不能看结果后择优 | 保持题定信度的程序级含义 | 事后选择情景需要重新控制选择错误 |
| A5 | 主规则确定且只依赖 `(N,t,x)` | 固定企业方案类 | 外部随机化只可作为理论放宽，不能冒充操作方案 |
| A6 | 情景 R 只允许拒收早停，情景 A 只允许接收早停 | 支撑单向语义和 ASN 单调性 | 加入相反早停必须回到 S3，本文全部 ASN 缩减失效 |

这些条件不是题面已经提供的样本信息，而是把题面方案落实为可检验程序所必需的执行
条件。本文不新增误检率、第二质量点或现实先验。

### 3.3 精确分布、可达域与一步转移

给定真实 `D`，时点 `t` 的可达次品计数为：

`max(0, t-(N-D)) <= x <= min(t,D)`。

在可达域内：

`P_D(X_t=x) = C(D,x) C(N-D,t-x) / C(N,t)`。

若 `t<N` 且程序在 `(t,x)` 继续，则下一件为次品和合格品的条件概率分别是：

`p_defect(D,t,x) = (D-x)/(N-t)`，

`p_good(D,t,x) = (N-D-t+x)/(N-t)`。

两者在可达状态上非负且和为 1。不可达状态的概率固定为 0；`t=N` 不再计算转移，避免
分母为 0。

## 4. 情景 R：95% 超标拒收

### 4.1 方案类和动作

对每个 `t=1,...,N-1` 设置整数上阈值：

`r_t in {0,1,...,t+1}`。

在 `(t,x)`：

- 若 `x>=r_t`，立即作出 `R`，即认定超过 10% 并拒收；
- 若 `x<r_t`，作出 `C`，即拒收证据不足并继续。

`r_t=t+1` 表示该时点不可能早停。阈值只要求同一时点对 `x` 方向单调，不要求
`r_t` 随 `t` 单调，以免加入未经批准的时间形状假设。`t=0` 禁止零检测拒收。

若到 `t=N` 仍未早停，则全检已知 `D=X_N`：`D>D0` 时按事实拒收，`D<=D0` 时按事实
接收。后一个动作不是 90% 统计接收结论。

### 4.2 风险和停止时间

情景 R 的程序级风险是：

`alpha_R(r) = sup(D=0..D0) P_D(T_R<N) <= 1/20`。

`T_R` 是首次满足 `X_t>=r_t` 的时点；若不存在，则 `T_R=N`。任何时点的普通 5% 固定样本
尾概率都不能替代这个“曾经早停”的整体概率。

### 4.3 优化目标

原 S3 目标是：

`W_R*(N) = min_r sup(D=D1..N) E_D[T_R]`。

第 6 节证明在本方案类中 `T_R` 随 `D` 路径级不增，因此严格化简为：

`W_R*(N) = min_r ASN_R(D1;r)`，约束为 `P_D0(T_R<N)<=1/20`。

这里 `ASN_R(D;r)=E_D[T_R]`。该化简不是遍历所有 `D` 的经验观察。

## 5. 情景 A：90% 不超标接收

### 5.1 方案类和动作

对每个 `t=1,...,N-1` 设置整数下阈值：

`a_t in {-1,0,1,...,t}`。

在 `(t,x)`：

- 若 `x<=a_t`，立即作出 `A`，即认定不超过 10% 并接收；
- 若 `x>a_t`，作出 `C`，即接收证据不足并继续。

`a_t=-1` 表示该时点不可能早停。仍只要求同一时点的方向单调，不增加时间单调条件；
`t=0` 禁止零检测接收。

若到 `t=N` 仍未早停，则 `D=X_N<=D0` 时按事实接收，`D>D0` 时按事实拒收。后一个动作
不是 95% 统计拒收结论。

### 5.2 风险和停止时间

情景 A 的程序级风险是：

`beta_A(a) = sup(D=D1..N) P_D(T_A<N) <= 1/10`。

`T_A` 是首次满足 `X_t<=a_t` 的时点；若不存在，则 `T_A=N`。

### 5.3 优化目标

原 S3 目标是：

`W_A*(N) = min_a sup(D=0..D0) E_D[T_A]`。

第 6 节证明 `T_A` 随 `D` 路径级不减，因此严格化简为：

`W_A*(N) = min_a ASN_A(D0;a)`，约束为 `P_D1(T_A<N)<=1/10`。

## 6. 两项复合最坏点缩减的严格证明

### 6.1 共同耦合

把 `D` 个次品所在的物件集合记为 `S_D`。从 `D` 增加到 `D+1` 时，只把一个原合格件
改为次品，使 `S_D` 包含于 `S_(D+1)`。对两个批次使用同一个均匀随机排列作为抽样顺序。
于是对每条耦合路径和每个时点都有：

`X_t(D) <= X_t(D+1)`。

该构造的两个边缘分布分别正是含 `D` 件和 `D+1` 件次品时的无放回随机抽样分布。

### 6.2 情景 R

若较小 `D` 的路径在时点 `t` 满足 `X_t(D)>=r_t`，则较大 `D+1` 的路径同样满足；后者
甚至可能更早触发。因此逐路径有：

`1{T_R(D)<N} <= 1{T_R(D+1)<N}`，

`T_R(D+1) <= T_R(D)`。

对第一式取期望，早拒事件概率随 `D` 不减，所以 `D<=D0` 中最坏风险恰在 `D0`。对第二式
取期望，ASN 随 `D` 不增，所以 `D>=D1` 中最大 ASN 恰在 `D1`。

### 6.3 情景 A

若较大 `D+1` 的路径在时点 `t` 满足 `X_t(D+1)<=a_t`，则较小 `D` 的路径也满足；后者
甚至可能更早触发。因此逐路径有：

`1{T_A(D)<N} >= 1{T_A(D+1)<N}`，

`T_A(D) <= T_A(D+1)`。

早接事件概率随 `D` 不增，所以 `D>=D1` 中最坏风险恰在 `D1`；ASN 随 `D` 不减，所以
`D<=D0` 中最大 ASN 恰在 `D0`。

### 6.4 证明边界

这些结论依赖每个情景只有一个方向的提前停止集合，且集合在 `x` 上方向单调。如果以后
允许情景 R 提前接收、允许情景 A 提前拒收、使用非单调状态动作或把两个情景并为一条
规则，以上路径不等式未必成立，必须回到 S3，而不能只改代码。

## 7. 精确前向递推：风险和 ASN 的唯一计算口径

对情景 `s` 属于 `{R,A}`，令 `z_s(t,x)` 表示该情景在 `(t,x)` 是否作出目标早停动作：

- `z_R(t,x)=1{x>=r_t}`；
- `z_A(t,x)=1{x<=a_t}`；
- 约定 `z_s(0,0)=0`，且 `t=N` 不计入目标早停。

令 `q_s(D,t,x)` 为在真实 `D` 下到达 `(t,x)` 且尚未在更早时点停止的概率。初始化：

`q_s(D,0,0)=1`，其余为 0。

对 `t=0,...,N-1`，只有继续质量 `q_s(D,t,x)(1-z_s(t,x))` 向下一时点传播：

`q_s(D,t+1,x+1) += q_s(D,t,x)(1-z_s(t,x))(D-x)/(N-t)`，

`q_s(D,t+1,x) += q_s(D,t,x)(1-z_s(t,x))(N-D-t+x)/(N-t)`。

不可达状态不传播；`t=N` 不进入上式。整个程序的目标早停概率为：

`Stop_s(D) = sum(t=1..N-1) sum(x=0..t) q_s(D,t,x) z_s(t,x)`。

平均检测次数为：

`ASN_s(D) = sum(t=1..N-1) t sum(x=0..t) q_s(D,t,x)z_s(t,x) + N(1-Stop_s(D))`。

质量守恒式为：

`Stop_s(D) + sum(x=0..N) q_s(D,N,x) = 1`。

因此当前两个独立约束和目标最终只需分别计算：

- 情景 R：风险 `Stop_R(D0)<=1/20`，目标 `ASN_R(D1)`；
- 情景 A：风险 `Stop_A(D1)<=1/10`，目标 `ASN_A(D0)`。

实现阶段可以额外输出全体 `D` 的曲线作独立审计，但那不是企业执行时需要知道 `D`，也
不是主优化必须遍历所有 `D`。

## 8. 精确优化对象与确定性并列规则

候选阈值域分别为：

`R_N = product(t=1..N-1) {0,...,t+1}`，

`A_N = product(t=1..N-1) {-1,...,t}`。

最终数学对象为：

`r*(N) in argmin[r in R_N, Stop_R(D0)<=1/20] ASN_R(D1)`，

`a*(N) in argmin[a in A_N, Stop_A(D1)<=1/10] ASN_A(D0)`。

若有多个精确同目标值的确定性方案，按 `(t,x)` 的字典序排列所有状态动作，编码
`继续=0、目标早停=1`，选动作向量字典序最小者。该规则只保证复现，不代表企业偏好，也
不增加第二目标。只有精确有理数相等或经严格区间证明相等时才触发并列，不能用任意浮点
容差制造并列。

## 9. 两组可手查基线

### 9.1 旧 `2/22` 固定证书基线

- 情景 R：`N>=3` 时，仅在 `t=2,x=2` 提前拒收，否则继续到全检；`N<=2` 直接全检。
  对任意 `D<=D0`，风险不超过 `(D/N)^2<=0.01<0.05`。
- 情景 A：`N>=23` 时，仅在 `t=22,x=0` 提前接收，否则继续到全检；`N<=22` 直接全检。
  对任意 `D>=D1`，风险小于 `0.9^22=0.098477...<0.10`。

这解释了旧方案中的 `2/22` 仍有何用，也明确了它们不是完整路径的固定总检测次数；在
已知有限 `N` 的当前接口下，它们也不保证仍是最早可行证书。

### 9.2 确定性事实基线

- 情景 R：当 `x>D0` 时，整批最终次品数必大于 `D0`，可以零风险提前拒收；对应
  `r_t=D0+1`（若大于 `t` 则该时点不触发）。
- 情景 A：当 `x+(N-t)<=D0` 时，即使未检件全部为次品也不超标，可以零风险提前接收；
  对应 `a_t=t-(N-D0)`（若小于 0 则该时点不触发）。

两个基线都属于主阈值方案类。故 S5 的最优候选必须可行，且目标 ASN 不得大于相应基线；
否则实现或求解必有错误。

## 10. 不靠全策略遍历的严格最优性证书

### 10.1 为什么仅有候选不够

前向递推能证明某个阈值方案可行并给出其 ASN，因此给出上界；但“程序找到一个好方案”
不能证明没有更好方案。S5 必须同时生成独立有效下界，只有上下界闭合才能声称全局最优。

### 10.2 拉格朗日 Bellman 下界

用公平二元序列分布 `Q` 作为统一参考。长度 `t`、累计 `x` 的任一有序前缀在真实 `D` 下
相对于 `Q` 的似然密度为：

`L_D(t,x) = 2^t falling(D,x) falling(N-D,t-x) / falling(N,t)`，

其中 `falling(u,k)=u(u-1)...(u-k+1)`，`falling(u,0)=1`；不可行前缀密度为 0。

情景 R 对任意乘子 `lambda>=0` 定义：

`Lag_R = E_D1[T_R] + lambda(P_D0(T_R<N)-1/20)`。

在允许任意完整历史动作和随机化的更宽方案类上，从 `t=N` 向前递推：

`V_R(N,x) = N L_D1(N,x)`；

对 `1<=t<N`：

`stop = t L_D1(t,x) + lambda L_D0(t,x)`，

`continue = (V_R(t+1,x)+V_R(t+1,x+1))/2`，

`V_R(t,x)=min(stop,continue)`。

根节点 `t=0` 禁止零检测停止，故 `V_R(0,0)` 只取继续值。于是：

`g_R(lambda)=V_R(0,0)-lambda/20`

是任何可行确定性阈值方案目标值的下界。

情景 A 完全另算：

`Lag_A = E_D0[T_A] + lambda(P_D1(T_A<N)-1/10)`；

`V_A(N,x)=N L_D0(N,x)`；

`stop=t L_D0(t,x)+lambda L_D1(t,x)`；

`continue=(V_A(t+1,x)+V_A(t+1,x+1))/2`；

`g_A(lambda)=V_A(0,0)-lambda/10`。

每个递推只有 `O(N^2)` 个状态。它不是对全部观测路径或全部策略逐一枚举。

### 10.3 下界为何有效、能证明到什么范围

对任何满足风险约束的方案，`lambda(风险-限额)<=0`，所以其拉格朗日值不大于其 ASN；
而 Bellman 递推取的是更宽方案类中的最小拉格朗日值。因此任意 `g_s(lambda)` 都是有效
下界，`sup(lambda>=0) g_s(lambda)` 仍是有效下界。

该宽类的随机化问题是有限线性规划，强对偶成立。如果确定性阈值候选的精确 ASN 等于
这个宽类下界，就证明它即使面对允许随机化、完整历史和非阈值动作的更宽比较类也全局
最优。

若上下界未闭合，则不得伪称最优。S5 采用带证书的分支定界：按时点对阈值取值分支，
一个阈值会同时固定该时点哪些 `x` 停止、哪些继续。在部分分支的 Bellman 递推中，已固定
停止状态只能取 `stop`，已固定继续状态只能取 `continue`，未固定状态才取两者的最小值；
同时放宽尚未固定动作的单调性，所得对偶值仍是所有合法完成方案的下界。若某分支能达到
的最小风险已经超限，或其下界不优于当前可行上界，就剪枝。只有所有分支均由可行性或
有效下界关闭，才能证明确定性阈值类全局最优。若资源限制前仍有节点未关闭，必须报告：

`certified_gap = feasible_ASN - valid_lower_bound`，

并把结论限制为“当前可行方案及其已证间隙”。这一路线以解析缩减和动态规划证书为主，
不是把全策略暴力遍历当作答案。

## 11. S5 产物合同

用户确认 S4 后，S5 才可实现以下产物；任何正式数字不得只留在控制台：

1. 输入 `N` 的合法性检查及 `D0,D1`；
2. 情景 R 的完整阈值序列 `r_t`、风险 `Stop_R(D0)`、目标 `ASN_R(D1)`；
3. 情景 A 的完整阈值序列 `a_t`、风险 `Stop_A(D1)`、目标 `ASN_A(D0)`；
4. 两个情景各自的基线 ASN、可行上界、有效下界和证书间隙；
5. 全 `D=0,...,N` 的停止概率与 ASN 曲线，仅作独立复核和边界展示；
6. 精确输入参数、算法版本、运行状态、候选身份、并列规则、哈希和直接消费者；
7. 人读执行表：给定 `N,t,x`，分别输出情景 R 或情景 A 的动作，不允许混成一张共同策略。

结构化结果必须把 `scenario_R` 与 `scenario_A` 置于不同对象中，不设置共同风险或共同
停止时刻字段。

## 12. S5—S6 验收测试

| 编号 | 检查对象 | 通过判据 |
|---|---|---|
| T1 | 情景隔离 | R 的公式、代码和产物不读取 A 的 `0.10` 风险；A 不读取 R 的 `0.05` 风险 |
| T2 | 动作域 | R 中途只有拒收/继续，A 中途只有接收/继续；证据不足不能终止 |
| T3 | 终点 | 所有路径最迟到 `N`；`t=N` 按真实 `D` 作事实动作且不计目标早停风险 |
| T4 | 阈值方向 | 固定 `t` 时，增加 `x` 不能把 R 从停变继续；减少 `x` 不能把 A 从停变继续 |
| T5 | 可达域 | 对每个 `N,D,t` 只传播合法 `x`，不可达状态质量为 0，`t=N` 无除零 |
| T6 | 质量守恒 | 每个情景、每个 `D` 均有“累计早停质量 + 到达 N 的质量 = 1” |
| T7 | 风险边界 | 精确复算 `Stop_R(D0)<=1/20`、`Stop_A(D1)<=1/10` |
| T8 | 复合单调性 | 全 `D` 审计中 R 早停概率不减、ASN 不增；A 早停概率不增、ASN 不减 |
| T9 | 最坏点等式 | 全域复算分别与 `D0,D1` 边界值一致；若不一致，判为模型或实现失败 |
| T10 | 基线手检 | 固定 `2/22` 基线满足风险；确定性事实基线风险精确为 0 |
| T11 | 支配基线 | 优化候选的目标 ASN 不大于同情景两项基线 |
| T12 | 最优性证书 | 保存可行上界、有效对偶下界和差；差为 0 才允许相应全局最优声明 |
| T13 | 小批边界 | 覆盖 `N=1,...,9`、`N=10` 及更大测试值，正确处理 `D0=0` 和短于 2/22 的批次 |
| T14 | 极端总体 | `D=0`、`D=N`、`D=D0`、`D=D1` 的转移、终止与动作符合定义 |

| T17 | 独立验证 | 独立复算不读取主求解摘要，至少重建风险、ASN、质量守恒和证书界 |
| T18 | 模型结构检验 | 用共同耦合、单调边界、全检退化和极端 `D` 攻击一个实质结构失败风险 |
| T19 | 禁止项扫描 | 当前产物不含共同 `T/M/W`、`0.85N`、第二质量点、灰区、功效、先验或 `D` 权重 |

## 13. 不确定性、误差和声明边界

| 来源 | 当前状态 | 来源依据 | 计划方法与判据 | 可能失效的声明 |
|---|---|---|---|---|
| 抽样随机性 | `unresolved` | 观测路径随机，直接决定风险与 ASN | S5 用第 7 节精确递推量化；通过 T6—T9 后转为 `quantified` | 信度、平均检测次数和最坏点 |
| `N` 未由题面给数值 | `not_triggered` | `N` 是执行输入，不是待估随机参数 | 输出关于 `N` 的生成规则，并以多个合法 `N` 做结构测试 | 不能虚构唯一常数样本量 |
| 检测误差 | `unresolved` | 题面无灵敏度、特异度或复检数据 | 不设任意误检分布；只声明准确检测条件下成立 | 真实设备上的风险保证 |
| 非随机或选择性抽样 | `unresolved` | 题面未给抽样执行质量数据 | 把均匀无放回写入操作要求；无现实对照时不作 V4 确认 | 从样品外推整批的信度 |
| 数值近似 | `unresolved` | 组合概率和对偶可能出现极小数与临界比较 | 精确有理数或严格区间；可行性只能在风险上界不超限时通过 | 风险可行性、并列和证书间隙 |
| 优化与最优性间隙 | `unresolved` | 确定性约束类非凸，候选不自动等于最优 | 同时报上界、Bellman 对偶下界和 `certified_gap` | 全局最优与“次数一定更少” |
| 模型形式与现实适用域 | `unresolved` | 无实测批次或可靠现实对照 | S6 必做 V3 结构检验；V4 若仍无数据记 `not_triggered` 并说明现实域未确认 | 对聚集、异质、动态生产批次的外推 |

不进行无依据的 `±5%`、`±10%` 扰动，也不把独立实现同值冒充误差分析。

## 14. 允许与禁止的最终表述

S5—S6 闭合后，允许在相应证据范围内表述：

- 给定 `N`、均匀无放回且准确检测时，情景 R 或情景 A 的可执行阈值规则；
- 各自独立的程序级风险上限、目标边界 ASN 和最大路径检测数 `N`；
- 当可行上界与有效下界闭合时，相应比较类内的全局最优性。

在证据未闭合前禁止表述：

- 两个情景共同构成一条二元接收—拒收检验；
- 一个情景不触发就得到另一个情景结论；
- 某一常数 `n` 对所有批量都最优；
- 只因程序返回候选就声称“同 `N` 下一定比所有方案检测更少”；
- 将确定性阈值类内结果无条件扩大到误检、非随机抽样、未知批量或动态总体。
