# 问题二情景1：可行固定方案全流程演示

> 状态：`S1_INTERPRET/approved interpretation example`。用户已经确认本文件演示的运营
> 口径；方案和数字仍只用于解释，不声称它是情景1的最优或推荐方案。

## 1. 已确认的上游口径

每个情景只选择一次完整四项方案，所有新生产、退货、拆解和再投入轮次执行同一动作。
16种组合全部生成；先检查流程是否最终退出且期望成本有限，再对通过者比较经济指标。

## 2. 本次演示方案、已确认口径和模型假设边界

方案为：检测零配件1、检测零配件2、不检测成品、拆解不合格品，即四项取值为
`(1, 1, 0, 1)`。

用户已经确认以下运营解释：

1. 检测出的坏零配件丢弃，只补购同类零配件，另一合格件保留待配对。
2. 无损拆解不改变零配件质量；装配失败只使本次成品不合格，不把两个正品零配件变坏。
3. 同一对正品零配件每次重新装配时，独立地有10%概率失败。
4. 客户收到坏品后持续无条件调换，直到取得合格替换品。
5. 退回品拆出的原零配件用于生产本订单的下一件替换品，不与公共库存混配。
6. 固定“检测两种零配件”意味着拆回后两种零配件都重新检测并再次付费。
7. 一个订单只取得一次56元收入；每次坏品交付均另计6元调换损失，而替换品生产成本
   单独核算。
8. 主经济指标按完成一个最终合格订单的平均利润核算。

为计算表中概率还需要后续模型明确假设检测完全准确，不同新购件相互独立且每次购买同
分布。它们不是题面原文，也不因用户确认运营流程而自动成为事实。

## 3. 首轮零配件筛选

零配件1每次购买支付4元、检测支付2元。单次成本为6元，合格概率为90%。得到一个合格
零配件1的平均购买次数为`1/0.9=1.1111`，平均成本为`6/0.9=6.6667`元。

零配件2每次购买支付18元、检测支付3元。单次成本为21元，合格概率为90%。得到一个
合格零配件2的平均购买次数为`1/0.9=1.1111`，平均成本为`21/0.9=23.3333`元。

企业只补购检测不合格的那一类零配件，已经合格的另一件留待装配。两种合格零配件准备
完成后的平均筛选成本为`6.6667+23.3333=30`元。

## 4. 首轮装配和销售

企业支付6元装配。由于投入的两种零配件均已检测合格，成品只有装配失败这一种次品来源：
成品以90%概率合格、10%概率不合格。

固定方案不检测成品，因此不支付3元成品检测费，装配完成后直接进入市场。首件产品进入
市场前的平均总成本为`30+6=36`元。

- 若首件产品合格，概率为90%，客户正常收货，订单结束。
- 若首件产品不合格，概率为10%，客户发现后要求调换，企业承担6元调换损失并收回坏品。

## 5. 退货、拆解和下一件替换品

固定方案要求拆解，企业支付5元拆解费。因为两种零配件在首轮装配前都已检测合格，且
无损拆解不改变质量，所以拆出的两种零配件仍然合格；本次成品不合格只来自装配失败。

拆回零配件重新执行同一固定方案：零配件1再次检测支付2元，零配件2再次检测支付3元，
然后重新装配支付6元。替换品仍不做成品检测，直接交给客户。

所以每出现一次市场坏品，到制成下一件替换品为止，追加费用为
`6+5+2+3+6=22`元，依次对应调换损失、拆解、两种零配件复检和重新装配。没有重复购买
零配件，因为本演示暂定原零配件继续使用。

若替换品仍因装配失败而不合格，就再次执行完全相同的22元循环；若装配成功，客户取得
合格品，订单结束。每轮重新装配成功概率为90%，所以在临时独立性假设下最终结束的概率
为1，期望成本有限，该方案通过已经确认的循环可行性硬门。

## 6. 在临时口径下的平均结果

从第一件产品开始，每次装配有90%概率结束订单。因此直到首次合格交付为止：

- 平均装配和交付件数为`1/0.9=1.1111`；
- 平均坏品、调换和拆解次数均为`0.1/0.9=0.1111`；
- 平均售后追加成本为`22×0.1/0.9=2.4444`元；
- 每个完成订单的平均总成本为`36+2.4444=38.4444`元；
- 若一个订单只取得一次56元收入，平均利润为`56-38.4444=17.5556`元。

检测次数还包含首轮筛选：每类零配件为得到一个合格件平均检测1.1111次，此后每个市场
坏品又复检一次。因此每个完成订单中，零配件1和零配件2的平均检测次数分别都是
`1.1111+0.1111=1.2222`次。

这些数字只演示当前临时口径的内部后果，不是情景1的策略比较结果。
