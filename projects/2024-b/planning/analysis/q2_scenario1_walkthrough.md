# 问题二情景1：单一固定方案全流程演示

> 状态：`S1_INTERPRET/provisional`。本文件用一个故意能够暴露循环歧义的方案帮助确认题意，
> 不是推荐方案，不是优化结果，也不是正式模型。

## 1. 官方参数

情景1的参数为：零配件1次品率10%、购买价4元、检测费2元；零配件2次品率10%、
购买价18元、检测费3元；两个正品零配件装配时成品次品率10%；装配费6元、成品检测费
3元、售价56元、调换损失6元、拆解费5元。

## 2. 本次演示方案

固定方案为：检测零配件1、不检测零配件2、不检测成品、拆解不合格品。四项决定在新购、
装配、市场退货、拆解和再投入的所有轮次保持不变。

为了把一条流程跑到底，本演示暂时采用四个尚未获用户确认的操作约定：

1. 以满足一个客户订单并最终交付合格品作为流程终点；替换品仍不合格时继续无条件调换。
2. 退回品拆出的两个零配件仍作为同一局部流程的可用件，不因退货而自动换成新品或与外部
   库存随机混配。
3. 售价56元只在原订单计一次；每发生一次市场不合格交付，就计一次6元调换损失。
4. 同一对合格零配件每次重新装配时，仍以10%的概率独立发生装配不合格；零配件自身质量
   在无损拆解后保持不变。

这些约定只为暴露分歧，用户可以逐项推翻。

## 3. 首轮生产

1. 购买一个零配件1，支付4元；按固定方案检测，再支付2元。
2. 若零配件1不合格，则丢弃，只重新购买并检测零配件1，直至得到合格件。每次尝试成本
   6元，成功概率90%，因此得到一个合格零配件1平均需要1/0.9次尝试，平均成本为
   6/0.9=6.6667元。
3. 购买一个零配件2，支付18元；按固定方案不检测，直接投入装配。
4. 支付6元装配。此时零配件1已经确定合格。成品不合格有两种来源：零配件2本身不合格，
   概率10%；零配件2合格但装配失败，概率0.9×0.1=9%。所以首个成品合格概率为81%，
   不合格概率为19%。
5. 按固定方案不检测成品，成品无论实际质量如何都直接进入市场。首轮进入市场前的平均
   成本为6.6667+18+6=30.6667元，不含后续调换和拆解。

## 4. 市场分支

### 4.1 首个成品合格

该分支概率为81%。客户正常收货，企业取得56元销售收入，流程结束。若零配件1第一次就
检测合格，这条实际路径成本为4+2+18+6=30元；若按零配件1筛选的长期平均成本核算，
进入市场前平均成本为30.6667元。

### 4.2 首个成品不合格

该分支概率为19%。由于企业没有成品检测，缺陷由客户发现。企业必须调换，并支付6元调换
损失。固定方案选择拆解，因此再支付5元，取回零配件1和零配件2。

拆出的零配件重新执行原固定方案：零配件1再次检测并支付2元；零配件2仍不检测；然后再
支付6元装配，替换品仍不做成品检测，直接交给客户。处理一个市场不合格品并制成下一件
替换品的直接费用为6+5+2+6=19元，不再重复计算已经拥有的两个零配件购买价。

若替换品仍不合格，就再次执行完全相同的调换、拆解、零配件1检测、装配和交付过程。

## 5. 不合格分支继续展开

在首个成品不合格的条件下：

- 以10/19的条件概率，原因是零配件2本身不合格。因为方案永远不检测零配件2，又暂定
  拆解后复用原件，所以这个坏零配件2会被无限次重新装配；每件替换品都必然不合格，流程
  永远无法结束，累计调换、拆解、零配件1检测和装配成本趋于无穷。
- 以9/19的条件概率，两个零配件都合格，只是本次装配失败。每次重新装配有90%概率成功、
  10%概率再次失败，最终以概率1结束。已知属于这个分支时，从当前坏成品开始，平均需要
  处理1/0.9=1.1111个市场不合格品，平均追加费用为19/0.9=21.1111元。

由于首轮有10%的绝对概率把真正不合格的零配件2投入这条无淘汰出口的回收循环，所以在
上述三个临时约定下，这套固定方案的流程以正概率永不终止，期望总成本和期望完成时间均为
无穷。这个结论只揭示题意与流程语义，不说明其他操作约定下仍会如此。

## 6. 请用户据实际语义纠正的节点

1. “无条件调换”是否意味着替换品仍不合格时继续调换，直至客户得到合格品？
2. 退回品拆出的零配件，是原样进入同一个订单的下一轮，还是进入公共库存并与其他件混配？
3. 若拆回一只始终不被检测的坏零配件，企业是否允许一直复用，还是存在题面未明说的报废、
   换新或最大循环次数？
4. 对拆回的零配件1，固定“检测零配件1”是否意味着每次再投入都重新检测并再次支付2元？
5. 56元售价是每个客户订单只计一次，还是每生产并交付一件替换品都另计一次收入？
6. 对同一组正品零配件反复装配时，10%的装配次品率是否每轮独立重新发生？
7. 指标究竟按一次初始投产、一个最终完成订单，还是长期稳定生产系统核算？

用户对这些节点的实际理解将决定S1的正式流程，而不是由本演示自行补齐。
