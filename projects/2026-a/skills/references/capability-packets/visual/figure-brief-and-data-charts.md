# 图件任务卡与数据结果图

适用于统计图、时间响应图、空间图、网络图、优化结果图和多面板结果图。选中本能力包后应完整读取；当前命中的规则原子仍拥有强度、适用范围和验收结论，本文件只说明如何把它们落实成图。

来源保留：V8 `04-figure-generator.md`、`27-visual-layout-acceptance.md`、`34-visuals-minimum.md`、`37-scientific-figure-design.md`；结合 V10–V14 的图件 identity、最小一致性闭包和人工审计边界重新组织。

## 先建立图件任务卡

绘图前先回答，不从“我要画什么图形”开始：

- 原题或当前工作的对应任务是什么；
- 图要帮助读者看见哪一种关系、机制、趋势、分布、空间结构、权衡或例外；
- 它支持哪条正文主张，该主张在什么条件下成立；
- 数据、运行结果、公式、拓扑或方案定义的权威来源是什么；
- 为什么图优于一句正文或一张表；
- 它与相邻正文、图或表各自承担什么不可替代的职责；
- 预期正文位置、最终栏宽和输出格式是什么。

若删除该图不损失必要信息，或它只能重复正文与表格，默认不画。不得用增加图数代替增加证据密度；也不得把关键结构、完整方案、阈值或权衡长期藏在代码和内部文件中。

正式稿中的新图类、关键主结果图或需要批量扩展的视觉系统，应先由人工确认任务卡。已经批准的同类图仅替换数据、修复标注或保持既定语义时，不重复索要形式确认；一旦比较对象、结论边界或视觉含义改变，应重新确认。

## 决定载体

- 一两个简单数字：优先正文。
- 小规模精确查询、完整清单、多字段逐项比较：优先表格。
- 趋势、分布、空间、路径、聚类、阈值和权衡：优先图。
- 图与表并存时：表负责精确查询，图负责结构、趋势、例外或权衡。

对图表执行双向删除检验：删除其中一个载体后若信息无损，则二者重复；若正文声称覆盖全部方案、条件或配方，主载体必须让读者实际看到这种覆盖，不能只展示少数代表案例。

## 先定义比较，再选图形

在写绘图代码前冻结：比较对象、基准、度量、单位、优劣方向、统计单位、筛选条件、方案版本，以及需要表达的不确定性或边界。

| 信息任务 | 首选表达 | 需要警惕 |
|---|---|---|
| 时间或迭代响应 | 共轴折线、相图、小倍图 | 时间顺序错误、平滑掩盖波动 |
| 分布与离群 | 箱线、经验分布、直方或密度 | 样本量隐藏、伪重复 |
| 参数扫描 | 曲线、等值图、小倍图 | 只展示有利区域、截轴夸差异 |
| 多目标权衡 | Pareto 图、权衡曲线 | 把加权分数冒充 Pareto 关系 |
| 空间与网络 | 坐标图、拓扑图、路径图 | 坐标系、边权和方向含义不明 |
| 小规模方案比较 | 点图、条形图或三线表 | 零点截断、排序制造暗示 |
| 不确定性 | 区间、带状区域、分布或情景小倍图 | 误差带来源不明 |

普通二维表达优先。双纵轴、面积编码、3D、透视、饼图堆叠和彩虹色阶只有在存在不可替代的信息收益且不会制造感知偏差时采用，并记录理由。

## 数据身份与生成闭环

本包中的正式定量图在语义计划中声明 `data_driven_visual=true`；这只是让 resolver 选中数据 identity 与禁止手改数值的完整规则，不代替下列人工核对。

正式图不能从聊天中的临时数字或未登记截图生成。至少核对：

1. 输入文件或正式结果的 identity 与图件登记一致；
2. 对象集合、筛选、单位、归一化、舍入和排序与当前结果一致；
3. 阈值、基准、误差带、置信区间和可行域的来源可以定位；
4. 生成脚本或可编辑源文件能从项目根稳定解析输入与输出；
5. 图源、矢量输出、审阅位图和论文引用指向同一图件版本。

数据或正式结果 identity 变化后，旧图即使文件仍能打开也不能继续被当作当前图。重新生成后同时复核正文数字、图注和直接消费者。

## 共享视觉语义

先建立项目级样式，再画单图。至少固定字体角色、最终字号、线宽层级、标记大小、面板编号、颜色语义、线型、单位格式、有效数字和图例顺序。

- 同一对象跨图保持相同颜色、符号和线型。
- 颜色只编码数据语义，不承担装饰职责。
- 关键差异必须同时由形状、线型、明度、标签或位置提供冗余编码。
- 避免红绿唯一对照和彩虹色阶；灰度打印仍应可辨。
- 网格线只在帮助读数时保留，并明显弱于数据。
- 图内不放论文式大标题和完整结论句，标题交给正文题注。
- 数学变量使用真实的上下标、希腊字母和数学符号，不以代码字符串冒充排版。
- 多面板图共享可比较尺度、边距、字体和面板字母位置；尺度不同时在图注说明。

若项目采用外部期刊或竞赛图件规范，先核验当期官方页面和适用范围。借鉴优秀图件时提取信息层级、比较设计、标注密度和视觉系统，不照搬其数据、结论或装饰。

## 图文解释闭环

每幅关键图在正文中形成：

`首次实质引用 → 图件 → 可直接观察的关系或现象 → 本问结论 → 条件、风险或决策作用`

图注说明对象、变量、条件和编码；正文负责分析。不得从坐标轴或图例直接跳到结论，不得用“如图所示”代替论证，也不得把相关性、局部案例或单一情景外推成因果或整体规律。

## 产物与人工确认

每幅正式图登记：图件 ID、信息职责、支持主张、输入 identity、生成器、输出文件、正文位置、题注状态、人工验收状态和未决问题。

对于关键主结果图或新的视觉系统，人工确认点为：

1. 批量绘制前确认任务卡和比较设计；
2. 一张高风险代表性样板通过后再扩展；
3. 在最终论文真实页内尺寸确认，而不是只看独立大图。

普通、低风险且沿用已批准样式的图，不机械增加三次确认；但最终渲染审计仍不可省略。
