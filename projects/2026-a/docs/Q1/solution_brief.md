# 问题1：圆柱药材径向传热与非线性水分扩散模型的建立与求解

## 1 问题重述

一根长25 cm、半径2 cm的近似圆柱形药材，初始各处温度为28 °C，干基含水率为2.55 kg水/kg干物质。根据附件给出的烘房温度、水分浓度及附录2的物性关系，建立预热平衡阶段的模型，计算开始烘干后1800 s内各径向位置的温度和含水率。

完整结果每1 s、每0.1 cm取样；摘要表列出100、300、600、900、1200、1500、1800 s及0、0.5、1.0、1.5、2.0 cm处的数值。结合圆柱形状与题给单一径向坐标，以下将所求分布解释为药材中部截面的分布。

## 2 问题分析

环境变化需要先通过药材表面的交换，再经内部传输影响中心。题目要求区分各个径向位置，因而必须同时表达外部交换和内部梯度，不能用烘房读数或一个截面平均状态直接代替所求分布。圆柱薄层的内、外表面积不同，应从带径向几何权重的收支建立方程。

附录2的热学参数为常数，扩散系数仅随含水率变化。因此，本问温度与含水率在数学上可以分别求解；水分方程本身仍是非线性的。热量和水分的传输时间尺度不同，模型需要说明在同一预热时段内，两种变化各自传播到哪里。

计算最需注意启动阶段。药材含水率初始均匀，表面却已存在向外交换的驱动力，短时内会形成陡峭梯度；圆心和表面也不能照搬普通内部节点公式。采用圆环控制体统一组织收支，再用隐式时间积分联立求新状态。离散环境观测通过分段线性插值进入边界，实际计算分辨率则由启动阶段的网格与时间精度对照确定。

## 3 模型假设

1. **中部截面满足轴对称径向近似。** 两场只随半径和时间变化，忽略该截面的轴向梯度；这与题给径向输出坐标一致，结果不用于解释端面附近的三维分布。
2. **侧表面交换沿周向一致。** 同一烘房环境作用于整个侧面，使交换条件与径向模型一致。
3. **相邻环境观测之间线性变化。** 仅使用0～1800 s的31个原始节点，以线性插值补足节点间输入，不作区间外推。
4. **采用题给水分数据的等效表面交换。** 题面给出的药材与烘房水分数据均按kg/kg数值使用，并给出传质系数，故交换项采用两者的数值差，记等效环境边界值Ceq=Y∞。这是本题的简化关系，不解释为材料实测吸附平衡律。

## 5 模型建立

### 5.1 已知条件与连续环境输入

已知量为几何、环境观测、物性关系及表面交换系数，待求量为T(r,t)、C(r,t)。表面状态是两场在r=R处的值，扩散系数由当前含水率确定，不另作参数拟合。初始条件为

```text
0 ≤ r ≤ R=0.02 m，0 ≤ t ≤ tf=1800 s，C(r,t)>0；
T(r,0)=Tinit=28 °C，C(r,0)=Cinit=2.55 kg 水/kg 干物质。      （1）
```

tf是本问计算时域的上限，不代表已经均温或烘干结束。计算保留t=0用于核对初态，正式结果从t=1 s取样。

表面交换需要在任意内部积分时刻求值，而环境每60 s才有一个观测。采用通过相邻原始节点的直线，既保留观测，又不额外引入曲率。令tj=60j s，j=0,…,30，gj为某一环境量的节点读数，则

```text
θ=(t−tj)/(tj+1−tj)，g(t)=(1−θ)gj+θgj+1，tj≤t≤tj+1；
g 分别取 T∞ 或 Y∞，Ceq(t) := Y∞(t)。                       （2）
```

θ为0～1内的无量纲权重，因此区间内输入不越过两端观测的范围。两种环境量分别按式（2）重建，保持原单位；Ceq表示Y∞在水分边界中的作用，不是药材表面含水率。线性重建补足的是计算输入，不能提高实测时间分辨率。

### 5.2 圆柱薄层的热量与水分收支

取半径a～b的圆柱薄层，0≤a<b≤R，体积元为2πLr dr。按Fourier定律计算两侧导热量，热量积累等于净传入量；约去共同因子2πL，得到

```text
d/dt [ρcp ∫a^b T(r,t)r dr] = [rk ∂T/∂r]a^b；
ρcp ∂T/∂t = (1/r) ∂/∂r [rk ∂T/∂r]
           =k[∂²T/∂r²+(1/r)∂T/∂r]，0<r<R，t>0。         （3）
```

方括号表示在b处取值减去在a处取值，ρcp是单位体积热容量。式（3）的1/r项来自圆柱内外层面积随半径变化，体现了本问与平板传导的区别。

以干基含水率为状态，按附录2的扩散系数建立Fick型有效扩散收支：

```text
d/dt [∫a^b C(r,t)r dr] = [rD(C) ∂C/∂r]a^b；
∂C/∂t = (1/r) ∂/∂r [rD(C) ∂C/∂r]，0<r<R，t>0。           （4）
```

积分表示归一化含水储存量，尚未乘以转换为真实水质量所需的干物质量因子。扩散关系及其链式展开为

```text
D(C)=7×10⁻⁹ exp(−0.89/C) m²/s，C>0；
D′(C)=0.89 D(C)/C²，∂D/∂r=D′(C)∂C/∂r；
∂C/∂t=D(C)[∂²C/∂r²+(1/r)∂C/∂r]+D′(C)(∂C/∂r)²；
α=k/(ρcp)=1.6885553×10⁻⁷ m²/s。                           （5）
```

D′是D对C的导数，0.89与题给kg/kg的代入口径配套。展开后除圆柱几何项外还有D′(C)(∂C/∂r)²，说明不能把变系数散度直接简写成D乘圆柱Laplace算子。下文离散完整通量，已保留这一作用；D′还进入隐式迭代的导数矩阵，不再另加同一项作源项。正含水率下D为正，变干会降低局部扩散能力；附录2的D不含温度变量。

### 5.3 中心对称、表面交换与短时响应

轴对称要求中心径向导数为零；以向外为物理通量正方向，侧表面采用第三类边界条件：

```text
∂T/∂r(0,t)=0，∂C/∂r(0,t)=0；
−k ∂T/∂r(R,t)=h[Ts(t)−T∞(t)]；
−D(Cs) ∂C/∂r(R,t)=hm[Cs(t)−Ceq(t)]，t>0；
Ts(t)=T(R,t)，Cs(t)=C(R,t)。                              （6）
```

Ts、Cs为待求表面状态。空气温度高于Ts时热量传入，Cs高于Ceq时水分迁出。有限的h、hm允许表面与环境保持差异，所以边界条件必须保留表面交换过程。

起始时内部含水率均匀，径向梯度为零，但Ceq(0)=0.01963已明显低于2.55。初值与表面导数条件在起始角点不相容：均匀初态在t=0成立，交换条件在t>0作用，由方程形成短时表面梯度。计算应保留这一响应，而不是先把表面改成环境值。

尺度估计说明了为什么需要同时解析两场。以R/2为特征长度，热Biot数hR/(2k)=0.6944，初始等效传质Biot数hmR/[2D(Cinit)]=1.6202，均不支持忽略内部阻力。以R为扩散长度，1800 s的热、水分Fourier数分别为0.7598和0.0222，预示热响应可更充分地向内传播，水分变化则更集中于外层。这些估计指导模型选择，实际分布仍须求解。

### 5.4 圆环控制体、端点处理与初始变化率

先在圆环上积分，再计算界面通量之差，可以保留圆柱体积权重，并避免直接在r=0计算1/r。半径等分为N段，节点位于圆心、表面及中间径向位置；相邻节点的中点为控制体界面：

```text
Δr=R/N，ri=iΔr，i=0,…,N；
ai=max(0,ri−Δr/2)，bi=min(R,ri+Δr/2)，vi=(bi²−ai²)/2；
v0=Δr²/8，vi=riΔr（1≤i≤N−1），vN=RΔr/2−Δr²/8；
Σi=0^N vi=R²/2。                                         （7）
```

ai、bi是第i个控制体的内外边界，vi为去掉2πL后的体积权重，单位m²。节点值ui近似相应位置的场值，viui近似该控制体的归一化存储。径向步距相等，外层圆环的体积仍更大；中心和表面的截断控制体权重也不同。

图1-1 圆柱截面与径向控制体划分。(a)圆形截面中的节点与环带；(b)对应的径向控制体。圆点表示状态节点，虚线位于相邻节点中点；蓝色环带标出一个内部控制体，浅橙环带为真实边界截断的表面半控制体，填色不表示含水率。箭头表示均匀初态下的表面向外水分交换，此时内部面通量为零；节点数、间距及箭头长度用于示意。

图中每个环带对应一个存储单元；共享界面上的一次交换，同时是一个单元的流出和相邻单元的流入。用u统一表示T或C，温度的存储系数s=ρcp，水分的s=1，则半离散收支为

```text
s vi dui/dt = Hi+1/2−Hi−1/2，i=0,…,N。                    （8）
```

H沿径向正梯度方向定义，向外的物理传输量为−H。内部界面以两点差近似梯度，界面物性取相邻节点系数的算术平均；两端通量直接来自边界条件：

```text
ri+1/2=(ri+ri+1)/2；
Hi+1/2=(ri+1/2/Δr) Ki+1/2(ui+1−ui)，i=0,…,N−1；
温度场：Ki+1/2=k，H−1/2=0，HN+1/2=Rh(T∞−TN)；
水分场：Ki+1/2=[D(Ci)+D(Ci+1)]/2，H−1/2=0，
        HN+1/2=Rhm(Ceq−CN)。                             （9）
```

温度H的单位为W/m，水分H为m²/s×含水率单位。非线性水分面系数平均的是D(Ci)、D(Ci+1)，不是先平均C再代入D。将端点权重代入式（8），得到

```text
温度中心：dT0(t)/dt=4α[T1(t)−T0(t)]/Δr²；
水分中心：dC0(t)/dt=4K1/2[C1(t)−C0(t)]/Δr²；
表面节点：duN/dt=[Rb(g−uN)−HN−1/2]/(s vN)，
          (b,g)=(h,T∞) 或 (hm,Ceq)。                     （10）
```

这里T0(t)、C0(t)指中心节点状态，与初始常数Tinit、Cinit区别；b、g分别为对应交换系数与环境输入。中心式与轴对称极限相符；表面仍保留有限体积的存储，因此不把它改成无存储代数约束，也不再附加半网格阻力。

这套收支直接给出启动方式。初态所有内部状态差为零，且T∞(0)=28 °C，只有表面水分交换非零：

```text
dTi/dt(0)=0，i=0,…,N；dCi/dt(0)=0，i=0,…,N−1；
dCN/dt(0)=Rhm[Ceq(0)−Cinit]/vN<0。                      （11）
```

因此先有表面失水，再形成相邻圆环之间的浓度差与扩散；温度随环境升温逐渐响应。由于vN约为RΔr/2，固定网格上的初始表面变化率绝对值按1/Δr增长。细网格能分辨短时梯度，也增大离散系统的初始表面变化率，下一节须用联立迭代和误差接纳处理这一变化。

对光滑场，内部面梯度与平均系数具有中点二阶精度。表面直接代入Robin通量，半控制体积分残差除以体积后，其节点变化率局部残差一般只有一阶。不能据内部面近似就把全部节点统称为二阶；整体输出是否足够精细，由第8.2节实际加密验证。

### 5.5 非线性处理：隐式BDF与解析稀疏Jacobian

把一个场的全部节点组成状态向量，空间离散转为常微分方程组：

```text
y(t)=(u0(t),…,uN(t))ᵀ，dy/dt=f(t,y)；
y(0)=Tinit·1（温度场）或 Cinit·1（水分场）。              （12）
```

y的分量保留相应场的单位，1为全1向量。温度右端为线性，水分右端含D(C)而非线性。扩散的最快时间尺度随Δr²缩小，细网格会使显式稳定步长很小，故采用自适应隐式BDF推进，并利用相邻节点依赖构造稀疏导数矩阵。

新时间层由存储变化与当前通量共同确定。本次积分器含NDF修正，其实际残差为

```text
F(yn)=yn−ŷ+ψ−c f(tn,yn)=0；
ŷ=Σj=0^q Bj，ψ=(Σj=1^q γj Bj)/aq，c=Δtn/aq；
γj=Σm=1^j 1/m，aq=(1−κq)γq。                            （13）
```

tn为当前内部时间，Δtn为步长，q为1～5的自适应阶数。Bj是按当前步长组织的状态差分向量，B0为上一已接受状态；ŷ是预测值，ψ是历史修正，均与y同单位且在当前非线性求解中固定。γj、aq无量纲，c单位为s。κ1～κ5依次为−0.185、−1/9、−0.0823、−0.0415、0，是时间公式修正系数。

首次计算没有多层历史。设积分段从ts及已知y⁰开始，先按面通量求f⁰=f(ts,y⁰)，以B0=y⁰、B1=Δt f⁰初始化，并从q=1起步。式（13）此时化为

```text
ŷ=y⁰+Δt f⁰，ψ=Δt f⁰/1.185，c=Δt/1.185；
1.185(y¹−y⁰)−0.185Δt f(ts,y⁰)−Δt f(t1,y¹)=0。           （14）
```

式（14）中已知的是初态、初始变化率与环境，待求的是整层y¹。预测值仅提供迭代起点；旧层导数项来自NDF启动，并非额外物理项。接受首步后才积累更多历史、调整阶数，因此不能把实际首步写成纯后向Euler。

图1-2 径向—时间计算网格与隐式耦合示意。交点表示uiⁿ≈u(ri,tn)，蓝色实心点为已知历史，橙色空心点为本层未知；粗横线表示本层相邻节点直接耦合，竖箭头表示同列历史输入。斜虚线表示整层联立后的跨层影响，不是额外差分项或全部影响路径；节点数和时间间距仅为示意。

图中一条横线的未知量需同时求解，不能沿半径逐点显式推进。控制体界面仍位于径向节点中点，时空矩形不是物理控制体；首步历史不足时使用式（14）。

在预测状态下形成残差后，采用Newton型修正：

```text
[I−c J*] δy=−F(y(k))；
y(k+1)=y(k)+δy。                                         （15）
```

I为单位矩阵，k为当前步内迭代序号，δy为修正量，J*=∂f/∂y是当前使用、按需更新的解析Jacobian。每次迭代重新计算残差，通过稀疏线性方程直接求修正，不显式求逆。自身及左右邻点决定每一行，因此J为三对角矩阵；若使用式（14）的缩放残差，首步矩阵等价为1.185I−ΔtJ*。

非线性导数必须同时包含“梯度改变”与“扩散能力改变”。对水分面通量，令p=ri+1/2/Δr、δ=Ci+1−Ci、D̄=[D(Ci)+D(Ci+1)]/2，则

```text
∂Hi+1/2/∂Ci   =p[D′(Ci)δ/2−D̄]；
∂Hi+1/2/∂Ci+1 =p[D′(Ci+1)δ/2+D̄]。                      （16）
```

p无量纲，δ与C同单位，D̄单位m²/s。这两个面导数以相反符号加入相邻控制体，并分别除以存储权重；表面另有−Rhm/vN。温度场用常数k代替面系数并除以ρcp，表面导数为−Rh/(ρcpvN)。D′项使迭代与原通量一致，每次右端仍使用当前C下的D(C)，并未把模型改为常扩散系数。

每步先以缩放后的修正量及其收敛率判断非线性迭代，再检查局部时间误差：各分量误差除以“绝对容差+相对容差×新状态绝对值”，其均方根不超过1才接受。误差过大则减步重试；非线性失败时先更新导数矩阵，仍失败再减步。这给出了状态更新与接受的完整规则，空间误差另行检验。

### 5.6 总收支与体积平均

所有控制体相加时，内部交换自动抵消，只留下外表面输入。由此定义体积均值及累计交换量：

```text
ρcp Σi vi dTi/dt=Rh(T∞−TN)，Σi vi dCi/dt=Rhm(Ceq−CN)；
ū(t)=(2/R²)Σi vi ui(t)；
IT(t)=∫0^t Rh[T∞(τ)−TN(τ)]dτ，
IC(t)=∫0^t Rhm[Ceq(τ)−CN(τ)]dτ；
ρcp Σi vi[Ti(t)−Tinit]=IT(t)，Σi vi[Ci(t)−Cinit]=IC(t)。   （17）
```

ū分别为体积平均温度、含水率；IT、IC是去掉公共几何因子的累计热输入与归一化水分输入，τ为积分时间。均值按全部计算节点的体积权重求得；收支关系则用于核查环境交换与内部存储变化是否一致。

## 8 模型检验与敏感性分析

上述径向差异能否作为本问结论，取决于两个层次：方程的几何、边界和非线性项是否被正确计算，以及启动梯度是否被足够细地分辨。两者分别检查，避免把“换网格后结果相近”同时当成实现与精度的全部依据。

### 8.1 几何、边界与非线性通量的独立核对

为检查D随C变化时是否漏项，在非均匀正含水率场上独立重建面通量与含D′的Jacobian。两场右端相对差均小于2.2×10⁻¹⁵，导数差达到预设容差，说明实际非线性迭代与第5节推导一致。

这类逐项核对仍可能共享几何或边界错误，因此进一步用圆柱Robin边界的Bessel解作独立参照。实际常系数温度采用512个模态，在1～1800 s的21个输出位置上最大差为3.2531×10⁻⁷ °C；另将水分D固定为初值4.9376551×10⁻⁹ m²/s，以1024个模态检查特例，最大差为5.9884×10⁻⁶ kg/kg。两项均小于各自5×10⁻⁵的比较目标，模态加倍差均低于各自10⁻⁷的截断目标。由此核对圆柱几何、表面交换和时间输入；正式水分关系仍是D(C)。

收支方向则由一个简短结构关系核对。恒定环境g下，正的传输、交换系数给出

```text
d/dt [½Σi s vi(ui−g)²]
 =−Σi=0^(N−1) (ri+1/2 Ki+1/2/Δr)(ui+1−ui)²
  −Rb(uN−g)² ≤ 0。                                      （18）
```

s、K、b沿用式（8）～（10），右端各项非正，表示内部均匀化及趋近环境的耗散方向。平衡场、关闭表面交换后的内部相消和式（17）的累计收支均与推导相符。累计量与状态来自同一积分器，只提供内部一致性证据；实际环境变化时不由式（18）推断全程单调。

### 8.2 启动梯度对空间与时间分辨率的要求

第5.4节表明，启动时表面变化快，后期平滑剖面不能代表全时域的计算难度。因此取全部规定输出点，分别改变空间网格和时间设置。用u表示温度或含水率，Ωout表示共同取样范围，定义

```text
Espace(u)=max[(t,r)∈Ωout]|u2N(t,r)−uN(t,r)|；
Etime(u)=max[(t,r)∈Ωout]|utight(t,r)−unominal(t,r)|。     （19）
```

其中tight、nominal为收紧及主时间设置，两场按各自单位计算最大绝对差。本问Ωout覆盖1～1800 s的全部1800×21个规定点；N依次取160、320、640、1280、2560、5120，保持其余设置比较相邻网格；再固定N=5120，把相对与绝对容差缩小10倍。

## 9 模型评价

圆柱控制体把内部传输、圆心和侧表面放进同一收支，能够逐式核对端点处理；非线性面导数与稀疏隐式求解又使解析启动梯度所需的细网格可计算。代价主要是表面短时响应带来的空间规模，题目只要求21个输出位置，并不意味着21个计算节点已经足够。

本问结论受中部径向近似、题给物性和等效水分交换关系限定。附件缺少内部温湿实测，也未给物性的不确定区间，所以现有检验支持数值求解的一致性与分辨能力，不能给出真实药材的预测准确率。后续改用另一问的题给物性时，可复用圆环收支与算法原理，仍需重新建立相应反馈。

## 10 问题1结论

在附录2物性、固定半径、中部径向近似和等效交换条件下，模型给出1～1800 s、0～2 cm的温度与含水率。1800 s时中心/表面温度为33.5753/36.7856 °C，体积均值35.1679 °C；中心/表面含水率约为2.5500/1.5102 kg水/kg干物质，体积均值2.2936。

预热期间温度已在全半径明显上升，失水仍主要集中外层。独立参照核对了几何和边界，实际网格与时间细化支持这一分布差异；result1及两张摘要表据同一数值解生成。
