# 问题4：固定网格论证的补充推导

本文件保存主稿压缩前的圆环离散、存在唯一性、不变范围、耗散与严格阈值完整论证，供进一步核查。以下局部公式编号沿用压缩前版本（9）—（16），不作为当前主稿的公式编号引用。

研究对象为材料坐标 ξ∈[0,1] 上的温度 Θ 与干基含水率 U；R(t)>0 来自实测半径重建，材料按均匀径向比例缩放。物性采用附录4：ρ=760+90U，cp=1850+2150U/(1+U)，s=ρcp，k=0.12+0.20U/(1+U)，D=4.2×10⁻⁴exp[−0.30/U−3850/(Θ+273.15)]。换热系数 h=25 W/(m²·K)，传质系数 hm=8×10⁻⁷ m/s；初态 Θ=28°C，U=2.55 kg/kg。环境按附件1重建，4 h后 g=0.04999041666666667 kg/kg。

这些推导针对固定有限网格的连续时间系统。它们不构成连续非线性PDE的全局强解或网格收敛证明，不保证任意BDF步长保正，也不把所采用的干基近似升级为真实两相质量与总能量的完整守恒闭合。

### 5.4 随材料运动的圆环离散

将0≤ξ≤1等分为N段，节点ξi=iδ、δ=1/N。相邻面位于两节点中点，中心边界取0、外边界取1。定义

```text
vi=(ξ_{i+1/2}²−ξ_{i−1/2}²)/2，qf=ξ_{i+1/2}/δ；
v0=δ²/8，vN=δ/2−δ²/8，Σi vi=1/2；
kf=(ki+ki+1)/2，Df=(Di+Di+1)/2。                     （9）
```

vi是无量纲材料圆环权重，实际圆环面积还含R²。选择圆环控制体，是为了直接按每个材料圆环的收支离散：相邻节点共享同一面通量，在两侧以相反符号记入，内部交换求和时自然相消。记Bi(a,z)为所有相邻面的qf af(z邻−zi)之和，则

```text
vi si Θ̇i=R⁻²Bi(k,Θ)+δiN(h/R)(T∞−ΘN)；
vi U̇i=R⁻²Bi(D,U)+δiN(hm/R)(g−UN)。                 （10）
```

δiN仅在表面取1。中心通过自身圆环收支处理，没有直接除以ξ=0；表面控制体仍有储存，不由环境值覆盖。R缩短扩散距离，也改变面积与体积之比，两种作用都由式（10）保持。

式（10）以交错状态y=(Θ0,U0,…,ΘN,UN)联合隐式推进。物性导数与热储存分母项为

```text
k′=0.20/(1+U)²，s′=90cp+ρ·2150/(1+U)²；
DU=0.30D/U²，DΘ=3850D/(Θ+273.15)²；
∂Θ̇i/∂Uj=(∂Ai/∂Uj)/(vi si)−δij Θ̇i s′i/si。       （11）
```

Ai表示式（10）温度行右端。R是外给时间函数，对状态求导时不增加Ry或R′项。Jacobian是两场变化率对各节点温度、含水率的导数矩阵，包含温温、温湿、湿温、湿湿四块。DΘ项表示Newton线性化中温度对水分变化率的影响；保留该项可使解析Jacobian与耦合右端一致。

径向网格越细，相邻节点间扩散的快速变化越明显，而整体干燥仍持续较长时间，这种快慢变化并存使显式推进容易受到稳定步长限制。因此采用后向差分公式BDF作隐式时间积分，在新时刻联合求两场；通过Newton迭代处理局部物性随未知状态变化的非线性。式（11）提供迭代所需导数，相邻节点间的局部耦合又使矩阵稀疏。这些选择分别回应时间稳定性、非线性和计算规模，实际精度仍需由第8.2节的网格与时间对照检验。

### 5.5 固定网格的存在唯一性与不变范围

取初态及全部环境输入的上下界，构成正值矩形

```text
θ−=min(28,inf T∞)，θ+=max(28,sup T∞)；
c−=min(2.55,inf g)>0，c+=max(2.55,sup g)；
K={y：θ−≤Θi≤θ+，c−≤Ui≤c+，i=0,…,N}。              （12）
```

在已明确输入的任意有限时域，R有正下界，K又远离绝对零度和U=0，故固定N的右端对状态局部Lipschitz。输入断点之间连续，分别求得局部唯一解，并在断点处连续接续状态；4 h边界跳变按右侧输入继续。某分量达到K的上界时，全部邻点差及相应外界差非正；达到下界时方向相反。正面系数、正容量及正R不会改变这个方向。

更具体地，令PK为矩形投影，e=y−PKy，在其邻域取关于状态的统一Lipschitz常数Lf；在每段内几乎处处有

```text
(1/2)d|e|²/dt=e·f(t,y)
≤e·[f(t,y)−f(t,PKy)]≤Lf|e|²，e(0)=0。              （13）
```

Gronwall不等式推出e=0，解保持在紧集K中，因而不会在有限时间内碰到物性奇点或爆破，可逐段唯一延拓。结论针对固定有限网格的连续时间系统；它不要求完整耦合Jacobian具有非负非对角元。

### 5.6 收支、最终达标与严格阈值

内部面相消给出

```text
Σi vi U̇i=(hm/R)(g−UN)；
Σi vi si Θ̇i=(h/R)(T∞−ΘN)。                          （14）
```

第一式是归一化随体含水收支，第二式是温度方程的瞬时储热—导热收支。它们用于核对面符号和半径缩放，不等同于完整材料总水质量或总热量的守恒式。

4 h后g固定。取t0=14400 s、t≥t0，置wi=Ui−g、E=(1/2)Σviwi²，将水分方程乘wi再求和：

```text
E′=−R⁻²Σf qfDf(wi+1−wi)²−(hm/R)wN²≤0；
E≤(N+1)[wN²+Σf(wi+1−wi)²]/4；
amin=min(Dmin minf qf/Rmax²，hm/Rmax)>0；
E(t)≤E(t0)exp[−4amin(t−t0)/(N+1)]。                  （15）
```

第二行由每个节点沿相邻链连接到表面的表达及Cauchy–Schwarz不等式得到，Dmin来自K上的正下界。若半径有始终为正且有界的延续，式（15）使每个节点最终趋近g<0.15，从而在有限时间后达标。这个保守界只证明最终可达，不能据此声称终点必在72 h以内。

停止条件保持问题三的全域量词：

```text
MN(t)=max[i=0,…,N]Ui(t)，c*=0.15；
τN=inf{t≥0：MN(t)<c*}；
nend=min{n∈正整数：MN(n)<c*}。                        （16）
```

本题全部边界输入满足g<c*。沿已确定轨迹，水分偏差Ui−c*构成正相邻连接的线性系统，表面有严格负强迫。这里只把沿轨迹的通量系数视为已知时间函数；有限时间区间上这些相邻系数正且有下界，逐次沿链使用变常数公式可知任意正时间差的传播矩阵元素严格为正。首次进入Ui≤c*闭矩形后，传播矩阵将负的表面强迫传至全部节点，故任意更晚时刻所有Ui<c*。于是连续严格集合的左端是下确界，通常在该端点本身仍等于阈值。

本文采用首个严格达标整数秒作保守报告，这是所选结束行规则，并非题目强制将时间量化为整数秒。数值计算先定位穿越，再用实际完整节点状态检查前一整数秒与结束秒：前者最大值≥0.15，后者最大值<0.15。显示四位小数的表格不能代替这一检查。位置是否在中心，也由全部节点的最大值确定。
