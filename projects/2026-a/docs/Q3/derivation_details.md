# 问题3：固定网格可解性与严格达标的推导细节

本说明保留固定径向网格系统的完整数学论证。主讲解稿已给出相同结论的短证明；这里展开正值范围、衰减常数和严格正传播三个步骤。证明对象是半离散常微分方程，不涉及连续偏微分方程的全局强解定理，也不承诺BDF在任意步长下保正。

## 1 方程与条件

半径R=0.02 m保持固定，将其等分为N段，ri=iΔr、Δr=R/N，i=0,…,N。控制体内外半径分别为max(0,ri−Δr/2)与min(R,ri+Δr/2)，vi为两者平方差的一半，故vi>0、Σi vi=R²/2。vi乘2πL后才是体积。每个节点有温度θi和干基含水率Ci，初值为28°C、2.55 kg水/kg干物质。

局部物性按附录3定义：

```text
ρ(C)=650+128C，cp(C)=1450+2736C/(1+C)，s(C)=ρ(C)cp(C)；
k(C)=0.21+0.38C/(1+C)；
D(C,θ)=2.4×10⁻³ exp[−0.45/C−3850/(θ+273.15)]。         （1）
```

ρ、cp、s、k、D的单位依次为kg/m³、J/(kg·K)、J/(m³·K)、W/(m·K)、m²/s。C>0、θ>−273.15°C时，所有系数光滑且为正。表面交换系数h=25 W/(m²·K)、hm=8×10⁻⁷ m/s。对相邻节点j=i+1，定义共享面的正系数，系统为

```text
qij=(ri+rj)/(2Δr)；
aᵏij=qij(ki+kj)/2，aᴰij=qij(Di+Dj)/2；
vi si θ̇i=Σ[j∼i]aᵏij(θj−θi)+δiN Rh(T∞−θi)；
vi Ċi=Σ[j∼i]aᴰij(Cj−Ci)+δiN Rhm(g−Ci)；
y=(θ0,C0,…,θN,CN)，ẏ=f(t,y)。                         （2）
```

δiN只在表面取1。内部同一个共享面的系数相同；两侧流入符号相反。温度与含水率保持当前模型的有效储存口径，水分方程的加权和不直接等同于真实水质量。

环境T∞、g有界，前4 h按60 s节点线性插值，在4 h右侧允许切换为常值。全程g(t)>0且g(t)<c*=0.15，环境温度远高于绝对零度。tb=14400 s之后，主情景取T∞=49.995916666666666°C、g=0.04999041666666667。所有输入断点处连续传递状态，微分关系按分段或几乎处处意义理解。

```text
MN(t)=max[i=0,…,N]Ci(t)，c*=0.15；
t*=inf{t≥0：MN(t)<c*}；
nend=min{n∈正整数：MN(n)<c*}。                          （3）
```

这些定义使用全部N+1个节点。固定N是以下每个命题的前提，时间阈值最终仍要由实际数值轨迹确定。

## 2 正值范围、存在性与唯一性

要沿数值动力系统寻找停止时刻，首先需要说明它能持续给出有意义的状态。下面检查物性始终有定义、状态不会越过输入所限定的范围，以及解能否延续到所需时域。

由初值和已定义的全部环境输入取上下界：

```text
θ−=min(28,inf T∞)，θ+=max(28,sup T∞)；
c−=min(2.55,inf g)>0，c+=max(2.55,sup g)；
K={y：θ−≤θi≤θ+，c−≤Ci≤c+，i=0,…,N}。                （4）
```

本题θ−>−273.15°C、c−>0，故K位于式（1）的光滑正值区域。任意固定有限N下，体积权重均为正，f对状态局部Lipschitz，因此先有局部唯一解。

若某个含水率分量达到自身上界，邻点差与表面环境差都非正，正面系数使其导数非正；在下界时方向相反。温度行除以正的热容量，仍有相同方向性。为了把这一点转成不会越界的论证，在固定单位下取矩形投影PK，令e=y−PKy；温度和含水率也可先作固定正比例缩放，再使用欧氏范数。在K的小邻域取Lipschitz常数Lf，有

```text
(1/2)d|e|²/dt=e·f(t,y)
≤e·[f(t,y)−f(t,PKy)]≤Lf|e|²，e(0)=0。               （5）
```

第一步不等式来自投影边界向内的导数方向。Gronwall不等式推出e始终为零，因而K正向不变。K是正值定义域中的紧集，f在其上有界，解不会在有限时间内爆破或碰到物性奇点，故可以唯一延拓到每个有限时域。环境断点处连续传递状态，上述微分论证在各连续区间及几乎处处意义下成立。

这证明的是固定网格连续时间系统，尚不是非线性连续偏微分方程的全局强解定理。它也不要求完整热质Jacobian的所有非对角项为正。

## 3 长期衰减与阈值有限可达

在tb之后，主情景g为常数且小于c*。令zi=Ci−g，以加权平方量衡量整个截面偏离边界状态的程度：

```text
E(t)=(1/2)Σi vi zi²；
E′(t)=−Σ[i=0,…,N−1]aᴰi,i+1(zi+1−zi)²−Rhm zN²。      （6）
```

E的单位为m²乘含水率平方。将式（2）的水分方程乘zi并求和，每个内部面产生一个负的相邻差平方，外表面产生负的zN平方，得到式（6）。温度可以仍随时间变化，面扩散系数仍为正，所以这种耗散关系保留。

仅有E不增还不能推出在有限时间跨过阈值。由不变矩形的紧性，D在其上有正下界d*。将相邻面系数简记为qi=q_i,i+1，置a*i=qi d*、b=Rhm，则a*i和b均为正。对任意节点，沿相邻节点连到表面，写成`zi=zN−Σ[j=i,…,N−1](zj+1−zj)`。加权Cauchy–Schwarz给出

```text
zi²≤[1/b+Σ[j=i,…,N−1]1/a*j]
     ×[b zN²+Σ[j=i,…,N−1]a*j(zj+1−zj)²]；
Σi vi zi²≤KN[b zN²+Σ[j=0,…,N−1]a*j(zj+1−zj)²]；
KN=Σi vi[1/b+Σ[j=i,…,N−1]1/a*j]<∞。                  （7）
```

KN的单位为秒。这个界利用了每个节点都能通过正传导系数连接到有交换的表面；若表面没有交换或链条断开，就不能照搬该论证。将式（7）与式（6）合并，得到

```text
E′≤−2E/KN；
E(t)≤E(tb)exp[−2(t−tb)/KN]；
max_i|Ci(t)−g|≤√[2E(tb)/vmin]exp[−(t−tb)/KN]，
vmin=min_i vi>0。                                     （8）
```

因为c*−g>0，右侧最终小于这段正距离，全部节点便严格低于c*。因此固定N系统在有限时间后会达标，式（3）的整数停止时间存在。d*取整个状态范围的最小值，可能非常保守，所以式（8）用于证明最终可达，不用它代替数值时长。

## 4 严格达标集合与整数秒报告

最终能够达标还不足以确定应报告哪个结束时刻。本节进一步说明穿越阈值后是否会返回，并区分连续穿越时刻与可直接核对严格不等式的报告时刻。

本题的观测输入及主情景尾段延续都满足g(t)<c*。令t0为首次进入Ci≤c*闭矩形的时刻。连续性使MN(t0)=c*，否则可以把进入时刻向前移动。令wi=Ci−c*，沿已经确定的实际轨迹，把式（2）的正面系数看作时间函数，则水分偏差满足

```text
w′=A(t)w+β(t)；
Aij(t)=aᴰij(t)/vi>0（相邻节点），
βN(t)=(Rhm/vN)[g(t)−c*]<0，其余βi=0。                （9）
```

A的对角元由相邻流出和表面交换给出。相邻系数为正且网格连通，意味着表面的负强迫能在任意正时间间隔传到每个节点。具体地，令Φ(t,s)为式（9）齐次系统的传播矩阵。在任意有限时窗取足够大的常数μ，使A+μI逐元非负；其传播矩阵的迭代积分展开各项非负，从表面到节点i的相邻路径又提供一个严格正的积分项。乘回正因子exp[−μ(t−s)]不改变符号，因此Φ非负，且t>s时ΦiN(t,s)>0。变参数公式给出

```text
w(t)=Φ(t,t0)w(t0)+∫[t0,t]Φ(t,s)β(s)ds；
wi(t)<0，对所有i及t>t0；
{t：MN(t)<c*}=(t0,∞)，t*=t0。                         （10）
```

第一项非正；第二项对每个节点严格为负，所以进入阈值闭矩形后会严格进入内部并保持。这里的正传播针对沿轨迹的水分系统，不把完整耦合Jacobian误说成具有相同符号结构。

式（10）解释了“首次严格达标”的细节：严格集合的左端点是下确界，该时刻的最大含水率等于阈值，故左端点不是该开集合的最小元素。本次主数值轨迹的穿越发生在4 h之后，满足本段条件。连续定位保留阈值到达的时间信息；首个严格达标整数秒则给结果表提供可直接核对的结束行，避免仅按分钟采样推迟报告。整数秒是本次报告尺度，并非题目额外规定。

数值上还要逐整数秒核对MN，保留nend−1尚未达标、nend已经达标的未舍入数值。这样既能检查浮点事件定位附近的严格不等式，也不依赖可能同样显示为0.1500的四位小数；仅对事件返回时间向上取整不足以完成这项核对。
