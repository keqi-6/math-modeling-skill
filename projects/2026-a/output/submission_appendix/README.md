# 附录与合稿材料

本目录用于完成论文附录和支撑材料的最后合稿。结构以队伍2025项目的定稿为主要范例：**参考文献 → 附录A文件清单 → 附录B程序**；按2026年现行要求，AI工具使用声明放在参考文献之前，附录B列出自编程序全文。

## 发给队友

- [附录与合稿素材.zip](附录与合稿素材.zip)：包含下列LaTeX源稿、完整支撑材料和新版PDF，解压后保持`assembly/`与`support/`相邻。
- [附录PDF](附录.pdf)：只含附录A文件清单与附录B完整程序，优先查看这一份。
- [附录合稿预览](附录_合稿预览.pdf)：在同一附录之前接入AI声明与参考文献，供检查合稿衔接；不是包含摘要和正文的参赛论文。
- [附录内容源稿](assembly/appendix.tex)：修改文件清单、小节说明和程序排列的位置。代码由`support/code/`等源文件直接读入，无另存的代码节选。

两份PDF共享上述同一内容源稿。使用XeLaTeX在`assembly/`中编译：`xelatex appendix_standalone.tex`生成单独附录，`xelatex main.tex`生成含声明和文献的合稿预览；重复编译至引用稳定。这两个入口仅负责不同预览范围，不是两份独立内容稿。

接入已有论文时，将`ai_statement.tex`、`references.tex`、`appendix.tex`分别放到相应位置，并在导言区引入[代码与表格局部样式](assembly/code_style.tex)。`preamble.tex`只供本目录的独立预览使用，**不要整体导入队友论文**，以免改写正文的页边距、字体或标题。已有同名宏包按需合并加载选项。保留源码相对路径，或随论文目录一起调整`../support/`路径。

本次版式参照2025定稿：正文宋体与Times New Roman，主标题14磅黑体、小标题12磅黑体，代码9磅Consolas、灰色6磅行号，跨页重复程序文件名。文件清单按用途分为四张三线表，图件以基名与扩展名明确列出全部文件；长代码行仅在显示时续排。A4预览的四边设为2.8cm，以便保留不少于2.5cm的实际正文边距。这些字体、字号和配色属于队伍版式选择，不是组委会统一规定。

完整预览使用Windows中已安装的宋体、黑体、Times New Roman和Consolas，不分发字体文件。移至其他系统时，应先适配预览入口与`preamble.tex`的字体；局部代码样式提供DejaVu Sans Mono与Fandol回退，重新编译后仍需检查真实页面。

`references.tex`提供可读题录，`references.bib`提供BibTeX条目，两者是两种接入方式，不应在同一稿中重复排两份书目。`reference_usage.md`说明每项文献能支持的具体内容，`optional_references.bib`保存备选条目。最终文末只保留正文实际引用的文献，按首次引用顺序调整编号，不将候选清单直接当作全文已经引用的证据。

## 支撑材料

[支撑材料候选ZIP](支撑材料_待合稿确认.zip)对应`support/`目录，包含可移植的完整程序、原始观测与模板、四份现有结果表、8幅选用图件及其数据、参考文献题录，以及当前AI工具使用详情。模型代码的运行方法见[运行说明](support/README.md)，图件编辑与重绘方法见[图件说明](support/figures/README.md)。

已有结果表保存在`support/results/`；重算使用独立输出目录。图件提供PDF、SVG和PNG，选用的网格图为交点网格版本，问题一径向剖面保留五个时刻。新增圆环控制体示意，问题二用正负贡献条说明扩散系数的本构变化，问题三用径向达标进程替代干燥折线。模型检验中的数值对照由讲解稿的紧凑表格承载。可直接复用图件；正文最终采用的图号、图注、解释和参考文献由队伍合稿时统一。

[AI工具使用详情](support/<未收录-AI工具使用详情>.)采用队伍共同商讨并明确指定的版本，来自项目`docs/<未收录-AI工具使用详情>.pdf`。文件原样收录，包含队友的AI使用信息；文字、页码、排版及元数据均未修改。短声明片段`assembly/ai_statement.tex`直接采用该报告第5节“团队声明”原文。当前收到的是PDF，没有附带其LaTeX源稿；此前由AI整理的详情及源稿已退出当前材料包。

压缩包只收录`support/`白名单材料。队友原稿、讲解稿、内部复核、外部个人解题答案、运行历史和工作环境没有列入其中。`assembly/`中的引用取舍说明和本阅读入口属于合稿材料，不在支撑材料候选ZIP内。

便携入口已完成三次主网格复算，耗时约2.24、159.72、106.50秒。四份工作簿共700,929个单元格与现有结果一致；问题三、四的连续达标时刻和整数结束秒也一致。这证明了本次代码整理与已有计算的数值一致性，不替代队伍对论文模型及结论的审核。

## 合稿与提交前衔接

1. 按最终正文确认引用条目、图件及其编号；如删换文件，同步附录A清单。
2. 将附录并入整篇论文，保持页码连续，检查整篇论文和支撑材料分别满足20 MB限制；附录不另作为论文上传。
3. 由队伍完成最终内容核对后提交。现有支撑材料候选已使用WinRAR封装，大小及逐文件哈希见`support_manifest.json`；压缩包已与支撑目录逐文件核验。如果合稿后文件有删换，重新同步清单并封装。

现行依据：[2026年论文格式规范](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)、[2026年AI工具使用规定](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)。具体赛区补充要求以队伍收到的通知为准。本目录完成的是附录与材料准备，整篇论文的书写、取舍及最终提交由队伍负责。
