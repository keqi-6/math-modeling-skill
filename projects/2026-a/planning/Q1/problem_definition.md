# 问题1：问题定义与证据计划

本文件依据原始题面第1页的问题1、第3页的附录1–2，以及附件1和result1模板形成。它界定任务与验证需求，不选择或冻结数学模型。

题面解释的集中勘误见[模型解释修订说明](../model_explanation_corrections.md)。本文件采用该说明中的题意口径，冻结计算规格及旧运行身份保持不变。

## 1. 现实对象与目标

研究一根长25 cm、半径2 cm、初始温度28°C、初始干基含水率2.55 kg/kg的近似圆柱形药材。在给定烘房温度和水分浓度变化的条件下，计算开始烘干后1800 s内不同径向位置的温度与含水率。

这是带初始条件和边界输入的传输过程预测问题，不是参数寻优或统计回归问题。没有药材内部实测温湿数据，不能用附件1代替药材内部观测来拟合“预测准确率”。

本问包含：题意解释、环境输入读取、初边值问题、数值解、题面要求的表格、验证及结论边界。后续各问的变物性、全程结束时间和收缩不纳入本问答案。初始条件在计算中使用t=0，正式模板从t=1 s开始。

## 4. 定义中需要保留的边界

题目给出0–2 cm的单一距离坐标，要求中心到表面的分布；结合圆柱几何，采用中部截面的径向模型是自然解释。轴向影响属于这一近似的适用范围，可用扩散尺度说明；只有需要进一步考察端面时才引入二维对照。

附件1覆盖到14400 s，本问仅使用0–1800 s，不需要外推。1 s是输出间隔，不能当成输入实测间隔或强制求解器步长。原始60 s节点之间的环境边界重建方法会改变输入曲线，正式使用前需记录选择。

附录2的热学系数固定，D只依赖C。因此，在导热与有效水分扩散框架中，温度方程不依赖C，水分方程不依赖T，两场可分别求解。该解耦是本问采用方程的性质。1800 s是题目规定的输出时限，不表示该时刻药材已达到均温或干燥完成。
