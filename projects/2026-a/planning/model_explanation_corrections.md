## 3 Q4辅助推导的充分条件

为核对干基变量与通量的关系，暂以b表示单位当前体积的干物质质量，v表示骨架速度，j_w表示相对骨架的水通量。在干物质无源且随骨架运动的辅助守恒描述下，先有：

```text
∂t b + div(bv) = 0，
∂t(bC) + div(bCv + j_w) = 0。
第二式减去C倍第一式，得到 b D_tC = −div j_w。
若 j_w = −bD∇C，则
D_tC = div(D∇C) + D∇ln(b)·∇C。
```

因此，b空间均匀是得到当前随体扩散式D_tC=div(D∇C)的一种**充分条件**；它不是一般必要条件，例如附加内积项为零也可得到同一约化。原规格“只有……才有”的说法过强。

若进一步假定无轴向体积变化、纯径向均匀应变及均匀初始b，辅助连续方程才给出b(t)=b₀[R₀/R(t)]²。表面R(t)及“未求轴向运动”不能自动提供全部这些前提。此辅助说明用于界定所选干基输运近似，不新增b作为求解变量，不改变附录4的ρ定义，也不把当前简化方程说成已完整证明所有材料组分与能量守恒。
