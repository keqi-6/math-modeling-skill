## 物性关系及实际变化

左侧以曲面、底面等值线和实际状态轨迹展示 D 对温度 θ、干基含水率 C 的依赖，右上用一维关系展示 k(C)，右下比较中心与表面在 3 h 时的 ln(D/D₀) 变化。升温项与失水项来自题给指数函数的精确对数分解，黑色短竖线为二者代数和；D₀ 指初始 θ=28°C、C=2.55 kg/kg 时的扩散系数。

曲面覆盖 28–50°C、1–2.55 kg/kg 的矩形状态范围，实际状态轨迹只是其中一部分，不能将整个曲面称为完整模型敏感性实验。底面投影只帮助读取状态位置，没有增加一个新的物理场。k 没有题给公式之外的温度依赖。

与上一版相比：由两个等大的三维面板改为一主两辅；取消三维透明网纹和粗重轨迹描边；以关系图和正负贡献图承担不同的阅读任务。

## 水分分布与温差演变

上排为 0、0.5、1、2、3 h 的含水率圆截面，所有圆半径为 2 cm，色标统一为 0–2.55 kg/kg。白圈为 C=2.0 kg/kg 的等值线；该值不在当前截面的值域内时不画圈，不把它解释为材料边界或独立干燥锋面。

左下的径向温差定义为

\[
\Delta\theta(r,t)=\theta(r,t)-\theta(0,t),
\]

以 0–3.5°C 的共用色标展示温度相对中心的差异，并标出 1、2、3°C 温差等值线。该量随过程减小反映径向温度趋于均匀，不等于全体温度保持不变。

右下展示每一时刻的中心含水率、表面含水率与截面面积平均含水率。面积平均定义为

\[
\overline C_A=\frac{2}{R^2}\int_0^R C(r)r\,\mathrm dr.
\]

横轴 0.8–2.6 kg/kg 已显式标注，图中使用点位置与端点间跨度，不是从零累计的柱形。此处的面积平均不冒充按干物质质量加权的整体含水率。

与上一版相比：保留空间水分图作为主图，取消几乎纯色的温度大圆；以温差图显示预热中的空间差异；以区间及标记补充截面图不便精确读取的数值关系。
