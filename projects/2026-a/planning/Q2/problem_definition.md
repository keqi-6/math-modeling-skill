## 1. 当前问的对象和目标

问题1已有结果、代码和待审事项保留。其数值结果不是本问输入；只复用仍适用的概念解释及实现经验。用户允许以后依据新发现重启相关问题，届时按真实变化定位受影响部分。

## 3. 附录3与单位

令θ表示药材摄氏温度，进入扩散公式时取T_K=θ+273.15。C始终为药材干基含水率，不能替换为湿基质量分数；C/(1+C)是经验式本身给出的比值。

\[
\rho(C)=650+128C,
\quad c_p(C)=1450+2736\frac{C}{1+C},
\]
\[
k(C)=0.21+0.38\frac{C}{1+C},
\quad D(C,\theta)=2.4\times10^{-3}
\exp\!\left(-\frac{0.45}{C}\right)
\exp\!\left(-\frac{3850}{\theta+273.15}\right).
\]

| 量 | 单位及自变量 |
|---|---|
| ρ | kg/m³；当前局部C |
| cp | J/(kg·K)；当前局部C |
| k | W/(m·K)；当前局部C |
| D | m²/s；当前局部C与药材温度T_K |
| θ、T∞ | °C；分别为药材局部温度和烘房温度 |
| C | kg水/kg干物质 |
| Y∞ | 烘房水分浓度，题面记为kg/kg |

初态直接代公式：ρ=976.4 kg/m³，cp=3415.295774647887 J/(kg·K)，k=0.48295774647887324 W/(m·K)，D=5.641680373025668×10⁻⁹ m²/s。这些是参数手算检查点，不是场求解结果。

附录3没有另列换热与表面传质系数。主候选延用附录2的h=25 W/(m²·K)、hm=8×10⁻⁷ m/s，并明确这是对同一工艺中未修改系数的延用解释。参数进入规格时应逐项列明来源，不能把附录2的ρ、cp、k或D公式一起带入。
