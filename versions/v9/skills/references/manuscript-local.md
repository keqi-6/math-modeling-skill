# 论文局部修改契约

只在用户明确要求局部修改，并且目标产物已经存在时使用。先界定修改面：目标字符或句子、所在段落、被其直接引用或消费的位置。

## 可保持局部的修改

- 错别字、标点、空格和不改变含义的排版错误；
- 不改变术语、数字、单位、符号、结论强度和章节职责的单句润色；
- 已有图表的纯位置或引用编号修复，且身份不变。

执行后检查目标句、整个段落和直接引用点。不得因为这些修改自动触发全文或全项目审计。

## 必须扩大检查面的修改

若修改改变术语、符号、单位、数据身份、数值、假设、模型定义、结论强度、图表含义或章节职责，搜索所有直接消费者并将任务重新路由到论文起草、模型、验证、图表或完整审计。不得把语义变化伪装成局部润色。

只修改用户授权范围。若发现无关缺陷，报告而不顺手扩写。完成声明仅覆盖实际检查过的局部范围。
