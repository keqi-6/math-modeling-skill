# V7 职责审计与处置表

状态：第一轮文件级审计完成；原子能力级审阅仍在进行。

## 判定规则

- **控制权威**：决定能否做、处于什么状态、何时回退和谁能批准，只能由 `SKILL.md` 拥有。
- **过程主责**：说明已获准工作如何实施，可以详细、包含例外和操作顺序。
- **来源保留**：保存外部方法论或经验规则及其强度，不直接授予权限或作最终通过判定。
- **验收交叉检查**：从成品侧独立检查，不复制过程所有权。
- **最低交叉检查**：跨版本、跨实现的最低质量底线，不取代详细过程。
- **原生补丁**：修复此前所有层都未完整覆盖的独立能力；验证成熟后再决定是否并入长期主责。
