## 引用纪律

- **[B/C, 06-01] 杜绝"有文无引"**：参考文献必须在正文用 `\cite` 引用。
  **[B, 06-02]**审计时比较正文实际引用键集合与文献条目键集合，并分别报告未定义
  引用和未被正文使用的条目；简单计数不能证明一一对应
- **[B, 06-03] 附录在正文引用**（"详见附录一"），不能凭空出现
- **[C/D, 06-04；B, 06-05]**新进展优先近年高质量来源；基础定义和经典算法应引用
  原始或权威来源，不能机械排除旧文献
- **[C/D, 06-06]**文献语种由正文证据需求、可获得的权威来源和官方要求决定；不设
  中英文配额，也不为凑语种引用弱来源

### 引用挂载
- **[B, 06-07；D, 06-08]**方法首次出现处挂引用（Dijkstra 定义处挂原始论文，
  最短路径模型处挂教材）
- **[B, 06-09]**是否补充中文教材由正文实际使用决定，不为满足语种配额强行引用
- **[A, 06-10]**严禁编造不存在的中文论文

### 编号验证
**[C, 06-11]**手工 `thebibliography` 必须按正文首现顺序重排。
```python
import re
c = open('paper.tex').read(); body = c[:c.find('thebibliography')]
seen = []
for m in re.finditer(r'\\cite\{([^}]+)\}', body):
    for k in m.group(1).split(','):
        if k.strip() not in seen: seen.append(k.strip())
bibs = re.findall(r'\\bibitem\{([^}]+)\}', c)
print(seen == [b for b in bibs if b in seen])
```
**[A, 06-13]**编译后 `grep -c "Citation.*undefined" paper.log` 必须为 0

## 表述规范

- **[B, 06-17]**每句话都要有信息量
- **[B/C, 06-18]**能定量说的就不定性描述
- **[D, 06-19/06-20]**较长章节或段落可用主题段、主题句帮助读者定位来意；短段、
  承接段或单一功能段不为满足形式机械添加
- **[B/D, 06-21]**因果链显式："因为A，所以B，因此C"

## 模型建立与求解的小节结构

先在无标题提纲中理清建模步骤的先后关系，再判断哪些步骤并列、哪些从属于上一步，
最后设置标题。不得把预设标题当作模型逻辑本身，也不得依靠改变低级标题字号制造并
不存在的层级。

**[C/D, 06-24]**每项建模任务应按题型和推理依赖覆盖以下内容职能：
1. 模型建立（把数据准备、变量定义和模型准备作为其内部四级内容）
2. 模型求解
3. 问题结论
4. 检验分析（按声明风险选择灵敏度、独立验证、反事实或复算）
5. 小结（在需要时概括本问，并在下一问真实依赖其口径或结果时说明承接关系）

**[B/C, 06-27/06-28]**《数模论文模板（修改版）》用五个三级标题展示上述内容框架，
但本工作流经用户确认不把示例机械固化为标题配方。多任务论文必须为各项任务设置
醒目、无歧义且与原题一致的标题入口；标题数量、层级和名称由实际并列、从属、推理
依赖及定位价值决定。摘要中的主要模型或亮点必须能通过正文标题快速定位。

真正展开内容的标题下面必须有正文。纯归类的上级标题可以直接接第一个子标题，不为
隔开标题补写空洞报幕段。任务标题后先概括本问的模型链条；若模型章节继续分出变量、
约束和目标等低级标题，应先说明这些部分怎样共同构成完整模型。

## 公式规范

- **[A, 06-32]**所有公式数学模式，不能是图片
- **[C, 06-33；A/B, 06-34]**单行公式居中，被引用的统一编号
- **[A/B, 06-35]**变量前后一致，符合常规习惯
- **[D, 06-36]**模型章节只有少量编号公式可作为“是否省略关键定义、约束或推导”的
  诊断信号；公式数量本身不构成空心化证据

## 图表格式增量

- **[A/C, 06-37]**坐标轴标注名称与物理单位
- **[B/C, 06-38]**图随文走：正文先作首次实质引用，图表紧跟引用段落，图后立即解释
  关系、现象及其结论意义，形成连续局部闭环
- **[B, 06-39]**全文图风格一致（线条/色彩/字体）
- **[D/C, 06-40；B/C, 06-41；A/B, 06-42；D/C, 06-43]**表格数字右对齐、
  小数位统一、注明单位、避免跨页

## 评委三大误区

1. **[B/D, 06-48]**评审只能依据实际可见的论文与获准支撑材料判断成果；应按当届
   交付边界把关键证据放入正确载体，不能假定评委能看到内部过程
2. **[B/D, 06-49]**"数学编程不行就去写作" → 写作手必须懂模型
3. **[B/D, 06-50]**格式缺陷会降低可读性、证据可见性或模板合规性；按实际缺陷报告，
   不声称存在未经证实的固定降档规则
