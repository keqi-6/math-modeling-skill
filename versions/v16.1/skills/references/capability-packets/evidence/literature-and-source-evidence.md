# 文献检索、来源评价与主张绑定

适用于领域语义、方法灵感、候选路线、参数依据、现实边界、官方规则和外部主张的调查与核验。联网与下载仍需当前工具和权限；本包不因提供检索程序而授予外部写入。

本包提供现有 `EVD-LITERATURE-001` 的实施方法，不新增状态、审批门或证据要求。`EVD.SEARCH.CLAIM_FIRST` 的规范效果允许明确的主张或研究决定；没有候选时可以从需要解决的问题出发，不必先虚构一个等待文献证明的结论。

来源保留：V8 `08-literature-search.md`、`12-source-audit-and-provenance.md`、`28-evidence-acceptance.md`，结合 V14 的 input/claim identity 和时效性边界。

## 何时需要检索

当前问出现以下任一情况时进行定向检索：

- 团队不熟悉领域对象、过程、制度或业务背景；
- 题面外变量、代理指标或中间产物需要现实解释；
- 需要识别公认问题类别、主要方法族或验证方式；
- 参数、阈值、误差范围、指标或适用边界需要外部依据；
- 稿件要使用“通常、已有研究、机理表明、官方要求”等外部主张；
- 法规、标准、竞赛规则、软件接口或政策可能已经变化。
- 用户明确要求查资料、寻找灵感或比较研究路线；
- 候选过窄、求解受阻、结果异常或现实解释不协调，并且缺口可能来自领域知识、方法条件或验证依据。

完全由题面定义的确定性任务可以不检索，但记录为何不使用外部主张。“已有代码”“时间紧”或“AI 知道”不是充分理由。

调查服务于当前问的真实缺口：陌生机理和方法空间在正式选模前调查；实现、验证或结果解释暴露新缺口时可以重新调查。继承仍适用的共享来源，只补新对象、条件或问题；普通代码错误和已有规格下的机械操作不自动触发搜索。

## 以研究问题或主张为检索单元

先辨明调查用途：

- **问题探索**：当前对象具有怎样的机制或数学结构；哪些方法可能解决当前难点；它们分别依赖什么条件。产出是候选解释、方法与待检验想法。
- **主张核验**：哪个来源能够支持、反驳或限制主张 C 在范围 R 内成立。产出是可追溯的依据及允许主张的边界。

两者可以连续进行，但一篇文章带来灵感不等于其结论已成为本题证据。把查询绑定到要解释的对象或要做的决定，不以宽泛主题堆论文，也不只替既定模型寻找支持。

按对象、机制、数学结构、场景、指标、时间和来源类型组合查询。可以分四轮：

1. 语义轮：实体、指标、制度职能和系统边界；
2. 选模轮：主要方法族、适用条件和替代方案；
3. 规格轮：假设、参数、基线、评价指标和验证设计；
4. 边界轮：现实推广、遗漏机制和时效性。

不得先凭常识固定模型，再只搜索支持既定选择的材料。文献前候选可作为关键词，但必须允许调查后新增、修改或淘汰。

## 从文献发现方法并迁移到本题

1. **先看当前可用材料。** 定位题面、附件、已有文献库和用户提供的参考稿，区分官方输入、领域资料、方法参考与往届作品，明确缺什么。已有材料没有覆盖的问题再联网补足；不可访问的全文如实记录。复盘时的当年讲评、赛后优秀论文或答案，在正在进行的比赛中可能尚不存在，不能把它们写成启动前置条件。
2. **从问题结构构造查询。** 组合研究对象/过程、数学结构、目标/约束、数据条件与当前困难；领域叫法不确定时，先寻找中英文同义词或邻近学科的称呼。除了题名和已知算法名，也搜索结构相同但应用不同的研究，例如资源分配、部分观测下的停止决策或耦合动力系统。语言与检索入口按证据覆盖选择，不设固定配额。
3. **拓宽后回溯。** 用综述、教材和代表性研究建立方法族与争议点，再沿关键引用定位原始定义、推导、适用条件和验证。对真正可能改变选择的方法读取相关正文；只看摘要的候选保留其阅读边界。找到熟悉算法不代表调查完成，还应查替代解释或失败条件。
4. **按条件迁移。** 比较原研究与本题的对象、目标、变量/约束、数据规模、可识别性和可计算条件。提取可迁移机制或求解结构，说明需改动什么、哪些条件不成立。参考代码只帮助理解实现，不能代替数学条件核对。
5. **转成可检验候选。** 在现有导向稿或候选比较中写清“来源中的方法/机理 → 对本题的具体启发 → 适用差异 → 能区分候选的最小检验 → 保留、修改、排除或待确认”。检验可以是手算情形、反例、数据能力分析或获授权的试算；检索本身不授予运行外部代码、求解或重算权限。

可以从阅读中得到新的派生变量、可视化方式、结构化求解、精度检查或论文论证顺序，不限于挑选模型名称。向用户说明这些发现如何改变当前判断，而不是把书目数量或术语列表当作灵感产出。

## 优秀论文、参考作品与实现材料

优秀论文和相近项目可用于发现方法角色、问题分解、图表职责、验证设计与表达顺序；它们不具有高于本题官方输入和独立证据的地位。当前比赛只使用实际可获得且符合当期要求的材料，不能预设存在本题完整答案。

关键借鉴核对正文公式、实验条件、结果口径与可取得的附录/代码是否相符。若它们冲突，记录冲突并追溯原始依据；有启发价值的方法可以继续作为候选，但错误或未核验数字不能成为验证真值。外部数字的正式比较与消费者准入仍按下节既有边界办理，不另造比较门。

## 来源身份与位阶

| 主张类型 | 优先来源 |
|---|---|
| 当前规则、日期、格式、资格 | 当期官方文件或发布机构 |
| 数据定义、口径和版本 | 数据发布者与原始元数据 |
| 算法定义、方法效果 | 原始论文、权威教材、官方技术文档 |
| 领域脉络 | 高质量综述并回溯关键原始文献 |
| 软件行为和接口 | 对应版本官方文档或源码 |

搜索结果页、摘要片段和 AI 回答只用于发现候选，不能承担正文证据。只有摘要可读时不能标为已阅读全文；往届答案、营销教程和方法清单不能证明事实、机理或最优性。

时效性主张在实际使用时重新联网核验。旧版本记录只能说明历史要求，不能自动成为当期规范。

## 阅读和记录

对实际采用的来源至少记录：稳定 ID、标题/作者/年份、DOI 或原始 URL、访问日期、来源类型、阅读范围、版本/页码、支持或反驳的主张、适用条件、限制和许可处置。

记录载体服从项目现有引用系统，不为满足模板同时创建多个重复台账。关键是能够从主张定位来源，也能从来源定位它被用于何处。

来源的本地副本要有合法取得路径和 identity；引用元数据、全文 identity 与稿件引用一致。引用主题相关但没有实际支撑当前主张属于装饰性引用。

## 外部数值的用途与消费者边界

外部数值不能只登记“有来源”，还要区分它在当前项目中的角色：

- 题面、当期官方规则或正式数据中的输入；
- 有文献依据、经当前模型采用的外部参数或阈值；
- 用于 E4 现实映射或正式方法比较的外部基准；
- 被当前项目仅用于候选启发、异常排查或内部回归告警的公开论文、复现或历史答案结果数值；
- 当前项目自己的正式运行输出。

对前四类至少记录 `source_authority`、`use_role`、`support_scope` 和 `permitted_consumers`。被登记为 `internal_regression` 或 `candidate_hint` 的外部答案数值，不得进入论文、已触发的人类讲解、正式答案主张或验收证据；引用完整也不会改变这个用途。若团队确实要把外部结果作为正式文献比较，先明确改变其用途，核对可比对象、输入、指标、候选域、精度和来源身份，再允许对应消费者使用。

这不是“所有外部数字禁入稿件”。题面常量、经批准的外部参数、现实基准和正式文献比较可以进入相应位置，但必须就近说明来源角色和它能支持什么。一个本项目独立计算值即使与公开结果舍入后相同，只要绑定自己的输入、规格、运行和验证 identity，仍是本项目输出；数值相同不能证明抄录。反过来，一个来源可靠的公开答案只要仍被登记为内部告警，就不能因“看起来正确”自动晋升为正式结果。

## 文献导向稿

复杂或关键子问可形成一份人可审阅的导向稿，包含：

- 需要外部证据回答的具体问题；
- 领域对象和候选机理；
- 方法族、条件、局限及与本题数据的匹配；
- 对数据处理、模型、图表和验证的具体影响；
- 本题证据与文献相容、矛盾或无法区分之处；
- 可进入论文的主张与禁止照搬的结论；
- 每个外部数值的用途角色、允许消费者与不可承担的验收责任；
- 仍未解决的问题。

它是人工讨论材料，不因写入文件成为选模权威。人工确认的是文献带来的关键方向与主张边界，不是逐篇批准引用格式。

## 防止知识污染

- 规则来源和规则强度分开；讲座或优秀论文不能整组升级成硬规范。
- 教材算法核对名称、假设、复杂度和当前软件接口。
- 示例代码先核对数学含义；确需运行时按当前项目授权和执行边界安排试验。未运行只记录代码阅读范围，不因检索或借鉴请求自行执行。
- 当前题目的节点、数值、路径和答案不进入通用 skill。
- 用户反馈先转成跨项目触发条件、动作和可检查结果；一次性偏好留在项目层。
- 历史时间线只能基于日志和产物 identity 推断，不能补造时间戳、动机或交互原话。

## 完成判断

检索完成不以文献数量或数据库数量判定，而看：关键外部主张有身份匹配的来源；阅读状态诚实；来源如何改变或约束当前分析清楚；其他体系和尺度没有无条件移植；人工理解了实质选择和边界。

探索阶段以足够支持下一研究决定为收束点：主要可行方向及其条件已清楚、关键反对证据已处理、剩余未知不会被伪装成已知。找不到合适来源时区分“没有检索到”“全文不可读”和“现有证据不支持”，可继续不依赖该缺口的推导或保留待验证候选，不把检索失败写成不存在方法或自动通过。后续新证据仍可重新打开调查；不强制跑满四轮、固定数据库或凑齐篇数。
