# E3/E4：模型结构检验与现实映射

适用于检验模型内部是否自洽、假设和机制是否支持主张，以及有现实数据或可靠基准时确认模型在预定用途上的适用性。E3/E4 与 E1/E2 分轴登记。

来源保留：V8 `09-robustness-checker.md`、`25-model-results-acceptance.md`、`32-verification-minimum.md` 和 `36-uncertainty-error-analysis.md`；采用 V14 的四轴证据边界。

## 从主张的实质失败风险选择检验

建立：

`模型主张 → 最可能失败的结构/现实条件 → 检验操作或数学关系 → 预先判据 → 结果 → 证明边界`

不要机械要求每题都做灵敏度、交叉验证或固定百分比扰动。所选检验必须能够推翻或收窄当前主张，而不是只产生另一张好看的图。

## E3：模型内部结构

根据模型类型选择具有信息增量的检查：

- 可行性、资源平衡、守恒和约束残差；
- 量纲、退化情形、边界行为、极限和解析特例；
- 单调性、对称性、凸性、稳定性或不变量；
- 参数可识别性、共线性和等价解；
- 约束消融、机制反例和最小反例；
- 与简单基线或关键替代模型的差异；
- 离散化、候选域和连续现实之间的边界。

每问至少有一项针对其核心结构风险的 E3 实质检验。内部哈希、字段对账、重复计算和另一实现同值属于实现层，不能冒充模型结构检查。

在语义计划中，先声明粗粒度 `structural_verification`，再按实际风险声明至少一个专项事件：约束、已知不变量、极限/解析特例、能推翻高影响主张的反例，或可变输入/结构选择的敏感性。专项事件只选择对应 atom；未被选择的菜单项记录不适用理由即可，不通过同时广播五项事件制造形式覆盖。`validate_structure` 只做 E3，`assess_reality` 只做 E4；只有确实同时执行两轴时才使用兼容动作 `validate_model`。

## E4：现实映射与用途确认

有实测、实验、留出观测或可靠现实基准时，检查：

- 数量级、方向、范围和场景覆盖；
- 参数是否可由现实资料识别；
- 预测、决策或排序在预定用途上的误差；
- 假设适用域、分布漂移和外推边界；
- 机制方向与已知现实过程是否一致；
- 结果是否可被领域使用者解释和执行。

机制核验检查模型表达的过程方向、约束和相互作用；reality fit 再比较观测模式、范围、语境和用途。二者不是“数量级看起来合理”。

没有可辩护现实对照时，E4 可以按题面理想用途记为 `justified_not_triggered`，但必须绑定当前模型规格 artifact identity，引用一个已解决的人工适用性决定，给出非触发依据，并明确保留“现实适用性、经验预测和部署有效性未确认”的禁止宣称边界；规格变化后原 N/A 自动失效。机器只能核验结构、身份和决定状态，不能替代人工判断理由真伪。不能把 E3 成功升级成现实证明；裸 N/A、把可获得却未检查的现实证据说成不存在，或用 N/A 隐藏已经观察到的现实失配，都不能关闭 E4。

## 比较和消融

对比模型时，保持输入、候选域、评价指标和验证预算一致。记分牌至少说明拟合/决策表现、复杂度、稳定性、解释性、失败条件和计算代价。

消融应只移除待检机制，其他条件尽量不变；若移除同时改变候选域或数据口径，结论必须注明。加入复杂机制若不改善预定风险或主张边界，应保留简单模型。

## 主张强度

把观察分为：计算事实、模型内解释、现实支持和因果/政策外推。E3 通常支持前两层；E4 的强度取决于现实设计、覆盖和识别条件。相关、局部案例、理想情景和单一数据集不能自动支持普遍规律或因果。

## 失败和重开

失败不是撰写一段“局限性”就关闭。先定位假设、对象映射、候选域、结构、参数或用途边界，返回最早受影响阶段。仍绑定未变化输入和主张的证据保留；受影响结果、图表、摘要和结论精确失效。

## 论文可见性

每问至少在正文中展示一项实质模型检验，说明对象或风险、设置或操作、预先判据或指标、观测结果、结论强度和边界；不要求同名章节，也不要求把 E3/E4 逐项做成标题。读者必须看到该检验为什么能推翻、收窄或增强当前模型主张，而不是只看到“通过”标签。

模型检验的正文责任是报告证据，不是另建模型。需要独立较强数学合同的辅助反例生成器、表面求值器、替代模型或敏感性实现，其完整推导和明细进入内部技术证据；正文保留上述对象—设置—判据—结果—边界链。若某个替代模型实际承担核心机制比较、正式共同求解或必要证明，应将它提升到模型建立或允许的附录中完整解释，而不能一面依赖它形成结论，一面以“内部验证”隐藏。

简单的极限关系、约束残差定义或有助理解 oracle 的公式可以出现在检验说明中；本边界不以公式数量或算法复杂度判定越界。它约束的是内容归属和主张强度，不增加 S7 门，也不要求每次局部编辑重新运行模型验证。
