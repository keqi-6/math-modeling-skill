# 正式交付、提交合规与人类责任

适用于最终论文、支撑材料、复现包和正式发布前审计。它只组装已经通过相应内容与证据检查的材料，不替代建模、验证、稿件或视觉审计。

来源保留：V8 `11-paper-finalizer.md`、`12-source-audit-and-provenance.md`、`35-provenance-delivery-minimum.md`；删除了过时年份和固定模板断言，保留“当期官方要求优先、真实记录、人类实质控制、白名单交付”。

## 先确认适用规范

记录项目用途、适用赛事/机构/期刊、年份或版本、截止时间、匿名要求、页数/格式、源码与支撑材料、数据许可、AI 使用和其他披露义务。

这些要求具有时效性，正式交付时重新读取当期官方文件；往届、学校、期刊或模板规则不能替代当前明文要求。官方文件冲突或存在真实解释取舍时提交人工决定。

## 交付白名单

从最终消费者反向列出必要文件，而不是把整个工作区打包：

| 对象 | 需要核对的身份 |
|---|---|
| 数据 | 来源、版本、哈希、许可与处理谱系 |
| 代码 | 正式入口、环境、参数、种子和运行说明 |
| 结果 | 运行 ID、指标、单位、验证与输出哈希 |
| 稿件 | 唯一源入口、最终渲染、引用和图表版本 |
| 外部材料 | 原始来源、访问日期、许可、用途角色、允许消费者和披露处置 |

排除缓存、临时中间量、环境凭据、旧候选、无法授权再分发的材料和与提交无关的个人信息。压缩包完成后实际列出成员、解压/打开代表文件并核对包 identity。

同时排除登记为内部回归、候选启发或内部诊断的外部答案数值，以及非主辅助验证器的完整强数学合同；它们可以保留在项目内部技术证据中，但不因“已经验证”“有引用”或“有助答辩”自动进入论文和交付包。题面/官方输入、经批准的外部参数、现实验证基准和正式文献比较不受一刀切排除，但必须与当前稿件主张、来源许可和登记的消费者一致。

若用户明确要求把逐问讲解作为交付物，或已有明确人类交接触发该讲解，才把它加入白名单并核对其消费者边界；未触发时不为交付机械创建讲解稿，也不把九项语义覆盖当作 S7 或发布门。

## 稿件与支撑材料一致性

- 最终 PDF 来自唯一当前源入口，而不是平行 Word/Markdown/旧 LaTeX 镜像。
- 摘要、正文、图表、结论、引用、附录和支撑材料指向同一结果与图件 identity。
- 每条主要主张能够反向到正式输出、验证、规格和原始输入。
- 每个外部数值和辅助验证方法的公开程度符合登记用途；内部专用内容未混入摘要、正文、图表、附录、讲解或包内说明。
- 代码和数据说明足以复现当前允许的范围，不用文件清单冒充实际要求的源码。
- 匿名、页数、字体、元数据、文件名、大小和格式按当期规则核验。

技术日志、编译成功和文件存在不能替代对最终 PDF 页面、引用、附件和提交包的人工检查。

### 附录与可执行支撑材料

参考队伍往届定稿时提取当期仍适用的代码展示、图表索引和引用组织方式，不沿用旧年文件名、版式或提交字段作为本年要求。逐项对齐题目要求的时间范围、空间位置、精度、文件名与列结构；供后问或内部检验使用的完整计算轨迹，不因已生成就进入前问提交表格。

整理代码保留能复现当前声明范围的入口、依赖、参数及其输入输出说明；排版为附录的代码与供执行的源码同源。参考文献对应实际采用并审阅的来源，图片对应稿件真实引用，三者各有索引与用途；不把环境、全部试验脚本和未采用图片整体打包。若发现最终图件无法打开，按[最终文件故障排查](../visual/render-and-audit.md#最终文件打不开时)定位，不只复查临时渲染。

## AI 使用与披露

只根据真实保存的工具、版本、日期、用途、关键交互、采纳范围、人工修改和验证记录形成披露。能逐字恢复的内容才作为原话；只能从日志确认主题时，明确标为重建摘要。

区分：

- 表达整理；
- 候选讨论、形式化、代码或分析等实质性辅助；
- AI 辅助编写代码后由真实数据确定性生成的图；
- 模型直接合成或实质修改像素的生成式图像。

具体标注位置和材料形式以当期官方要求为准。不能用一段笼统声明替代明文要求，也不能把“工作链中出现过 AI”直接写成“全部成果由 AI 生成”。

团队提供整合后的声明且明确禁止修改时，保留原件及其身份，只在授权范围内整合或引用，不因本 Agent 的记录不占主体就补写、更名或替换团队陈述。发现可核实冲突时单独指出，不能擅自修订原件。强调人工纠错和未使用 AI 的环节仍应有事实依据；记录缺失不等于从未使用，不能为了符合希望而补造交互或否认已发生的辅助。

## 人类实质控制

人工主导的证据在于负责人实际决定问题和评价标准，理解假设、变量、目标、约束与边界，能够拒绝或修改建议，核查公式、程序、图表和结论，并对真实性、准确性和完整性承担责任。

空白纸推导、反例、变式、纠错和迁移可以作为团队自检和答辩准备，但 Agent 不能据此认证人的内在思考、原创程度或成果归属。

## 最终人工确认

交付前向人工呈现：适用规范、白名单成员、尚存限制、最终 PDF/包 identity、关键审计结果和任何未满足项。只有人工明确批准正式状态后才发布；候选通过检查不等于自动替换正式稿或提交。
