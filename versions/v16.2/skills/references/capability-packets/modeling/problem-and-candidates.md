# 问题重述、基线、候选比较与人工选模

适用于把当前子问转成可建模任务、建立简单基线、比较候选方法和形成人工方法决定。`rules/modeling.json` 拥有正式比较与晋升要求，本包提供完整做法。

来源保留：V8 `07-algorithm-reference.md`、`15-pipeline-methodology.md`、`25-model-results-acceptance.md`、`31-modeling-minimum.md`；吸收 V14 的逐组件状态、已批准决定继承和比例性授权。

## 从当前问题零起点开始

先只重述当前问：现实对象、动作、量词、输入、未知量、约束、评价依据、要求输出、单位和适用边界。不要从旧代码、上一问模型、常用算法或论文标题反推题意。

建立直接回答链：

`当前问要求 → 数学/计算动作 → 输出证据 → 验证 → 允许主张`

没有对应位置的公式、模型、图件和压力测试是思维惯性候选，不是创新。

## 共享底座与必要独立性

“零起点”用于摆脱旧方案先入为主，不是抹去整题背景。逐句核对本问时，同时联读总背景、相关前后问、表格、附件和附录替换关系，区分共同事实、本问覆盖项、由指代与任务结构支持的自然承接，以及仍需补充的假设。后问未重复写同一对象的初态或未变参数，不自动等于缺少条件；前问的特殊近似、结束状态和本问未采用的参数，也不能因代码方便而继续沿用。

可以继承有上述依据的官方输入、概念、兼容接口、通用代码和所需上游结论；方法部件、目标、参数和验证仍须说明在本问的用途。例如后问明确全程改用另一组物性时，不在某时刻暗切回前问参数；后问若以“继续同一过程”承接前问，已有状态及判据可以自然成为输入。遇到明确换对象、换初态或重置条件，则以新规定为准。比较可计算的完整时域、内部保存的复用轨迹与本问要求交付的时段，不把三个范围自动合并。

反事实检查只隐藏旧解法和草稿，保留权威题面全上下文：是否仍会选择并同样解释当前方法。共享事实要求一致，不要求所有子问采用同一模型族，也不允许为了叙事统一把较简模型写成较复杂模型的错误版本。

## 先建立简单基线

进入本问的正式基线和候选比较前，先判断领域对象、机理、方法族或验证依据是否存在实质知识缺口。用户要求找灵感、候选局限于熟悉算法或已有路线暴露解释/效率问题时，按[文献能力包](../evidence/literature-and-source-evidence.md)开展问题探索，再回到本节比较。候选之前没有明确主张不妨碍调查；初步想法用于生成检索词，调查应允许增加、修改或淘汰它们。已有相同条件的来源可复用，只补当前问新增的缺口；无相关缺口的确定性推导或局部实现不重复检索。实际检索、来源审阅与模型比较按既有语义计划分别声明真实动作，不把全部文献事件广播到每个建模步骤。

基线应容易手检，明确回答问题的一部分，并暴露复杂模型要修复的具体不足。它可以是常数/朴素预测、贪心或松弛解、最近邻、等权评分、平衡态、简单统计、可行常数方案，甚至“无需新增模型”。

不能因为候选更复杂、更新颖、流行或内部指标略优就淘汰基线。先说明基线在哪个对象、假设、输出、误差或决策风险上不足。

## 候选由问题结构产生

| 问题结构 | 可手检基线 | 候选方向 | 首要风险 |
|---|---|---|---|
| 预测/时间序列 | 季节朴素、线性趋势 | ARIMA、状态空间、树模型、序列模型 | 时间泄漏、结构突变、区间失真 |
| 分类/回归 | 线性或逻辑模型 | 树集成、核方法、神经网络 | 分布漂移、不平衡、校准不足 |
| 离散优化 | 贪心、松弛、小规模枚举 | MILP、动态规划、局部搜索、元启发式 | 不可行、最优性缺口、尺度爆炸 |
| 连续优化 | 可行常数、梯度基线 | SQP、内点、全局搜索 | 局部最优、尺度病态、约束残差 |
| 网络与路径 | BFS/Dijkstra、中心性 | 流、匹配、生成树、多层/时变网络 | 边权、方向、连通和单位错误 |
| 动力系统 | 平衡态、线性化 | ODE/PDE、差分、状态估计 | 参数不可识别、刚性、边界条件 |
| 随机过程 | 均值近似 | 马尔可夫链、排队网络、仿真 | 稳态未到、随机误差、相关到达 |
| 多指标决策 | 等权或规则排序 | AHP/熵权、TOPSIS、Pareto、效用模型 | 权重脆弱、尺度重复、补偿假设 |

候选表不是方法菜单。数据、机制、目标、可识别性、计算预算和验证条件先淘汰不适用项。

## 防止常见方法偷换

- Dijkstra 需要非负边权；还要核对有向性、连通性和权重单位。
- 最小生成树解决“连通所有节点且总边权最小”，不是一般最短路或设施选址。
- 经典指派是一对一；容量、多对一和设施—需求联合分配必须重新建模。
- TOPSIS 对既有候选排序，不负责生成可行最优方案。
- 熵权反映样本离散度，不等于现实重要性或客观正确。
- 多指标排序与多目标优化不能仅因都涉及“多个指标”而混用。
- 精确方法在资源范围内可行时优先；启发式要有小规模精确基线、可行性修复、多种子分布和可获得的界。

## 候选比较表

对保留候选比较：

- 与题意和输出的匹配；
- 现实对象到数学对象的映射；
- 假设、数据支持和可识别性；
- 目标、约束与候选域；
- 输出类型及允许主张；
- 可手检基线和验证路径；
- 主要失败风险、解释性和下游成本；
- 实现预算、随机性与最优性边界。

关键替代方法只选真正可能改变结论的一两个，不为凑数罗列名称。

## 让人理解后再决定

面向人工决定的说明按“问题—最小数字例子—本题映射—各方法只负责什么—能与不能说明什么—可信替代—信息增量”组织。先用普通话说明比较动作，再给必要术语；隐藏模型名和公式后，负责人仍应能复述方案做什么、为何采用、怎样改变结论、不能推出什么。

选模确认、参数确认、实现授权、结果确认和论文批准是不同事件。已有明确批准且语义兼容的决定直接继承，不把它重新包装成未决问题；发现新证据、目标变化或可信替代会实质改变结果时，成组呈现差异和后果，再重新打开决定。

## 论证强度与外部提示

需要“严格论证”或“唯一方案”时，先明确证明对象：题面是否强制某方法、在声明条件下模型的解是否唯一、离散系统是否存在唯一解、计算是否收敛、现实预测是否准确，是不同命题。可充分论证并选定一条路线，不必假称排除了所有合理模型或算法。条件证明写清前提与未证明部分。另加假设后导出矛盾，不能直接宣布原题自身矛盾；但一个满足原命题全部前提的有效反例，仍可否定其普遍结论，不能因反例还具有其他性质而排除它。

教师关键词、会议手记和参考论文先转成可核的问题，再映射到已有规格、实现和证据。“网格搜索”可能指参数寻优，也可能只是网格加密；插值不等于参数拟合，联立求解不自动构成物理耦合。模糊提示不能直接写成已实现功能、已发现错误或新验收要求；补充方法仍服务于题目需要，未要求的物理机制只在真实影响当前结论时展开。

用户明确要求全面复审时，过去已确认的决定也回到原始依据重新核对。先用题面解决可解决的问题，再集中呈现仍会实质改变结论的未决项；复审不自动撤销全部批准，也不要求用户重新确认每条共同事实。保留“原建议—实际批准—后续纠正”的归属，不把助手实施细节追记成用户逐字确认。

## 输出

输出应包括当前问题定义、简单基线、候选比较、关键风险、验证计划、人工决定及仍未批准的事项。决定进入规格包，不直接跳到代码。
