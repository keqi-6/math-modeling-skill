# 证据链、复现与来源规则

## 双向证据链

正向：

`原题与数据 → 题意解释 → 方法规格 → 代码 → 冻结结果 → 图表与正文 → 摘要与结论`

反向：

`论文声明 → 冻结结果 → 代码 → 方法规格 → 题意与原始数据`

每个关键声明记录证据路径、验证状态、适用范围和禁止外推。发现冲突时，修正最早错误
层并重新生成全部下游产物，不能只改论文表面措辞。

论文不是单一权威文件。题面、批准的任务定义、方法规格、公式、实现、冻结输出、图表、
正文、摘要和结论不一致时，不能用其中任一处单独覆盖其余内容；先定位最早的不受支持
层，再把修正传播到全部消费者。

## 数据与代码

- 原始输入只读并保存哈希、工作表或页码、原始行号和原文；
- 结构化字段、派生字段、分析设置和更正记录分开；
- 结论必须冻结在结构化输出中，控制台文字不能作为唯一证据；
- 验证程序不导入主实现的结论逻辑，并直接读取权威输入复算；
- 代码声明的输入输出与真实读写一致；
- 任何数字按其身份和显示精度追溯，不用统一容差掩盖错误。

每个当前有效机器产物登记生产者、输入版本、模式、哈希、直接消费者、支撑声明和当前
状态。消费者可以是下游脚本、图表、正文、验证或交付材料；没有下游脚本读取不等于
孤儿，但没有生产者、用途、消费者或版本状态的文件不得作为当前证据。上游题意、数据、
假设、目标、约束或参数改变后，使直接与传递消费者失效，重跑或证明不受影响后才能
关闭。

程序中的数值按角色区分：题设常量可以集中命名并保留来源；灵敏度范围、显示精度和
安全余量属于分析设置；临界值、最优值、推荐方案和瓶颈对象必须实时计算，禁止把上次
输出写回求解逻辑。展示点若依赖计算结果，先计算再按明确规则生成。论文关键结果在源码
中以裸常量出现时，除带来源的测试期望值外，按严重问题追查。

## 来源

题面、官方文件、学术文献、公开论文、讲座规则和用户决定保持来源身份。公开优秀论文
只能用于观察表达结构，不能复制文字、模型和结果，也不能自动提升其写法为硬规则。

外部资料记录原始 URL 或 DOI、访问日期、来源类型、阅读状态、支撑主张和限制。只有
摘要可读时不得声称阅读全文；搜索结果页、AI回答和往届答案不能作为事实、机理或最优性
依据。论文中的外部主张必须能回到与其身份相符的来源，不能用主题相关文献装饰。

## 一修全修

术语、单位、指标、条件、数字或证明范围改变后，搜索摘要、正文、公式、表头、图注、
结论、审计、复现文档和交付副本的全部关联表达。同步核对完成前不得关闭问题。
