# 图表、LaTeX 与页面专项规则

## 模板

服从当届官方规范和用户确认模板。当前基线为中文正文宋体小四、英文数字 Times New
Roman、单倍行距；题目黑体三号居中；一级标题黑体四号居中；二至四级标题黑体小四。
不得靠缩字号、行距、页边距或标题间距掩盖内容和分页问题。

结构性重写先列无标题的逻辑提纲，再把真实的并列、从属和依赖关系映射为标题；不得先
套“模型建立—模型求解—结果分析”模板再塞内容。标题既导航也预告本节实质机制，但
不得写成宣传语、完整结论或术语清单。隐藏正文只读标题时，应能辨认原题各项任务入口
和推进顺序。

建立“摘要主要方法或亮点—正文标题或首句—公式、结果或检验证据”映射。只有本节确有
独特机制、约束、证明、反事实、阈值或权衡时才在标题预告；普通组织性章节可保留普通
标题，不为显得创新把所有标题改成宣传语，也不增加只有一个子项的空层级。

## 字体可用性与验证门禁

字体要求描述的是排版角色，不等于任意运行环境都安装了同名字体。首次编译、迁移机器、
切换操作系统或更换 TeX 环境后，必须先查询编译器实际运行环境可见的中文衬线、中文
无衬线和西文衬线字体，再显式设置正文、标题与英文数字字体；不得依赖文档类按操作系统
名称自动猜测字体，也不得把宿主系统“看得见”误当成 WSL、容器或远程编译器可调用。

- 精确模板字体可用时，使用经查询确认的字体族名；
- 精确字体不可用但当前成果允许工程替代时，中文正文采用字形完整的宋体类衬线字体，
  标题采用黑体类无衬线字体，英文数字采用 Times 兼容衬线字体；记录“要求字体—
  实际字体—替代理由—适用范围”，并明确该结果不等于精确模板合规；
- 精确字体是交付硬条件时，不得静默替代，必须停止正式交付并报告缺失字体；
- 全文编译前先用包含中文标题、中文正文、英文、数字、标点和数学公式的最小样张检查
  字形。字体加载错误、中文缺字警告、中文被西文字体代打或不可见均视为编译失败；
- 生成 PDF 后使用 `pdffonts` 或等价工具核对预期字体已嵌入或子集嵌入，并目视检查
  代表页面。源码中的字体声明、编译退出码和“生成了 PDF”都不能单独证明字体正确。

### 环境探测

第一次编译或环境变化后，先确认实际 `xelatex` 的路径与版本，再按该程序所在环境检查
字体。Linux 原生环境可用 `fc-list`、`fc-match`，TeX 随附字体可用 `kpsewhich`；
Windows 环境检查系统字体目录和字体注册情况。用查询或文件检查证实的字体族名，不凭
经验拼写。

若 WSL 调用的实际是 Windows 版 XeLaTeX，Linux `fc-list` 不能完整代表它能使用的
字体。此时同时检查 `/mnt/c/Windows/Fonts/` 中的文件，并可通过
`Path=C:/Windows/Fonts/` 与具体文件名显式加载。显式路径优先于依赖 `ctex` 自动发现
Windows 字体，因为后者可能受注册名称和启动环境影响。

### XeLaTeX 显式设置

重建入口时优先使用 `fontset=none`，通过 `fontspec`/`xeCJK` 显式设置。Windows 字体
文件存在且项目要求精确采用宋体、黑体和 Times New Roman 时，可使用下列结构；具体
文件名必须在当前机器检查，不能未经核验照抄：

```latex
\documentclass[UTF8,fontset=none,12pt,a4paper]{ctexart}
\usepackage{fontspec,xeCJK}
\setmainfont[
  Path=C:/Windows/Fonts/,
  UprightFont=times.ttf,
  BoldFont=timesbd.ttf,
  ItalicFont=timesi.ttf,
  BoldItalicFont=timesbi.ttf
]{Times New Roman}
\setCJKmainfont[
  Path=C:/Windows/Fonts/,
  UprightFont=simsun.ttc,
  BoldFont=simhei.ttf
]{SimSun}
\setCJKsansfont[
  Path=C:/Windows/Fonts/,
  UprightFont=simhei.ttf,
  BoldFont=simhei.ttf
]{SimHei}
```

使用 `fontset=none` 后，若正文或标题调用 `\songti`、`\heiti` 等 `ctex` 字体族命令，
还必须用 `\setCJKfamilyfont` 为相应 family 建立显式映射，并以 `\newcommand` 或适合
当前文档类的方式定义命令；不得只设置 main/sans font 后假定这些命令自然有效。

### 替代层级与记录

1. 精确模板字体可用时采用精确字体；
2. 精确字体不可用但当前草稿允许工程替代时，采用字形完整、角色相符且实测可用的
   宋体类、黑体类和 Times 兼容字体，并记录“要求字体—实际字体—替代理由—影响与
   适用范围”；Fandol 或 Noto 只能作为候选，不能未经实测自动选用；
3. 精确字体属于正式交付硬条件且不可用时，停止正式交付并报告安装需求。

### 最小样张与 PDF 验收

全文编译前先编译一页样张，至少包含中文题目、各级标题、正文、全角/半角标点、英文、
数字、单位、行内与展示公式、粗体、斜体和题注。`fontspec`/`xeCJK` 加载错误、
`Missing character`、中文被西文字体代打、空白方框或不可见字符均为硬失败。

全文双编后必须同时：

1. 检查完整日志中的字体错误、缺字、未定义引用和越界盒；
2. 用 `pdffonts` 或等价工具核对中文正文、中文标题、英文和数字字体已实际嵌入或
   子集嵌入；
3. 逐页目视检查，并重点放大首页、正文密集页、公式页、图表题注和参考文献页；
4. 保存字体映射、检查命令、结果和未满足的精确合规边界。

只有字体可加载、无缺字、PDF 实际嵌入且页面显示正确同时成立，字体门禁才通过。

## 图表选择

- 精确查询和完整比较优先表格；
- 趋势、分布、结构和权衡优先图；
- 一两项简单数字直接写正文；
- 每张图表只承担一个主要信息职责；
- 图题说明对象、条件和单位，图后正文解释发现及题目作用。

图像使用色觉友好配色，并以形状、线型或标签提供冗余编码；最终尺寸下文字、坐标和
图例清晰。禁止装饰性背景和无意义三维效果。

同一主张原则上只有一个主载体。表用于完整查询，图用于趋势、分布、例外和权衡；若
正文声称覆盖全部配方、条件或方案，主载体必须让读者实际看见这一覆盖，不能只展示
少数代表案例并把完整证据藏在内部文件。多面板图在最终页尺寸下任一面板无法快速读取
时，必须拆分、改用表格或重新设计，不能以源图高清为由放行。

图表必须通过三层检查：

1. 全文层：题目要求和关键主张是否都有合适载体，图、表和正文的分工是否必要；
2. 单件层：数据、单位、比较对象、视觉编码和图题是否正确，是否承担唯一信息职责；
3. 渲染层：最终 PDF 中字号、线宽、颜色、图例、裁切、留白和灰度可辨性是否合格。

任一层通过都不能替代另外两层。

### 图表内容闭环

每幅关键图表在正文中依次完成：

`首次实质引用 → 图表 → 可直接观察的关系或现象 → 本问结论 → 必要决策作用与边界`

图注只说明对象、变量、条件和编码，不能代替正文分析。不得从坐标轴或图例直接跳到
结论，也不得把相关、局部案例或单一情景外推为因果或整体规律。图与表同时保留时，正文
明确表负责精确查询、图负责趋势、分布、例外或权衡；双向删除后若信息无损，视为重复。

### Nature 图件与退化检查

正式图件遵守已经确认采用的 Nature Research Figure Guide：

- 线图、结构图和文字优先矢量 PDF/EPS；照片类位图在最终尺寸至少 300 dpi，不用插值
  放大冒充分辨率；
- 图内英文和数字优先 Arial/Helvetica，普通图中文字原则上为最终尺寸 5--7 pt；
  多面板标号使用 8 pt、粗体、正体、小写字母；
- 坐标写明变量和单位，图例无装饰边框，图题只放 LaTeX 题注；
- 颜色具有数据语义，并同时使用形状、线型、明度或标签，不使用彩虹色阶、红绿唯一
  对照、三维效果、渐变、阴影和装饰背景；
- 同一对象在全文保持相同颜色、符号、线型、单位和图例顺序。

逐图、逐表执行三轮验收：

1. 独立检查数据、标签、图例、遮挡、裁切、单位、表格列宽与小数位；
2. 在最终 PDF 实际尺寸逐页检查最小文字、细线、表格换行、引用—载体—解释的邻接、
   留白、孤题和浮动；
3. 检查灰度、低对比和普通打印下是否仍可凭冗余编码辨认。

修复后必须重新生成、编译并复查当前页与相邻页；源图高清或脚本无报错不能替代验收。

每幅图表登记所回答任务、支持声明、数据或模型来源、生成方式、正文引用位置和当前
版本。数据图追溯到冻结数据与脚本；流程图、机制图和结构图追溯到明确公式、拓扑或
设计定义。手工绘制不免除来源与版本登记。

## LaTeX 源边界

正式论文只保留一个 LaTeX 主入口；不得建立 Word、Markdown 或另一份 LaTeX 作为竞争
主稿。`.tex` 不得残留 Markdown 标题、强调、链接、管道表格或围栏代码；项目 Markdown
不得混入用作正文结构的 LaTeX 命令和数学定界符。编译成功不能证明源格式边界正确。

草稿的非正式标识、正式入口隔离与人工升级门禁只执行
`50-governance-handoff.md`，本文件不重复规定。

## 浮动与分页

图表放在首次实质引用之后，并与解释保持局部闭环。出现大块留白、标题孤行、图表漂移、
图表或单条文献无意义独占页时，先定位原因。未经用户确认，不得擅自删改必要文字、
调整字体、行距、页边距、标题间距、图表顺序或浮动规则；可先尝试在保持清晰度前提下
调整图像显示尺寸。

## 编译检查

使用唯一草稿入口双编至引用稳定。检查错误、未定义引用、越界盒、页数和输出文件，并
逐页目视检查字体、标题、表格、公式、图像、留白、分页和参考文献。日志通过不能替代
视觉检查。

出现摘要超页、关键词跨页、正文超限、标题或句子孤悬、半页留白和图表漂移时，先报告
具体页面、原因和受影响内容。除保持图件完整且仍清晰的显示尺寸调整外，删除、压缩、
合并或改写文字，以及改变字号、字体、行距、字距、页边距、段距、标题间距、分页、
图表顺序和浮动参数，均须取得用户对具体方案的确认。
