# 论文表达与论证闭合

适用于起草或修订摘要、方法、结果、评价、结论，以及任何包含术语、公式、比较、原因、证明强度或决策含义的实质性文字。本包把已经成立的模型与证据写成读者可复推的论证；它不能用更流畅的措辞修补错误规格、未验证结果或缺失证据。

来源保留：V1 `03-paper-content-rules.md` 与 `13-excellent-paper-expression.md` 的句子功能、摘要准入、就地解释、因果闭合、公式/算法叙述、结果边界和最小改写；结合 V3–V5 的 claim-evidence、standalone 与 no-dump 原子。旧版固定句数、固定摘要配额、禁词计数和逐句持久化表均不恢复。

## 何时使用

以下情形应读取本包：

- 从规格、结果和证据起草新的论文段落；
- 文字看似专业但读者无法说明对象、动作、理由或落点；
- 模型名、公式、数字或图表代替了实际解释；
- 摘要与正文、结果与结论、主张与证明能力不一致；
- 局部润色可能改变数值精度、因果强度、最优性、稳健性或适用范围。

纯错字、标点、引用编号或不改变语义的排版修复，只需执行 V14 给出的局部闭包，不因此加载整套表达审计。

## 一、先确定段落职责，再写句子

历史规则中最值得保留的表达是：

> 建模论文的基本表达单元不是“显得专业的长句”，而是来意、定义、动作、理由、证据和落点。

这六项是诊断语言，不是每段必须凑齐的句子配额：

- **来意**：本段要解决什么矛盾，或承接前文的哪项输出；
- **定义**：现实对象怎样映射为数学对象，术语在本文中指什么；
- **动作**：对哪些对象执行何种计算、筛选、固定、比较或推导；
- **理由**：为何需要该动作，不这样做会出现什么困难或错误；
- **证据**：给出公式关系、数据、结果、界、对照、图表或独立检验；
- **落点**：证据回答题目什么，限定什么，并为下一步提供什么输入。

起草一个段落时按以下步骤做：

1. 用一句内部白话写出本段唯一主要职责；
2. 列出读者进入本段前已经知道的对象、条件和定义；
3. 选择本段必须新增的动作、理由或证据；
4. 把成立条件放在动作或结论附近，把结果放在证据之后；
5. 用落点收回题目，不以算法名或“结果良好”结束；
6. 删除后检查：每句是否提供新职能，删掉后推理是否仍完整。

同一句可以承担相邻职能。只有对象不唯一、条件埋在句尾、多个判断混在一起或因果难以辨认时才拆句；不要用固定句长和连接词数量判错。

## 二、判断—理由—证据—边界

分类、等价、上下界、因果、改善原因、最优性、稳健性、适用性和方案推荐都属于需要依据的判断。对每个实质判断执行：

1. 写清判断对象和结论，不用“该指标”“效果更好”替代；
2. 定位能推出它的数学关系、数据事实、约束、对照、运行或来源；
3. 把最小充分理由放在同句或紧邻上文；
4. 先用本题对象解释机制，再给规范术语；
5. 将候选域、参数范围、比较基准和检验范围紧邻其限定的结论；
6. 把措辞强度收敛到证据真正支持的上限；
7. 遮去术语后，确认仍能复述对象、机制、证据和结论。

定义句、题面事实和直接报告数据不必人为制造原因，但其来源、统计单位、条件或结果身份必须明确。找不到真实理由时，不得为句式完整而虚构因果；应降低主张、删除判断，或回到模型/验证层补证据。

高风险主张可以临时记录“判断—邻近理由—证明范围—修改动作”供人工审计；普通段落无需生成固定字段或额外回执。

## 三、术语与普通语言的双层表达

模型名、指标名、变量和判断规则首次实质参与正文推理时，当前句或紧邻上文应已经说明：

- 它针对什么现实或数学对象；
- 执行什么动作或比较；
- 按什么方向、阈值或判据工作；
- 输出怎样进入当前题目答案。

推荐次序是“普通语言机制 + 规范术语 + 本题映射”，例如先说明在给定阈值下保留哪些连接、检查何种覆盖关系，再称其为阈值匹配。后文可以补公式和严格定义，但不能倒推挽救读者此前被迫猜测的术语。

正常回指不必每次重新定义：邻近上文已有唯一对象、条件仍持续有效时可以简称。若一个简称可能对应两个公式、两个统计单位或两种证明能力，就写出完整对象和口径，不靠项目内部习惯消歧。

遇到抽象名词堆叠，不做同义词替换，改写为可检验动作。例如把“提升配置效率”改成“在相同资源上限下比较两方案的已服务需求量；增加量构成本段所称的效率改善”。

## 四、公式与推导怎样写

保留历史短句：

> 公式解释的审计单位是数学职能，不是 LaTeX 环境、编号或换行数量。

每个关键公式或公式组按实际需要闭合：

`现实对象或原始关系 → 数学表达 → 必要变形 → 公式在模型中的作用 → 对结果的影响`

具体做法：

- 公式前说明为什么需要这条关系；
- 符号首次出现附近给出含义、单位、定义域与来源；
- 对决定目标含义、约束作用或等价性的步骤，展示从原始关系到可计算形式的桥；
- 使用绝对值拆分、最大值上界、辅助流、松弛或线性化时，同时解释原量、辅助关系、等价条件和可能失效的边界；
- 公式后说明它排除什么错误方案，或将哪项现实要求转成了什么数学条件；
- 多个公式后用普通语言拼回输入、可行域、比较规则和输出。

展开尺度由数学职能决定。机械代入、简单换算和已定义对象可省略；会改变物理含义、量纲、等价性、目标优先级或结论边界的桥不能省略。不要为形式整齐强制“一句一公式”“每步编号”或固定推导长度。

形式规格的权威细节由 [可实现、可验证的数学规格](../modeling/mathematical-specification.md) 承担；论文表达负责让评审能理解和复推，不另造一份竞争规格。

### 从模型建立到求解、检验的内容归属

本节是通用论证依赖在方法内容上的专项覆盖；重合处以这里的更具体职责为准，不把两套顺序机械叠加。通用依赖仍用于全稿和其他章节的证据链检查。

模型建立、模型求解和模型检验是论证责任，不是强制标题模板。模型建立必须自含正式对象、变量、假设、关系、目标、约束、关键可计算化变形，以及由这些公式推出的主求解逻辑。读者在进入本次执行细节前，应已经知道候选怎样被判定、比较或排除，以及算法为何与模型同义。

模型求解只承接和实例化该合同：回指前述公式，写实际输入、初始化、参数、执行顺序、停止与失败处置、输出生成。它可以给操作性伪代码，却不能首次引入决定目标含义、等价性、可行域或证明能力的新数学合同。模型检验则写清对象或风险、设置、预先判据或指标、结果、结论与边界，不把内部验证器的完整推导变成第二套模型。

边界不按篇幅或术语复杂度机械决定。闭式解可能没有独立求解节；必要的括区间或等价变形即使含实现步骤，也可能是模型可计算化的一部分。若替代算法实际承担共同求解、核心证明或论文的主要比较，就应作为正式方法解释；只有非主方法、且展开会形成独立强合同的辅助验证器，才把完整推导留在内部证据并在正文保留证据摘要。

## 五、方法与算法怎样写

> 论文是数学论证，不是程序运行报告。

方法部分应让读者不依赖代码，也能追踪决策怎样形成。围绕实际需要回答：

- 初始状态、候选域或搜索区间怎样形成；
- 每一步增加、删除、分支、固定或更新什么对象；
- 用什么指标、界、单调性或可行性判据比较和排除候选；
- 约束与目标分别怎样影响状态，不把目标写成可行性条件；
- 停止条件是什么；停止后能支持可行、局部不可改进还是全局最优；
- 数学结果怎样还原为题目要求的现实方案。

软件、函数、变量规模、运行时间和求解器状态只能补充实现信息，不能替代上述逻辑。规范算法名只保留理解本题路线所需者，并就地说明它在本题中比较、限制或输出什么。

### 参数变化与方案切换

参数情景变化时，区分：

1. 不变的候选集合、现实关系和基本规则；
2. 改变的系数、可行域、最优指派、活跃约束或瓶颈；
3. 固定旧方案后复算，与新情景下重新优化；
4. 直接效应，与耦合约束造成的间接重分配；
5. 主目标变化，与并列最优中由次级目标选择的变化。

若解释方案切换，给出最小反事实：在新条件下保留旧方案会使哪项指标、约束或高优先级目标变差；重新优化交换了什么、修复了什么、代价落在哪里。离散测试点只支持已测试情景，不能被写成连续区间证明。

## 六、结果、比较与证明强度

结果段从身份开始，不从形容词开始。按需要交代：

`对象与条件 → 基准与指标 → 方向和量级 → 形成机制 → 代价或例外 → 题目含义`

- 数值绑定正式结果身份、统计单位、舍入规则和适用情景；
- 区分当前项目登记输出、题面或官方输入、外部参数/现实基准，以及只供内部回归或候选启发的外部答案数值；
- 外部数值是否可写入正文由已登记的用途和允许消费者决定，不由引用是否完整或字面值是否相同决定；标为内部回归/候选启发的数值不得冒充正式结果或进入评审可见比较；
- 比较句写明比较对象、指标、方向和基准；
- 先说图表可直接观察到什么，再给不超过证据强度的解释；
- 收益与代价同时报告，不用“显著、合理、有效”代替判据；
- 精确计数和精确求解结果不以“约”掩盖冲突；估计、测量和预测保留相应不确定性。

证明措辞按能力区分：

- 重新计算指标：只说明统计与方案一致；
- 删除任一已选元素后失效：只说明当前集合不可直接删减；
- 另一实现得到同值解：增强一致性，但未必单独证明最优；
- 有效上下界闭合、穷尽候选或已证明的等价判据：才可支撑相应全局结论；
- 有限扰动未改变结果：只写“在所考察范围内保持”，不写普遍稳健。

一个本项目独立计算值与公开参考值舍入后相同，仍可以作为当前项目结果报告，前提是它绑定自己的输入、规格、运行和验证 identity；数值相等不会把它变成外部抄录。反过来，一个来源可靠、引用完整的公开答案若只被批准作内部告警，也不能因“有引用”自动进入论文。题面常量、经批准的外部参数和用于现实验证的基准不受一刀切禁令约束，但必须写清其来源角色和用途。

把“证明、验证、最优、稳健、有效、显著”当作语义判定，不作关键词禁用。若证据不足，局部修复是收窄对象、范围和措辞，而不是删除一个敏感词后保留原来的暗示。

## 七、摘要怎样压缩而不丢能力

摘要不是目录，也不是全部工作的成本清单。先从正文抽取每项任务的直接答案，再决定哪些信息必须进入摘要。

### 内容准入

- **必须保留**：直接回答题目；改变推荐、可行域、目标优先级或结论边界；标识主要技术路线且正文有完整支撑的内容。
- **条件保留**：关键下界、稳健范围或独立证据；缺失会让读者误解最优性、可靠性或适用范围时保留。
- **留在正文**：求解器、函数、变量规模、局部诊断、完整节点表、重复验证和不改变结论的次要数字。

以最小信息单元分级，不整句一刀切。检验和边界跟随它所限定的主张：主张保留时并入必要边界，主张移回正文时不要在摘要留下孤立免责声明。

> 代码很复杂、运行很久或使用了规范算法名，不自动取得摘要席位。

### 每项任务的自足链

根据题目需要写成自然段，不固定句数：

`新增任务或条件 → 关键建模动作及其本题职能 → 核心结果或方案 → 决策含义与必要边界`

模型名、检验名或指标名不能单独承担一句。出现“评价、分析、优化、验证、诊断、比较”时，应能回答对什么对象、按什么判据、得到什么结论、为何影响题目答案。

摘要定稿做双向检查：

- 正文到摘要：改变结论、范围或执行方案的主要工作是否有对应表达；
- 摘要到正文：每个模型名、数字、检验和边界是否有正文推导与证据。

发现冲突时不默认任何文本为权威，回到题意、规格、实现和正式结果定位最早错误层。版面压缩只能在实际需要且获得相应授权时进行；优先删背景套话、实现细节、重复主语和次要诊断，不能删掉方法因果链后留下空泛动作。

## 八、结论、评价与局限

结论按题目顺序回收：

`决策或判断 → 核心证据 → 成立条件 → 必要边界`

不复刻摘要的建模过程，也不新增正文未展开的方法、数字或启示。模型评价应把优点绑定具体机制和证据；局限说明缺失机制可能使结果向什么方向偏移、影响哪类结论、何时需要扩展。没有材料性局限时不编造通用缺点；已经发现会改变解释的失败边界不能用套话掩盖。

## 九、局部改写程序

局部改写前先读目标句、完整段落和必要邻接，再执行：

1. 标记当前句主要职能；
2. 区分事实错误、证据缺口、逻辑跳步和纯风格问题；
3. 指出只需要补的对象、动作、理由、证据、边界或回指；
4. 保持未授权的模型含义、数值、条件和证明强度不变；
5. 修改最小充分范围；
6. 重读修改后的整段及直接引用，确认没有重复、指代漂移或新因果；
7. 仅按 V14 的实际依赖闭包同步其他直接消费者。

可用“当前功能—当前缺陷—局部动作”作为临时思考格式，但普通编辑不要求保存表格。

> 禁止为了模仿“优秀语气”而全段重写。

只有段落的功能次序本身混乱时才结构性重写；缺主语就补主语，缺基准就补基准，术语未解释就补本题动作，证明过强就收窄边界。学习优秀论文只学习信息次序和证据落点，不复制句库、语气或固定套话。

## 十、完成标准与常见失败

当前表达工作完成，当且仅当：

- 每个实质判断能定位到相称证据，且理由在读者需要它的位置出现；
- 术语首次实质使用可由普通语言复述，回指对象唯一；
- 公式、数字和图表嵌入对象—动作—证据—含义链，没有代替解释；
- 方法文字能让读者复推状态变化、比较和停止逻辑；
- 结果身份、基准、条件、方向、精度和证明范围一致；
- 摘要、正文和结论双向一致；
- 修改未借风格调整改变事实、数值、不确定性或因果强度。

| 常见失败 | 局部修复 |
|---|---|
| 只报模型名 | 补本题对象、关键动作、判据与输出 |
| 连续堆公式 | 在公式前补来意，公式后补现实作用，并删除无职能重复式 |
| 只报数字 | 补结果身份、条件、基准和题目含义 |
| “因此”前只有相关信息 | 补最小推导机制，或降低为相关/观察性表述 |
| 软件名替代算法 | 改写候选怎样产生、比较、排除和停止 |
| 验证措辞超过能力 | 明确检验对象、操作、判据及不能证明什么 |
| 摘要塞满实现细节 | 保留直接回答、路线职能、核心结果与必要边界；细节回正文 |
| 为流畅而改强结论 | 恢复原条件、不确定性和证据强度，再做句法优化 |

## 十一、必要人工确认点

本包不要求每句、每段或每次局部润色都再次确认。只有当候选改写会实际改变下列内容，且当前授权尚未覆盖时，才交人工决定：

- 模型对象、任务解释、评价口径或候选域；
- 主要主张、因果方向、最优性/稳健性强度或适用边界；
- 正式结果数字、舍入政策或证据身份；
- 摘要/结论中主要贡献的取舍，或为版面删除必要信息；
- 与当前官方格式或用户明确写作画像发生冲突。

在既定语义和已授权范围内补解释、修指代、调句序、收紧措辞和同步直接引用，作为一个连贯 ChangeSet 完成即可，不增加逐句审批流水线。
