# 科学示意图、流程图与工程结构图

适用于模型机理图、算法流程图、网络拓扑图、工程结构图、剖面图、运动关系图和受力图。此类图的核心不是“看起来专业”，而是题面、数学关系和图中元素之间可以逐项核对。

来源保留：V8 `37-scientific-figure-design.md` 的真实性映射、图类范式、工具选择、样板准入和像素验收；吸收 V14 的工件 identity 与最小影响闭包。规则原子拥有规范强度，本包不自行批准模型、公式、结果或论文发布。

## 真实性映射先于构图

纯概念、流程或工程示意图在语义计划中声明 `data_driven_visual=false`。这会排除只适用于定量图的数据 identity/禁止手改数值 atom，但不会排除本包的来源、拓扑、方向、几何、渲染和人工验收要求；若图中任何位置、颜色、面积或标签数值承担定量含义，则改为 `true` 或同时读取数据图能力包。

正式绘图前建立：

`题面对象 → 几何/拓扑关系 → 数学变量 → 作用或信息流 → 图中元素`

映射表逐项记录题面页码、原图、附件、冻结公式、算法步骤或设计定义。先核对原题和权威规格，再用公式检查作用方向、符号和依赖。

公式可以约束动力学关系，但不能唯一决定题面没有写明的外壳、安装、铰接、支承和连接几何。不得用领域常见装置、旧草图或生成模型先验补全事实。真实性映射未闭合时，只制作明确标有待核项的内部草图，不得美化后准入论文。

若图与公式不一致，先区分：几何解释错误、符号约定错误、图形实现错误，还是模型本身错误。只有最后一类才回到模型规格；不能因为图“看起来不对”就直接推翻冻结公式。

该映射不是绘图前的一次性笔记。代码生成后的每个对象、边、箭头方向、连接点、相对几何和标签都要反向核对来源；自动布局只可以决定不承载事实的间距与避让，不能发明连接、方向、比例、铰接或空间位置。数据图同样核对对象和值到来源的映射；工程/概念示意图则重点核对拓扑、方向和“未按比例”边界。

## 工程结构、剖面与受力图

- 默认白底、黑线或深灰线，使用可见轮廓、内部构件、轴线、剖面线的线宽层级。
- 保持轴对称、共轴、铰接、固定、接触、穿设和自由度关系可读。
- 引出线先留短着陆段，再指向唯一对象；标签不压线、不跨对象。
- 不使用卡片、渐变、阴影、拟物高光和装饰性环境填充。
- 非按比例工程图应明确标注“示意”，限制读者进行尺寸推断。

受力图另外核对：

- 分离体、坐标系、正方向和参考状态明确；
- 每个力或力矩都有施力者、受力者、方向和符号约定；
- 不同分离体上的内力等大反向；
- 在动态平衡坐标中消去的重力、静浮力等必须说明，不能一面省略一面保留；
- 图中箭头与最终方程逐项双向核对，颜色不能代替方向语义。

## 模型机理、流程和算法图

- 节点只写短标签，定义和长解释放图注或正文。
- 箭头只表达明确的因果、依赖、数据流、控制流或迭代方向。
- 输入、输出、分支条件、循环回边、停止条件和失败出口必须能够回放。
- 图的顺序忠实于实际求解流程，不把普通流水线包装成虚构的新算法。
- 并行步骤、可选步骤与严格先后关系使用不同结构表达，避免所有方框被一条链串联。

对复杂流程，先写结构清单或图描述，再生成图；不要一边移动节点一边决定算法逻辑。人工审阅时尝试只看图复述一次流程，无法复述的缺口回到结构定义修复。

## 视图和符号合同

涉及题面装置、运动自由度或局部机构时，先从原题 PDF 原生提取并查看相关图像，分别核对总体、正反、侧视和局部视图。一个投影面不能同时说明两组正交关系时，拆成“主几何图＋局部结构图”，不要把所有构件、箭头和说明压进一幅图。

绘图前冻结符号合同：图中变量直接使用当前正文或规格的权威符号、下标和角度定义。同一符号不得在图和正文中指代不同物理量，也不得靠一段映射文字长期维护两套符号。

角度圆弧、质心、铰点、连接点、参考轴和引线终点逐项核对。组合标签包含多个元件时，应分别指向各元件，或改用局部图完整表达。

## 工具选择

| 图件 | 优先工具 | 边界 |
|---|---|---|
| 数值曲线、统计图、参数图 | Python/Matplotlib | 不用于精细工程几何排布 |
| 精确节点布局、工程剖面、复杂标注 | 可编程 SVG | 保存结构化源与可编辑元素 |
| 稳定流程和依赖图 | SVG、Graphviz、Mermaid 或 TikZ | 先确认布局引擎不会扭曲语义 |
| 字体一致且构图适中的论文图 | TikZ | 避免复杂图导致维护和编译成本失控 |
| CAD 或矢量编辑器 | 精确结构或末端微调 | 保存源文件并记录不可代码重现的操作 |

生成式位图只能用于不承担精确几何、数值或拓扑的装饰性素材，不能作为受力图、工程图、数据图或逐项科学证据的生成器。

每幅正式图至少保留可复现源码或可编辑源、矢量 PDF/SVG 和审阅 PNG。路径从项目根解析，不依赖个人桌面、临时目录或隐含工作目录。

## 高风险样板与人工门

新图类、题面工程复原、受力图或新的视觉系统先做一张最难的代表性样板：

1. 核对真实性映射；
2. 核对图类、视角和信息职责；
3. 核对视觉层级和最终尺寸；
4. 核对灰度、低对比和普通打印；
5. 由人工确认技术含义和审美；
6. 再批量扩展或准入论文。

“好看”不能批准内容错误，“正确”也不能批准最终尺寸下难读的图。样板进入项目、替换旧图和修改论文引用是不同动作；保留已接受版本，重大视角调整或重画使用新文件名。

## 像素级验收

SVG 或矢量源完成后，渲染成最终交付尺寸的 PNG，并以该 PNG 而不是放大的源图验收：

- 记录画布像素及横纵缩放比例；
- 检查角度圆弧端点与参考线的像素偏差；
- 检查标签锚点、引线终点和目标边界的距离；
- 检查关键元件的最终可见包围盒；
- 检查文字、箭头头部、轮廓、虚线和引线是否真实相交或形成伪符号。

修复后重新渲染，并检查是否制造了新问题。最终还要放入论文 PDF，按真实页内尺寸复检。
