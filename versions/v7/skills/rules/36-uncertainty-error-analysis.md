# 误差、不确定性、敏感性与稳健性专项规则

## U-01 职责与适用范围

本文件源自 V5 的结果可信度修复，现为 V7 的误差与不确定性专项主责。控制器仍决定当前能否规格、实现、验证或发表；
`09` 保留既有稳健性方法，`25` 保留模型—结果写作闭环，`32` 保留验证最低交叉检查。
本文件只补充它们未统一规定的误差与不确定性身份、传播、决策影响和报告边界。

每问都执行来源审查，但不机械执行同一种试验，也不强制建立名为“误差分析”的章节。
只有会影响预定用途、关键输出、可行性、排序、最优决策或主要声明的来源才进入实际
量化、定界或试验；未触发项必须给出题型和证据理由。

## U-02 四类来源

按真实来源分类，不把分析方法误写成误差来源：

1. **输入、观测与参数不确定性**：测量精度、附件舍入、抽样波动、参数估计、自然
   变异、情景输入、输入相关性和知识不足；
2. **数值近似与计算实现误差**：离散、时间步长、网格、截断、插值、迭代容差、浮点
   舍入和计算环境差异。程序实现错误属于验证失败，必须修复，不能作为可接受误差项；
3. **求解与优化不确定性**：搜索域离散、提前停止、最优性间隙、随机种子、局部最优、
   代理模型和未穷尽候选域；仅在存在非精确求解或优化时触发；
4. **模型形式与适用域不确定性**：线性化、小角度或稳态近似、遗漏机制、代理变量、
   边界条件、函数形式及训练域与应用域差异。没有理论、实验或对照证据时，不声称偏差
   方向或概率分布。

统计分析、重采样、Monte Carlo、解析传播、区间传播、网格收敛和上下界是评定方法，
不是第五类来源。“误差”用于与参考值的有符号或绝对差异；来源、分布或真值不完全已知
时优先使用“不确定性”。

## U-03 与其他可信度证据分离

- **代码验证**回答实现是否符合算法规格；
- **数值解验证**回答离散、迭代和舍入对数学解的影响；
- **模型确认或适用性检查**回答模型在预定用途下是否充分代表现实；
- **不确定性分析**量化或定界关键输出可能变化多少；
- **敏感性分析**识别输出变化主要受哪些输入、假设或情景驱动；
- **稳健性分析**判断主要结论在有依据的变化范围内是否保持。

另一实现得到同值、一次参数扰动、求解器成功状态和编译通过均不能替代上述其他证据。

## U-04 S4 规格接口

在冻结模型规格时，对每问记录：

`预定用途 → 关键输出或决策 → 潜在来源 → 来源依据 → 可能失效的声明
→ 计划方法与判据 → 无法分析时的边界`

不得先选 Monte Carlo、固定百分比网格或置信区间再寻找来源。范围和分布必须来自题面、
测量精度、数据、可靠文献、现实情景或明确标注的探索目的；缺少依据时不得虚构概率分布。

## U-05 S6 执行闭环

对每个触发来源形成：

`关键输出 → 来源与证据身份 → 范围、分布或界 → 方法与复现设置 → 输出影响
→ 是否改变数值、排序、可行性或决策 → 机制解释 → 证明边界`

按问题选择解析传播、区间或上下界、重复试验、重采样、交叉验证、Monte Carlo、局部或
全局敏感性、步长/网格/容差收敛、有效最优性界、候选域精化、替代模型或现实对照。
方法复杂度必须匹配风险；局部导数不能自动代表非线性大范围变化，离散测试点不能证明
未测试的连续区间。

参数或情景改变时继续区分：固定原方案只评估既定方案表现；重新优化才评估最优决策
是否切换。联合变化可能重要时，不以逐个单因素扰动替代交互或联合情景检查。

## U-06 合法状态

每类来源只能使用以下可审计状态之一：

- `not_triggered`：已检查，并以题型、数据和预定用途证明不构成材料风险；
- `quantified`：有证据支持的概率、区间或数值量化；
- `bounded`：只能给出确定性上界、下界或范围；
- `tested`：完成探索情景或敏感性试验，但不能解释为真实误差分布；
- `unresolved`：证据不足；限制声明，必要时回到最早受影响状态。

“影响较小”“基本稳定”“误差可忽略”不是状态证据。`tested` 不得升级为 `quantified`；
`unresolved` 不得与无条件的精确、稳定、因果、全局最优或现实有效声明并存。

## U-07 写作与全文审计

正文只呈现会影响主要答案理解的证据，不为满足模板堆砌试验。可放在对应小问的求解
检验、结果解释、模型评价或局限中，不要求独立同名章节。至少说明对象、来源依据、方法、
范围/界/分布、关键输出影响、是否改变结论和不能推出什么；详细运行表进入结构化输出或
复现材料。

全文统一数字身份和声明强度。禁止：

- 用任意 `±5%`、`±10%` 或 `±20%` 代替真实误差依据；
- 把敏感性试验写成误差分布或置信区间；
- 把预测误差写成实验测量误差；
- 只运行一个步长、网格、容差或随机种子便声称数值收敛或算法稳定；
- 把候选域内最优写成连续域、现实域或全局最优；
- 发现实现错误后只降低论文声明强度；
- 没有对照证据时声称模型简化偏差必然朝某一方向。

## U-07A 逐问“模型—求解—结果—可信度”闭环门

每个已经产生数值答案的独立问题、情形或方案比较，必须在评审可见论文中形成以下职责链：

`模型 → 求解 → 结果 → 可信度说明`

这些职责可以合并在自然段、表图解释或相邻小节中，不要求四个标题、四个段落或四种
同构句式，也不能用“验证可靠”替代真实证据。其内容至少回答：

1. **模型**：现实对象怎样映射为变量，采用哪些关系、假设、目标和约束，为什么该结构
   能回答本问；
2. **算法**：输入、候选或状态怎样产生和更新，按什么判据比较或接受，何时停止，输出
   怎样还原为题目答案；
3. **结果**：在什么条件和候选域内得到什么数值或方案，与基准相比说明什么，如何直接
   回答题目；
4. **误差分析或敏感性分析**：先按U-02识别真实来源，再说明所用范围、界、扰动或收敛
   设计，量化关键输出变化，并判断是否改变数值精度、排序、可行性或最终决策。没有依据
   的扰动范围不得为了凑结构而虚构；未触发某类误差时，说明为什么不构成材料风险，并
   保留仍未解决的模型适用边界。

### 误差与灵敏度的方法—数理关系门

每个误差或灵敏度段必须就地写明所用方法的规范名称，并紧邻给出它实际计算的
数理关系，例如误差范数、相对差、收敛比、区间传播、局部扰动差、重新优化映射或决策
切换判据；随后报告该关系得到的范围以及是否改变报告精度、排序、可行性或决策。软件
包名和“进行了分析”不能代替方法与数学关系。正文使用“采用容差加严法”“采用区间
角点传播”等自然表述，不把“工具”作为机械标签，也不为每项方法重复设置同构句式。

独立实现、独立程序或另一算法同值仍只属于内部实现审计。若它没有额外产生数值误差
界、收敛阶、输入传播范围、参数敏感度或决策变化信息，就不得放入评审可见的“误差
分析/灵敏度分析”正文、标题、图注或表题，也不得用相对同值差伪装成离散误差。正文
应改用真实触发来源对应的容差/步长加严、区间传播、扰动、界或模型形式比较；若没有
这种证据，明确记为`unresolved`并收缩声明，而不是用独立复算补位。

### 摘要可信度准入门

摘要首先承担逐问方法、核心结果和结论边界，不按固定句数分配职责。误差或敏感性结果
只有在它会改变报告精度、方案排序、可行性、最终决策或适用边界时，才作为该问的摘要
信息写入；写入时须交代扰动对象、范围或判据及结论是否改变。不能让模型名称代替模型
职能、让“数值求解”代替关键算法逻辑、让数字清单代替结果含义，也不能用“经过验证”
冒充可信度结论。若真实证据只能给确定性数值误差界，就明确报告该界，不得改称概率误差
或稳健性。

### 正文就地闭环门

正文中每问的各项职责必须能在局部论证中直接定位，并达到可复推程度，但不强制每项另设
标题。模型部分先
给对象和关系，算法段说明状态变化与停止依据，结果段完成数据—结论闭环，误差/敏感性
段按U-05形成“来源—范围—方法—输出影响—决策影响—边界”闭环。评价章节可以汇总
跨问边界，但不能替代各问就地展开的第四段。

### 内部交叉求解边界

采用另一算法、另一实现或另一软件得到同值，只用于内部实现审计，回答“代码是否忠实
执行规格”。它本身不是论文中的误差分析或敏感性分析，也不作为摘要中的验证亮点。
除非交叉求解进一步给出与预定用途相关的数值误差界、收敛阶、参数扰动响应或决策变化，
否则不在评审可见正文罗列另一算法名称、实现路线和同值差；只把由其支持且符合上述第四
段口径的误差界写入对应小问。内部审计证据继续保存在验证报告和冻结产物中，不因正文
精简而删除。

全文审计逐问建立职责映射。正文的必要职责为空、只有悬空术语、缺少题目作用，或者
把内部交叉求解冒充误差/敏感性分析时，当前模块回退为`逐句审计失败`。

## U-08 来源边界

本规则的通用原则与 NIST TN 1297 的不确定性分量识别、传播和报告要求，NASA-STD-7009B
的验证、确认、不确定性刻画和结果稳健性职责，以及欧盟委员会 JRC 将不确定性分析与
敏感性分析配套但分责的指导一致。外部标准用于确定通用质量问题，不自动规定竞赛论文
标题、固定方法、固定扰动比例或本题参数；项目仍须登记实际使用来源和适用范围。
