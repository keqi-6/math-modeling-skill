# 活动规则唯一归属

| 范围 | 唯一 owner |
|---|---|
| K-01—K-07 不可跳过内核 | `SKILL.md` |
| G-* 全项目读取、结构和回归门 | `00-execution-gates.md` |
| R-* 执行回执与跳过证明 | `01-execution-receipt.md` |
| L-* 生命周期、逐问阶段、理解与候选晋升 | `05-project-lifecycle.md` |
| M-* 全文通用内容与读者优先规则 | `10-global-manuscript-rules.md` |
| F-* 前置部分 | `20-front-matter.md` |
| B-* 背景、重述与问题分析 | `21-background-restatement-analysis.md` |
| A-* 假设、符号与数据 | `22-assumptions-symbols-data.md` |
| S-* 模型、求解、结果与逐问回答 | `23-model-solution-results.md` |
| C-* 评价、结论与参考文献 | `24-evaluation-conclusion-references.md` |
| V-* 图表、LaTeX、PDF 与版式 | `30-figures-tables-layout.md` |
| E-* 证据、来源、数字与声明 | `40-evidence-provenance.md` |
| H-* 治理、交接和交付 | `50-governance-handoff.md` |

唯一归属只禁止同一规则存在两个正文权威，不禁止入口重复列出触发条件、失败条件和
MUST_READ 路由。入口重复的是执行索引，不是规则副本。

历史材料位于 `references/rule-sources/`，只承担来源追踪和迁移核验。任何仍有效的独立
义务必须进入上述 owner；不能用“历史文件里还有”证明活动 skill 已覆盖。
