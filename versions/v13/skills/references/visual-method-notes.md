# 图表方法提示（非规范性）

## 设计

先确定读者问题，再选择编码。精确值比较常适合位置或长度；趋势适合共享坐标轴；分布适合箱线、密度、直方或经验分布；网络、空间和流程关系需要明确节点、边、尺度或方向含义。3D、面积和装饰性图形容易放大感知误差，应有信息收益才使用。

不确定性可以用区间、带状区域、分布、情景小倍图或概率编码表达。多个面板宜共享可比较尺度，并在图注解释不同尺度。

## audit

实际渲染审计可以从身份、准确、可读和版面四层检查：

| 层 | 典型检查 |
|---|---|
| 身份 | 数据/运行哈希、图源、渲染输出是否同步 |
| 准确 | 坐标、单位、排序、归一化、误差条和截断是否正确 |
| 可读 | 字号、线宽、颜色、重叠、图例和标注是否清晰 |
| 版面 | 最终尺寸、分页、裁切、分辨率和嵌入是否正确 |

概念示意图应明确标记为非数据图，避免读者把装饰性比例或位置当成定量关系。
