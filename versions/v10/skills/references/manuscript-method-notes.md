# 稿件方法提示（非规范性）

稿件结构由当前项目要求决定。以下检查项是方法提示，不是固定章节模板。

## 内容链

读者通常需要依次看见：问题边界、符号与假设、数据身份、候选选择、数学规格、求解过程、关键结果、验证、局限和结论。每个主张可问三个问题：它属于计算、解释还是外推；证据在哪里；证据变化时哪段文字应失效。

摘要可以按“问题—方法—核心结果—验证边界—结论”核对，但不必机械套句式。方法段的最低信息量由复现需求决定；篇幅受限时，正文仍应保留决定模型身份的内容。

## reader-audit

完整读者审计可依首次阅读顺序进行：标题与摘要是否准确；术语是否先定义；章节承诺是否兑现；公式和变量是否一致；结果是否回答当前问题；图表是否在首次引用附近得到解释；局限是否来自真实验证；结论是否超过证据。

验收还可检查交叉引用、引用来源、占位符、分页、字体嵌入、表格溢出和最终渲染。但这些技术通过不能替代主张审计。

## local-edit

局部修改先圈定文本跨度，再检查直接依赖：同一符号的其他出现、交叉引用、摘要或结论中的重复主张、相关图表标题和单位。若变更改变模型、数据或主要结论，应离开局部编辑路由，重新进入相应领域路由。
