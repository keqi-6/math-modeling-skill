# 误差、不确定性、敏感性与稳健性

适用于量化输入、参数、结构和数值不确定性，检查结论翻转边界，以及把可信度结果绑定到论文主张。它补充 E1–E4，不替代其中任何一轴。

来源保留：V8 `09-robustness-checker.md`、`36-uncertainty-error-analysis.md` 和结果验收规则；结合 V14 的预注册、精确 evidence binding 与状态边界。

## 先分类来源

至少区分：

| 来源 | 典型内容 | 不应混淆为 |
|---|---|---|
| 数据/观测 | 测量噪声、抽样、缺失、口径 | 数值求解误差 |
| 参数 | 估计误差、区间、校准不确定 | 任意百分比扰动 |
| 结构 | 假设、模型族、边界条件、候选域 | 单参数敏感性 |
| 数值 | 离散、容差、舍入、随机搜索 | 现实变异 |

还要分开实现错误、模型不适用和现实情景变化；不同来源需要不同证据。

## 在看结果前登记设计

登记扰动对象、现实或统计依据、名义基线、范围、联合结构、次数、是否重新估计/优化、输出指标、决策阈值和预期判据。这样可以避免看到结果后挑选有利尺度。

统一 ±5% 或 ±10% 不是通用默认。范围应来自测量精度、估计区间、历史波动、题面情景、工程容差或明确的探索性边界；探索网格必须标为探索，不能冒充概率分布。

## 方法选择

- 有概率信息：蒙特卡洛、bootstrap、后验传播或随机过程分析。
- 只有范围信息：区间、情景、最坏情形或鲁棒优化。
- 有依赖结构：按实体、区组、时间、网络或空间单位重采样/扰动。
- 结构不确定：比较关键模型族、约束或边界条件，而非只扰动参数。
- 数值误差：有序加密、容差收紧、独立高精度或误差界。

抽样单位必须匹配数据依赖；逐点删除不能用于本应整组、整条轨迹或整张网络改变的问题。

## 固定方案与重新优化

明确区分：

- 固定名义方案后代入新参数：回答既有方案的性能变化；
- 参数变化后重新估计或优化：回答决策是否切换、资源如何重新分配。

声称方案切换时，比较新旧完整方案，定位最小变化子集，并说明继续使用旧方案会违反什么约束或损失什么指标。

## 状态依赖、输出响应与多因素归因

先说明图或实验展示的是本构函数值、偏导/弹性、沿名义状态轨迹的系数变化，还是扰动经完整模型传播后的输出响应。函数高值不等于高敏感度，某系数沿过程变化最大也不等于终点对它最敏感。只研究函数形状时无须额外运行完整模型；只有提出输出敏感性或重要性排序时，才需要与该主张匹配的受控传播证据。不同量纲的幅度或未经说明的归一化不能直接排列物理作用大小。

多个因素同时变化得到联合情景效果。若要分辨两个因素，可在其他条件相同且组合有意义时比较 y00、y10、y01、y11，其中两个下标分别标识因素设置；条件效应如 y10−y00、y11−y01，交互对比为 y11−y10−y01+y00。非零交互说明效应依赖另一因素设置，不能默认单因素贡献可相加。整组系数替换只支持该组变化的条件效应，不能据此归因某个系数；这些仍是模型内对照，不自动成为现实因果证明。是否需要交叉情景由归因问题决定，不要求每次敏感性分析跑全因子实验。

分阶段比较时说明分段点来自题设、外部输入、物理状态还是人为诊断窗口。同名阶段须核对对应条件，不能把上一问条件或人为分段直接当成本问规定。阶段划分用于定位风险，不因分段本身增加证据强度。

## 输入重建与取样位置

比较插值、平滑或观测区间外的延续时，核对数据是否允许该处理、节点是否保留、物理形状约束、共同计算条件与输出位置。更光滑或阶数更高不自动更接近未观测真值；数值网格加密不能消除观测重建的不确定性。用均值代表已观测平台的最小二乘性质，也不证明未来一定保持该平台。

移动区域中，固定物理位置、固定材料坐标和实际表面是不同取样对象。局部差异可能同时来自历程改变与位置映射；先对齐比较口径，再判断需要哪些对照才能拆分贡献，不从终点接近推断全场稳定。分阶段或局部指标只在能解释全局极值掩盖的风险时补充；不要求所有模型都分段，也不把若干情景包络称为置信区间。

## 输出和解释

结果最好给出分布、区间、翻转阈值、可行比例、排名稳定度或决策切换边界，而不是一句“变化不大”。至少形成：

`不确定来源 → 方法与数学关系 → 范围依据 → 传播对象 → 结果 → 主张影响 → 不能推出什么`

误差带、置信区间、概率和最坏情形界必须标明含义；视觉相似只能展示结果，不能单独证明稳健。

## 与 E1–E4 和 S6 的边界

- 数值误差可进入 E2，但不替代 E1 的规格符合性。
- 参数/结构敏感性可支持 E3，但必须针对模型主张和失败风险。
- 现实数据下的覆盖与预测表现可支持 E4，强度由数据设计决定。
- 模板化限制段落不是任何一类证据。

S6 只核验当前 E1–E4 及命中的不确定性/稳健性证据；之后只读复核可以继续。若新结果推翻旧证据，先按 identity 和主张依赖精确重开，不能在已关闭阶段原地覆盖。

## 人工审阅

人工重点确认扰动是否现实、决策阈值是否有意义、结论翻转是否可接受，以及论文主张是否已相应收窄。多个参数和场景可成组确认，不要求逐点门禁；新的价值权衡、现实容差或结论边界变化需重新确认。
