# 版本阅读指南

`versions/` 保存技能的完整演进谱系，共 17 个版本。**内层结构不统一**，
因为目录本身是当时工作状态的原样保留：

| 版本 | 内层结构 | 说明 |
|---|---|---|
| V2 – V9 | `versions/vN/SKILL.md` | 早期版本直接把技能树放在版本根目录 |
| V10 – V16.2 | `versions/vN/skills/SKILL.md` | 内层统一为 `skills/`，同级附带该版本的发布/验证元数据 |

## 演进节点

| 版本 | 阶段形态 | 主要变化 |
|---|---|---|
| V2 | 单一规则清单 | 一个 SKILL.md 加一组编号规则文件（`rules/00`–`rules/50`），`source-portfolios/` 保留课前来源组合 |
| V3 | 规则补全 | 规则条目继续细化 |
| V4 | 规则分域 | 规则按数据、建模、验证、论文、图表、来源交付分文件，`references/migration-ledger.md` 开始记录迁移 |
| V5 | 项目实践接入 | 规则开始带真实项目回传 |
| V6 – V7 | 规则库膨胀 | 规则条目与来源组合大幅增长，出现架构决策记录 |
| V8 – V9 | 结构化重构 | 规则结构与校验脚本分离，模块化 references 成形 |
| V10 | 能力双层 | 原子规则与实施方法包分层，加入工作检查点与恢复清单 |
| V11 – V14 | 状态与契约 | 状态机、路由契约、回执 schema、恢复评估逐步成形 |
| V15 | 平台准入与发布门 | 引入平台契约、发布计划与场景回归 |
| V16 / V16.1 | 兼容变更闭包 | 修复"跨题兼容补丁被放大成大量状态迁移"的控制缺陷，加入 validity overlay 与原子闭包对账 |
| V16.2 | 稳定发布 | 依据一次完整项目复盘澄清十项方法；规则、状态、权限与验收门不变 |

## 当前主技能

仓库根目录的 `skills/` 是 **V16.2.0** 的冻结副本，与 `versions/v16.2/skills/` 内容一致。
V4 之前的 bootstrap 主线单独放在 [`legacy/bootstrap/`](../legacy/bootstrap/)，
因为 2011B、2021B 两个项目实践用的正是它。
`versions/v16.2/` 另外保留冻结记录（`冻结记录/`）与该版本发布清单、交付校验。
