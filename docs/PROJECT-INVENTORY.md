版本号取自项目内嵌 `skills/SKILL.md` 的标题与 `metadata.version`，并与中央版本树做过内容哈希比对。

位置用 `<AI_ROOT>`（项目父目录）、`<WORKSPACE>`（2021 B 题工作根）、`~`（用户主目录）表示。

## 四、版本命名说明

| 版本 | SKILL.md 中的名称 |
|---|---|
| V1 / V2 / V3 | `math-modeling-project-bootstrap`（V1 无版本号，V3 标题为 "Bootstrap V3"） |
| V4 起 | `math-modeling-project-controller` |

因此上表第 1–3 项用的是 bootstrap 语义的技能，第 4 项起才是 controller 语义。
2021 B 题项目内的 `skills/SKILL.md` 与中央 `总skill/skills/SKILL.md` 内容哈希一致——
V1 主线被原样带入了项目。
